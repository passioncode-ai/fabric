# Персональный Fabric и пульс работы

Статус: целевой дизайн, уточнён оператором 2026-09-15. Продолжение [первого запуска](README.md), а не новый продуктовый приоритет. Все числа в макетах — синтетический набор; runtime coverage не меняется.

## Зачем

Вернуться, узнать своего Fabric, увидеть значимые изменения и выбрать следующее действие. Цветной персонаж создаёт узнаваемость; источник пользы остаётся прежним: восстановленный контекст и разобранные вопросы. Доска выше графика и релизов. Пульс помогает отличить ожидающее решение от отсутствия свежего наблюдения.

## Композиция

Home: цветной аватар и приветствие; короткая статистика с формулой; доска и проекты в основной колонке; пульс в правой. Ниже основной работы — график значимых событий и последний проверенный релиз. На узком экране пульс идёт после доски и проектов. Аватар не мигает и не изображает состояние агента цветом.

**Знакомство с Fabric:** характер «Орбита / Искра / Волна», три варианта, явный выбранный облик, «Ещё варианты», «Сохранить облик» и «Пока оставить этот». Выбор сначала черновик; выход не меняет сохранённый профиль. Возврат в настройку сохраняет текущий облик. В R0 генератор детерминированный SVG, без сетевого запроса; персональный seed принадлежит estate, не аккаунту провайдера. AI-рисование можно добавить отдельным адаптером позже, не делая первый вход зависимым от него.

**Пульс:** сводка «нужно ваше решение / есть свежие наблюдения / покрытие неполное», время снимка и источники, последняя/следующая итерация обзора. «Пауза ленты» останавливает только отображение. «Показать новые» применяет накопленную порцию без автоматического перемещения фокуса. Пример отключения источника сохраняет последний снимок и говорит, чего не знаем. Отдельная полоса показывает рабочие циклы: расписание, последнее окно и результат. Зелёный heartbeat не подтверждает проверенный результат.

**Активность:** 7/28 календарных дней в указанном часовом поясе, столбцы результатов и решений с текстовыми значениями. Клик по дню открывает его исходные записи. Нет покрытия — «нет данных», а не 0. Только уникальные принятые результаты/решения участвуют в прогрессе; heartbeat, токены, повторная доставка, открытие приложения и фоновые тики не увеличивают streak. Дни отдыха не наказываются. Сравнение с другим человеком и лидерборд не входят в запуск.

**Релизы:** объект релиза закреплён за проектом и средой; карточка отвечает «что изменилось, почему, где действует, чем проверено, что дальше». Commit, сборка, публикация, проверка и принятие человеком различаются. Откат — новая запись со ссылкой на исходный релиз, не исчезновение истории. В макете никаких deploy-кнопок с внешним эффектом.

## Границы этой итерации

Сохраняем выбранную композицию и бренд-токены, добавляем ограниченную цветовую палитру персонажа и диаграммы. Проверка визуала: доска остаётся первым действием; у каждой цифры и live-статуса есть объяснение; на 390px управляющие элементы доступны; выбор аватара не сбрасывается при переходах. Один последовательный visual critique, изменения только по наблюдаемым дефектам. Данные примерные, состояние живёт в странице; сохранение в базе, фоновые наблюдатели и AI-generation — будущая инженерная работа.

Порядок текущей работы: сценарии/источники → контракт и пакеты → макеты → интерактивная/визуальная проверка → документация и карта → fast → Git → версия wiki. Текущая модель сеанса сохраняется; дополнительных агентов и фоновых заданий для этой итерации не запускаем.
