## Overview

Fabric — узнаваемый CEO внутри PassionCode.ai. Его ценность: при возвращении к работе показать, куда идёт проект, что изменилось, почему мы здесь и какое решение нужно сейчас. IDE остаётся местом исполнения внутри проекта.

Сердце продукта: цель → задача → исполнение → вопрос или результат → решение и проверка → сохранённый контекст → следующий запуск. Циклы входят в первую итерацию.

## Priority

1. **Сейчас: AD00 — исправить связь источников и UX-проекции.** [Точный пакет](adoption/packets/AD00.md): последний экран ошибочно получает ссылки из общих приложений. До дальнейшего coverage-планирования исправить границы и доказать отрицательным тестом. AD02 независимо защищает native-черновики.
2. **Затем AD01 / OX-01 / D01 — сверить контракты с producers.** Подтвердить единую адресацию, границы команд и конкретные пробелы реализации. [Общий контекст и весь план](adoption/README.md). Первый сквозной результат — Project → checkpoint → restart → exact return; далее обязательный голос и узкие agent/cycle capabilities по готовности.
3. **R0: первый полезный возврат и ввод.** Контекст, доска, профиль, проекты, агенты, рабочие циклы; узкий CEO через текст и обязательный голос, журнал и атрибуция. Ручные формы и разговор используют один command path.
4. **R1: расширение после полезного R0.** Полный редактор планирования и более широкий manager. Сквозная приёмка обязательного R0, включая голос, больше не откладывается до R1; исторический план сохранён.

Зависимости и критерии: [пакеты работы](../audit/2026-09-15-launch/packets.md), [граф запуска](../audit/2026-09-15-launch/index.html#workgraph). Статусы исполнения остаются в [основном backlog](../evidence/backlog.md); этот вход задаёт фокус, не дублирует task store. Общее направление для всех участников — [общий план разработки](../evidence/backlog.md#general-development-plan) (ADR-0101): первый релиз, адаптация, агенты и память стоят в нём отдельными lanes.
