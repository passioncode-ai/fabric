# Знакомство с Fabric

Fabric — ваш CEO: помогает вернуться в контекст, найти проект, записать поручение и разобраться с вопросами, требующими решения. Имя остаётся Fabric; персональный цветной аватар меняется в «Мой Fabric». Прогресс знакомства не меняет права агента.

[Попробовать примеры](../reports/product.html#view-launch-help) · [Добавить первый проект](../reports/product.html#view-launch-start) · [Открыть главную](../reports/product.html#view-launch-home).

Это руководство к **целевому интерактивному макету**. Его данные сохраняются в пределах страницы. Ответы, сканирование папок и голос демонстрационные: реальный диск, модель и микрофон не используются.

## Первый проект

1. Нажмите «Добавить проект». Выберите папку с проектами, отдельный проект или новую идею. В примере сканирования сначала выберите один найденный проект. Само сканирование ничего не создаёт.
2. Назовите проект и первый полезный результат: например, «Подготовить страницу записи на консультацию».
3. Выберите кандидата-исполнителя или «Настроить позже». Подключение аккаунта и допуск к запуску остаются отдельными действиями.
4. Проверьте состав и создайте проект. Он получает собственную страницу и данные.
5. Откройте Fabric, обсудите цель и запишите первую задачу. Задача сохраняется в backlog; запуск не начинается автоматически.
6. Добавьте учебную тему доски. После прочтения сохраните итог разбора. Рабочая задача остаётся открытой.
7. Продолжите работу. Вернуться к знакомству можно через навигацию и руководство; пропуск подсказок не отключает функции.

## Один разговор — понятная область

Кнопка с аватаром открывает чат поверх правого края экрана. Основная страница сохраняет расположение. На узком экране чат занимает весь экран; «Закрыть» или Escape возвращает к работе.

Перед поручением посмотрите на поле «Область разговора». «Все проекты» удобно для поиска и общей доски. Конкретный проект — для его задач и настроек. При переключении разговоры и черновики остаются в своих областях. Голосовая запись прерывается при смене области.

| Напишите | Что произойдёт в макете | Следующий шаг |
|---|---|---|
| «Найди проект Atlas» | Список совпадений среди доступных проектов | Открыть нужный проект |
| «Собери изменения с прошлого визита» | Краткое состояние выбранного проекта и ссылка на контекст | Изучить источники и следующий шаг |
| «Что требует моего решения на доске?» | Открытые вопросы снимка и переход к доске | Разобрать конкретную тему |
| «Создай задачу: проверить вход» | Задача записывается сразу, если проект выбран | Открыть запись, уточнить критерии и исполнителя |
| «Добавь тему на доску: обсудить приоритет» | Предложение темы с проектом назначения | Добавить тему |
| «Настрой агента Reviewer» | Черновик инструкции | Проверить конфигурацию и допуск |
| «Настрой цикл: утренний обзор» | Черновик цикла на паузе | Проверить расписание и включить |
| «Покажи harness и доступ» | Переход к общей форме инструментов и полномочий | Изучить конкретный инструмент |
| «Поставь цикл на паузу» | Список циклов; никаких скрытых изменений | Выбрать нужный цикл и поставить на паузу |

Неизвестный запрос вызывает уточнение. Если проект не выбран, Fabric не записывает задачу в случайный проект. Для управленческих действий, ещё не представленных самостоятельным диалогом, он открывает точную общую форму. Раздел «Все управленческие возможности» содержит эти переходы.

## Голос и история

Нажмите «Голосовой ввод · пример», остановите запись, покажите расшифровку. Исправьте текст и отправьте отдельно. В раскрываемых деталях доступны примеры запрета микрофона, отсутствия устройства, тишины, прерывания и ошибки расшифровки. Текстовый ввод остаётся запасным путём.

У сообщения есть время, исходная область, способ ввода и версия. Исправленная расшифровка не уничтожает оригинал. У записанной задачи есть ссылка на точную карточку и источник команды. В продукте эти связи должны сохраняться в журнале проекта после перезапуска; в макете они живут в памяти страницы.

## Когда нужен оператор

Чтение доступного состояния не требует подтверждения. Явно запрошенная обратимая задача записывается без лишнего шага. Запуск, расширение доступа, включение цикла и действия с внешними последствиями используют существующие проверки и конкретные параметры. Пауза циклов не запрещает обсуждать работу и сохранять задачи.

При отказе Fabric объясняет причину и оставляет черновик. При неизвестном исходе нужно проверить тот же запрос, а не отправлять копию. Отсутствие данных, ошибка чтения и отсутствие доступа — разные состояния.

Основания руководства: [сценарии](../ux/scenarios.md), [контракт и план](ceo-onboarding.md), `scripts/product/assistant.mjs` (`submitAssistantMessage`, `applyAssistantProposal`), `concierge.mjs` (`fabricCapabilities`), `guided.mjs` (`renderGuided`, `attachGuided`), `operations.mjs` (`createFabricTask`). Проверки: `scripts/test/ceo-onboarding.test.mjs`.


## Контекст над вводом

На главной Fabric открывает общий разговор; в проекте — разговор этого проекта. Выберите другое назначение над полем: основной экран останется на месте, а черновик сохранится в своём разговоре. Через «+ Контекст» найдите проект, задачу, решение или событие. Чипы можно убрать до отправки. Приложенный материал другого проекта не меняет назначение поручения. «Обсудить с Fabric» прикладывает выбранный объект; если объект не выбран, это будет проект. Во время записи голоса область закреплена до завершения или отмены.

Пример: выберите Atlas, приложите Studio и напишите «Создай задачу: сверить подход с материалами Studio». Задача относится к Atlas, Studio остаётся источником. Источники, исходный текст и квитанция раскрываются в сообщении. [Попробовать](../reports/product.html#view-launch-home) · [Все экраны и раскрытия](../reports/product.html#view-launch-design).
