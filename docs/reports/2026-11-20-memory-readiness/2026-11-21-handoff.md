## Найдено

- Установленная Fabric 0.3.26 Memory не содержит; появится со следующим выпуском.
- Транскрипты на диске только за 14 дней: старше база не видела.
- Векторы у 2,9 % документов (у Sound Engine 42 %); золотого набора и метрик нет.
- Индекс около 1 ГБ при часовом диска на линии 12 ГБ: индекс должен уважать линию (не сделано).
- Гейт репозитория идёт около 20 минут, и каждое изменение исходников требует новой записи в карте дизайна; это главная цена каждой итерации.
- Mac Studio не равен MacBook для гейта: нет `pnpm`, `rg`, Python `jsonschema` в окружении ssh, Node 26.12 вместо измеренной 26.10.
