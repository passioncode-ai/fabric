# База знаний Fabric «Memory»: готовность на 2026-11-20

**Итог.** База собирается и ищет по-настоящему, но живёт только на ветке `feat/knowledge-graph`: в установленной
Fabric 0.3.26 её нет. На этом Mac она за 12 минут прочитала 121 проект из 122 и отвечает за 0,7 до 1,7 секунды с
дословными цитатами, которые проверяются. Дашборда «Memory», как у brain Sound Engine, пока нет: есть только группа
«Везде» в поиске окна и маленький рисунок соседей узла. Не хватает ещё эталонного набора вопросов с метриками,
ленты «что изменилось», слоя «кто сейчас над чем работает» и векторов для большей части базы.

Источник замера: ветка `feat/knowledge-graph` на `99d362cc` и скрипт `apps/desktop/scripts/memory-measure.mts`
(тот же проход, что в приложении, строки Fabric из локальной базы через `psql`, индекс в `~/.cache`), 2026-11-20,
21:15 до 21:45 по Варшаве. Решения: [ADR-0200](../../adr/0200-the-estate-index-and-graph-live-in-fabrics-core.md),
[ADR-0199](../../adr/0199-the-ceo-navigates-with-direct-tools-over-one-index-not-a-router-agent.md), спецификация
[индекса и графа](../../evidence/specs/2026-11-19-estate-index-and-graph.md).

## 1. Что собирается и откуда

| Источник | Что попадает | Как обновляется |
|---|---|---|
| Транскрипты Claude Code и Codex (`~/.claude/projects`, домашние папки Switchboard, `~/.codex/sessions`) | сессия с заголовком, папкой и командой продолжения; реплики человека и агента кусками до 1 800 знаков с номерами строк JSONL; вывод инструментов и субагенты пропускаются | файл дочитывается с байта, где остановился прошлый проход |
| Консоли Fabric (`terminal.opened@1`, `session.turn.observed@1`) | консоль, её Claude-сессия, коммит HEAD на каждом ходе | по `seq` журнала |
| Задачи, заметки, связи задач, заявки, факты памяти | все проекты поместья | по `seq` таблиц |
| Доска | сообщения и запросы всех тредов (дверь оператора) | по `seq` доски |
| Git | коммиты канонических проектов за 120 дней (до 400 на репозиторий) | когда сдвинулся HEAD |
| Документы | Markdown репозиториев: ADR и решения, спеки, планы, README, AGENTS, CHANGELOG, остальное `docs/`; до 300 файлов, разрезано по заголовкам | вместе с коммитами |

Поиск гибридный, как у Sound Engine: слова через русский и английский стеммер Fabric (тот же, что у поиска по доске),
триграммы для частей идентификаторов и векторы из локальной Ollama (`embeddinggemma`), слитые по RRF с k = 60. Текст
не уходит ни в одну удалённую модель. Граф лежит в том же файле: узлы (проект, задача, сессия, консоль, сообщение,
коммит, документ, решение, действие) и связи (принадлежит, породила, блокирует, сделал, работал как, изменил,
цитирует, отвечает, связан, ждёт). Проход идёт при старте приложения, затем каждые 5 минут, первый индекс догоняется
кусками по 60 и 20 секунд, чтобы не держать окно.

## 3. Пример ответа с цитатами

Вопрос: «почему доска запускает агента, когда проекту пишут». Ответ за 852 мс, все три способа поиска сработали
(`words`, `trigram`, `vector`), первые находки: задача Fabric `bbf5d017` «Доска живёт отдельно от Fabric, смотритель
доски сам продолжает работу…», запрос владельцу о чистке кэшей, ход сессии
`~/.claude/projects/-Users-sshlg-DATA-fabric/b3f2fd9b….jsonl:86-602`. Проверка цитат (`quote.check`): дословная
цитата из найденного документа принята, та же цитата с добавленным числом отклонена с причиной `adds-number`. Так же
на остальных трёх вопросах замера (663 до 1 666 мс): «база знаний по мотивам Sound Engine», `fabric_ceo_session_resume`,
«how does the board dispatcher restart a run» (английский вопрос находит коммит `fix(dispatch): a crashed run's
workflow is taken back as crash` и CHANGELOG Switchboard 0.7.114 с `path:lines`).

## 5. Чего не хватает против Sound Engine Hub

| Sound Engine Hub | Fabric сейчас |
|---|---|
| «Мозг» на весь экран: граф всех хранилищ по регионам (sigma 4 + graphology, ForceAtlas2), подсветка соседей, карточка узла, поиск узла (`Hub/static/brain.js`) | только группа «Везде» и кольцо соседей 320 px (`renderer/src/EverywhereSearch.tsx`) |
| Живой слой: какие агенты сейчас работают и над каким узлом (`hub_brain.py#live`) | нет на графе (есть отдельно в левой колонке и на «Агентах») |
| Лента обновлений (`hub_knowledge.py#updates_list`) | нет «что изменилось» |
| Эталонный набор 48 вопросов, recall@5 0,875 и MRR@10 0,747 в гибридном режиме (`docs/research/kb-eval/results-2026-11-18.json`) | нет набора и метрик |
| Векторы у 42 % фрагментов (8 589 из 20 481) | у 2,9 % (5 600 из 194 897): 400 за проход |
| Словарь синонимов для расширения запроса (`Tools/kb/glossary.json`) | нет |
| Граф кода и конечного вида (codebase-memory, функции спеки) | код не индексируется |
| Двери search и execute для любого клиента с ключом (`/mcp`) | только CEO; для сессий проектов ждёт CO-422 |

Чего у Sound Engine нет, а у Fabric есть: сессии и транскрипты всех агентов, задачи и доска всех проектов, коммиты и
документы 121 репозитория, разделение по контекстам организаций и партнёров, команда продолжения сессии в каждой находке.

## 6. Найдено при замере и исправлено (коммит `7e93b07d`)

1. Удаление из полнотекстового индекса пишет служебную страницу с номером выше 2^53, и node:sqlite падал с «Value
   is too large to be represented as a JavaScript number: 9008161327415296»: 1 до 5 транскриптов за проход не
   записывались. Тест `estate-index.test.mjs` «…tombstone pages past 2^53…» падал до починки.
2. Проект, чьи документы откладывались по бюджету прохода, перечитывал свои коммиты каждый проход (24 208, затем
   14 685 тех же). Тест «…not read for its commits again…» падал до починки.

После починки проход по тому же индексу: 867 транскриптов прочитаны, деградаций нет.

## 7. Риски

- Диск: индекс 962 МБ, а у MacBook сейчас около 10 ГБ свободно при критической линии 8 ГБ (часовой Observatory).
  Индекс производный и удаляемый, но в приложении он должен уважать эту линию.
- Окно: первый индекс занимает главный процесс кусками по 60 и 20 секунд около 12 минут суммарно.

## 8. Что дальше (план волн)

- **Волна 1. Memory как раздел.** Вход «Memory» в левой колонке; обзор (сколько, откуда, по проектам и
  организациям), граф организаций и проектов на sigma (тот же открытый движок, что у Sound Engine, не его код), поиск
  с проверенными цитатами, свежесть по каждому источнику, «что изменилось» за сутки. Один модуль операций
  `memory.overview`, `memory.graph`, `memory.changes` за дверью execute, и окно, и CEO вызывают его.
- **Волна 2. Качество.** Эталонный набор вопросов Fabric с recall@5 и MRR, векторы быстрее, словарь синонимов,
  индекс уважает линию диска.
- **Волна 3. Доступ.** Двери search и execute для сессий проектов в их контексте (CO-422), коннектор графа
  организации (CO-600), граф организаций с долями из данных владельца (сессия 8343a070), живой слой.

Вливание `feat/knowledge-graph` в main идёт по политике репозитория после зелёных гейтов, без force-push.
