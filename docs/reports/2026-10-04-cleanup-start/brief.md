## Selected profile and boundaries

Five stages: inspect/measure → bounded cleanup and source harvest → reconciliation
and Start packets → execute available leaf and review → source delivery/publication.
Kernel fields scope/evidence/deps/resume are mandatory throughout. Current parent
model is inherited; no model override, extra approval cycle or provider session.
The operator requested execution; routine reversible implementation is authorized.
Human-protected release, live database migration and authority-changing operations
retain their existing gates. A branch receipt is never promoted to main/native proof.

Project alignment: progressive Start strengthens the durable Project and truthful
readiness; cleanup restores capacity without changing product authority. Accepted
vision and ADR-0100 govern lane 1. Existing owners of P-08 and onboarding fixtures
keep their work; root selects a non-overlapping available leaf or reports its exact
dependency. Canonical statuses have one owning register.
