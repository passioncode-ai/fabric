# Fabric renderer UI audit, release candidate 0.3.21

**Source:** `/Users/example/DATA/_worktrees/fabric-0321-i3r4` at `819b4bc7`, which includes the `.as-main` fix. Nothing in the checkout was changed. Paths are relative to `apps/desktop/src/renderer/src/`. Screenshots are in `shots/`.

**Method:**
- `stress.mjs`: every grid or flex-row class gets one child carrying wide content, at 1280 and 800 px. Output is `stress.json`: 195 classes let the child run past the container, 78 of them grids.
- `repro.mjs`: markup copied from the components' JSX inside the shell markup, with the nine renderer stylesheets in bundle order, at 1800, 1280, 1024 and 800 px, plus screenshots.
- `apc.mjs`: the repository's agent-page column test extended to 900, 800 and 700 px (12 checks pass).
- `contrast.mjs`: every text and line colour token on every background token, both themes.
- `rail.mjs`: the rail counters and star in both themes.
- Mechanical scans of `ru.ts` and `en.ts`, and a reading of `CommsScreen`, `CommsFeed`, `WorkDirections`, `ProjectLaunch`, `AgentPage`, `KanbanBoard`, `BoardScreen` and `LaunchShell`.

**Coverage limit:** the helper reviews of the full `ru.ts` text and of every screen against `scenarios.md` and `screens.md` were stopped by the usage limit and produced nothing. Other screens were covered only by the stress test and the string scans.

## Systemic causes (one fix removes many)
1. **Grid columns sized `auto` or `1fr`.** Both grow to the widest child, which is how `.as-main`, UI-4, UI-5, UI-6 and the 78 grids of UI-8 widen. Fix: `minmax(0,1fr)` everywhere, including the media-query collapses, or `min-width:0` on grid children. Add the stress test to `scripts/test/` as a gate.
2. **One row class reused for different rows.** `.lp-topic` is a numbered 4-column grid, and Comms uses it for a two-child thread row and for whole messages (UI-1, UI-2, UI-22). Fix: a separate class per row shape.
3. **Breakpoints read the window, not the space the page has.** The rail and the side panel change that space, so with the panel open the page keeps two columns in 456 px (UI-3). Fix: `container-type:inline-size` on the page and `@container` queries.
4. **`break-word` where `anywhere` is needed.** User content (UI-5, UI-6, UI-11) needs `overflow-wrap:anywhere`.
5. **One yellow accent for both themes** (UI-12, UI-13). Fix: an `--app-accent-ink` token for text and markers; keep the yellow for fills.
6. **Literal type sizes instead of the token scale** (UI-10). Fix: tokens, and a lint for sizes under 11 px.
7. **No gate on em dashes in strings** (UI-15). Fix: extend `scripts/check-design.mjs` to fail on U+2014 in i18n values and JSX text.
