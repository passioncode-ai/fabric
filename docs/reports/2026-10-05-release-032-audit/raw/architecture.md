## What was checked and found sound, per area

**1. Process and trust boundaries.**
- Every `BrowserWindow` uses `sandbox: true` with the default `contextIsolation`, and the preload is CJS for the sandbox (`index.ts:4116/4148/4169/4356`, `electron.vite.config.ts`). There is no `dangerouslySetInnerHTML`/`innerHTML` in the renderer.
- File access goes through per-window granted roots. `files.read/write/openExternally`, start-path inspect/scan, create-folder and repo attach all resolve through `fileRoots.resolve`, and the roots are revoked on window close (`index.ts:3712-3849`, `:3204-3280`, `:943`).
- The agent surface checks Host before anything else (`421` unless it is the literal loopback origin), refuses any `Origin`, and binds 127.0.0.1 plus `[::1]` for the hub port. The session bearer is spent on one `initialize` and tied to the MCP session id. External bearers are admitted per bucket before body read, the door token is compared in constant time, bodies are capped at 1 MB within 10 s, batches are refused, and the budget is 120/min (`agentSurface.ts:357-700`, `accessService.ts:91-95`).
- `hub.json` and the door token are 0600 and written atomically, and are withdrawn only by their own pid; the quit-time read refuses FIFOs and symlinks (`hub.ts`).
- The product forwarder refuses every redirect, so no key travels to a second origin, and it has a whole-exchange deadline. Connect callbacks require https `server`/`mcpUrl` without userinfo (`productForwarder.ts:101-124`, `productConnect.ts:161-162`, `:371-372`).
- Board calls take estate, Project and principal from the authenticated scope, use strict zod schemas, and MAC their cursors with `timingSafeEqual` (`boardService.ts`, `agentSurface.ts:2258-2262`).
- Credentials stay out of argv. The ACP session document and bridge bearer travel in env and are deleted on read (`acpShellMain.ts:17-19`, `mcpStdioBridgeMain.ts:13`). Vault secrets go on stdin or through a 0600 FIFO (`observatoryVault.ts`). The Codex backend gets only a token digest (`codexLoopback.ts:104-107`). Session environments withhold Fabric's own DB keys (`sessionEnv.ts`); A7-001 shows those keys are guessable anyway.

**2. Data integrity.**
- All 65 tables across 79 migrations have RLS and an explicit or default grant. Board tables revoke all API roles, and every `board_*` function is `security definer set search_path = public`, executable only by service_role (`…081_project_board.sql:133-134`, `:422-429`).
- No SECURITY DEFINER function lacks `search_path`. The dispatcher grew strictly one function at a time, ending with `apply_comms`. All 101 event types have an `event.<type>` sentence in `en.ts` and `ru.ts`.
- `schemaContract.json` is 79/79, equal to the migration count. `build-manifest.mjs:83` enforces this, and `schemaReadiness.ts` fails closed.
- Local state writes go to a temp file, are fsynced and renamed, and are validated before and after serialisation (`localState.ts:195-245`).
- The journal client retries only on 55P03, with jitter.

**3. Lifecycle (LC-01…LC-15).**
- The quit coordinator re-quits on a macrotask, stops every registered scheduler first, and arms both the 10 s in-process deadline (exit 3) and the outside reaper before the stops run (`quit.ts`).
- Every `setInterval` in main is cleared on quit or unref'd: TICK_MS, NOTIFY_MS, analytics hourly, registry poll, splash tick (`index.ts:647`, `:2087`, `:2968`; `agentRegistry.ts:486-495`).
- Hub files are withdrawn on quit (`index.ts:603-607`). A `supabase start` during the splash is ended (`env.ts:85-99`).
- Detection and auth probes run in their own process group, which is SIGKILLed on every outcome (`executorDetect.ts:171-200`, `executorAuth.ts:50-80`).
- `--background` opens no splash and no window until activation (`index.ts:423`, `:4287`).
- Stop receipts stay honest: an unmanaged agent session reports `outcome_unknown` unless the provider proves quiescence (`nativeStopRuntime.ts:161-190`).
- The gaps are the detached ACP agent (A7-003), the synchronous `which` (A7-011) and the reaper (A7-029).

**4. Error handling and observability.**
- Every `fetch` in main has a deadline (analytics 15 s, quota 8 s, forwarder 60 s), and every child process has a bound.
- All IPC goes through `handle()` with a correlation id; the three `ipcMain.on` listeners are the exception (A7-009).
- The surface handler records its failure and answers 500, or cuts the response. The ops sink never throws, counts lost lines and redacts detail and messages.
- Executor spawn errors are withheld because they can carry private paths, and forwarder errors are scrubbed.

**5. Duplication and drift.**
- `check-regions.mjs`: 175 markers, all closed and resolving. Twelve were sampled against their targets: hub-discovery, hub-external-ingress, hub-call, board tools and service, acp-shell, mcp-stdio-bridge, helper-process, usage-analytics (two), quit-coordinator. All match except A7-042.
- The AGENTS.md lifecycle constants match the code: 60 s ticks, 8 s drain, 10 s deadline, exit 3, port 47070, the credential hold.
- `surfaceTools.ts` equals the registered tools (27/27). The contract fixture pin matches ADR-0117. `check-registers.mjs` and `check-docs.sh` pass, with the caveats in A7-041 and A7-046.

**6. Analytics privacy.**
- `cleanProps` keeps only finite numbers, booleans and a fixed list of kinds.
- Only release builds carrying an App Key send.
- The shared switch is fail-closed: an unparsable or removed file turns analytics off and is never repaired or recreated.
- Turning it off drops the queue. The queue lives in memory only, is capped at 200 and kept at most 23 h, and sends go out with a 15 s deadline.
- `refresh()` honours another app's switch, hourly (A7-031). Unknown fields are kept on rewrite. The `environment` rule matches the growth contract.
- The issues are the default-on, "anonymous" framing of a persistent cross-app id (A7-012) and dev builds minting the id (A7-030).
