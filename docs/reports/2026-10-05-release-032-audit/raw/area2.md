## What was checked and found sound

- **Grants and RLS.** I collected all 65 `create table` statements across the 79 migrations by script. Every table has RLS enabled. Every table has an explicit grant or the migration-26 default (`select` to authenticated, DML to service_role). The tables without a policy are either private tables that no API role may read (`ceo_*`, `board_*`, `*_authorizations`, `estate_restore_boundaries`) or are read only by the service-role host. The desktop uses only the service key (`index.ts:483`). No `.from()` target in `apps/desktop/src` or `packages` reads a table whose privileges were revoked from service_role, and every `.from()` target exists.
- **The board tables.** They revoke all from every API role (81:133-134). Every `board_*` function is `security definer set search_path = public`, and the five commands are executable only by service_role (81:422-429). Primary rows are immutable through triggers. Writes are gated on `board_write_authorizations` inside `append_event`. Both event types are registered, and `event.<type>` sentences exist in en.ts:22-23 and ru.ts.
- **Feed sentences.** All 101 event-type literals in the migrations have an `event.<type>` sentence in en.ts.
- **Function privileges.** No SECURITY DEFINER function's latest definition lacks `search_path`. Every function created in migrations 70-81 is revoked from authenticated (migration 75 sweeps `apply_*`).
- **The dispatcher.** `apply_projections` only ever grew one line at a time, from 19 → 81, ending with `apply_comms`.
- **The journal client.** `packages/journal` retries only on 55P03, with jitter. `append_event` keeps the registry check, `lock_timeout`, and the canonical, foreign-identity and taken-name refusals in 81.
- **Coverage registers.** Every table is classified in `storageContract.ts`.
- **Schema contract.** `schemaContract.json` is 79/79, which equals the migration file count. `build-manifest.mjs:83` enforces this, `schema_version()` counts applied migrations, and `schemaReadiness.ts` fails closed on timeout, error and out-of-window.
- **Local state.** Writes go to a temp file, are fsynced, then renamed (`localState.ts:195-210`).
- **Known rows, not repeated.** CO-185 (offset paging), CO-199 (78/79 filenames), CO-200/201/202 (hub journal volume, replay rules, restored denial) and CO-212 (board restore keeps events, not messages) are recorded and the code matches their descriptions.
