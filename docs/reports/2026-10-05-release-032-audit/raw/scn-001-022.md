# Audit slice A1 — SCN-001…SCN-022 (Fabric 0.3.2 RC, commit e19e1b9e)

Read-only audit of `the audit checkout`. All paths are repository-relative;
`src/` means `apps/desktop/src/`. Line numbers are at e19e1b9e.

Checks actually run: `npx vitest run src/shared/attention.test.ts src/shared/proposals.test.ts
src/shared/servers.test.ts src/renderer/src/launch/BoardScreen.test.tsx
src/renderer/src/launch/ObligationActs.test.tsx` gave 5 files and 86 tests passed. No DB test was run,
because a DB test needs the stack and the stack was not started.

Context: 20 of the 22 scenarios in this slice describe the pre-R0 "managed estate" contract. That
contract covers providers, admission, bindings, connections, membership, foundry, support, content and
MCP access. The SCR records for these screens mostly say `designed` / `none yet`
(`docs/ux/screens.md:20-38`). The first-release banner (`docs/ux/scenarios.md:5-7`) supersedes the
creation route. "Missing" below therefore means the scenario's described behaviour has no code. It does
not mean a regression.
