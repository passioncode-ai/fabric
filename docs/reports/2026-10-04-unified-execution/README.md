## Single queue and cold handoff

[plan.json](plan.json) has twelve lanes, all250 canonical ids, 59 pinned source files, 294 base research/implementation-context packets and288 bounded preparation leaves (582 planning records total). These are **planning records, not582 delivered capabilities**. Broad implementation/acceptance parents remain `design-gated`; a prepare leaf owns one dossier, validates actual prerequisite receipts and returns a precise refusal where unresolved. The147 horizon activation parents and their preparations remain held until their trigger is measured. The [audit graph](audit-graph.json) is a projection for the installed pipeline's cold-reader/collision check, not a second product-status board.

```sh
node scripts/unified-plan.mjs check
node scripts/unified-plan.mjs next
node scripts/unified-plan.mjs packet P-06.1
node scripts/unified-plan.mjs packet CO-179.prepare
node scripts/unified-plan.mjs impacts P-08
```

`check` validates the **current source bytes** and fails after drift; stale snapshot is retained as dated evidence. A future cut must first reconcile current source/receipts; do not update hashes merely to make dispatch green. `next` is a candidate list, not a lease or authority. Priority uses canonical Now first, then computed downstream count and stable ids. Human-gated and externally owned work stays held. Dependency edges name control/data payload; original cross-product dependencies are preserved in the full packet and must be converted into exact receipts by preparation before implementation. [protocol](protocol.md) describes immediate messages, acknowledgement, durable impacts and invalidation of dependent proofs.

**Cold context travels in the output**, not in this conversation: programme constraints, selected task, original detailed research packet, dependency contracts, failure cases, scope, acceptance, source pins and impacts. Read a single selected packet; do not feed the6MB queue into an agent. The compiler is [reproducible](../../../scripts/build-unified-plan.py), while the dispatch checker uses Node built-ins only. Future source changes require a new reconciled report cut; this dated report is not silently rewritten.
