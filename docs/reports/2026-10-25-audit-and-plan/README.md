### 3.3 Раскатка на первую организацию (Appvillis)

Минимальный путь из [03 §3](2026-10-25-03-first-organization.md), с тем, что из него касается Fabric:

1. Решения оператора В-1..В-4 (§4 ниже).
2. Wave 1, шаги оператора: активировать PassionCode.ai на `org.passioncode.ai/setup`, экран согласия Google в External.
3. Mac Studio вступает в PassionCode.ai.
4. Установка, пригодная для сотрудника: лаунчер ставит среду контейнеров и Supabase CLI сам; засечённый проход на чистом
   пользователе macOS. Для Fabric сюда же CO-219 (стек не должен отвечать в LAN с паролем по умолчанию на чужой машине).
5. Заморозить версию Fabric для пилота: без апдейтера (P-12 в 0.4.0) каждая версия значит ручной выход и шаг схемы на
   каждой машине.
6. Юридический минимум и поддержка (параллельно).
7. Wave 2: активация Appvillis, оба Mac оператора вступают.
8. Пилот 2-3 человека с персональным подключением; данные в отчёте не раньше 2026-11-14 (Observatory OE-01, OE-06, OBS-200).
9. Неделя пилота, проверка изоляции; затем Wave 3, остальные Mac.

Чего Fabric для этого пути **не** нужно: вход второго человека, организация как сущность, сеть машин. Каждый человек
работает в своём Fabric; организацию держат Vesta, Observatory и группы Switchboard. Это верно, только если волны развязаны (В-2).
