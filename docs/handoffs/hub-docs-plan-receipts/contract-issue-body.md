Fabric accepts the product MCP tool names `read_message` and `list_messages`, but the published `fabric-interop/0.1` argument schema rejects them. This is Fabric CO-193; it remains an open compatibility deviation until the owning contract revision is published and consumers repin it.

Measured 2026-10-04 against contract main `71cdd6ed461a177e17aa2db7f5ed2059a537543e`: [`common.schema.json`](https://github.com/passioncode-ai/fabric-agent-contract/blob/71cdd6ed461a177e17aa2db7f5ed2059a537543e/schemas/common.schema.json) defines `capabilityName` as `^[a-z][a-z0-9.-]{1,127}$`. [`interop-agent-call.schema.json`](https://github.com/passioncode-ai/fabric-agent-contract/blob/71cdd6ed461a177e17aa2db7f5ed2059a537543e/schemas/interop-agent-call.schema.json) references it. Fabric published main [`access.ts`](https://github.com/passioncode-ai/fabric/blob/8ff1450ba3b2845a9162cc2fb183a04b895ad363/apps/desktop/src/shared/access.ts) accepts `^[a-z][a-z0-9._-]{1,127}$`; [`CO-193`](https://github.com/passioncode-ai/fabric/blob/8ff1450ba3b2845a9162cc2fb183a04b895ad363/docs/evidence/specs/2026-08-16-software-fabric-carryover.md) and [`ADR-0115`](https://github.com/passioncode-ai/fabric/blob/8ff1450ba3b2845a9162cc2fb183a04b895ad363/docs/adr/0115-a-local-agent-reaches-a-cloud-product-through-fabric-on-consent.md) own the existing hub route.

Bounded design/implementation packet:

- Prefer the backward-compatible widening to `^[a-z][a-z0-9._-]{1,127}$`: every formerly valid name remains valid; existing strict validators need a new contract pin before they accept underscores. Do not silently change immutable release/tag bytes. If preserving the generic capability vocabulary requires a separate `toolName`, specify an explicit mapping and wire compatibility instead; do not require an incompatible new field in existing requests.
- Inventory every `$defs.capabilityName` use before editing; show the intended effect on capability declarations, grants and job/pipeline references. Preserve the leading lowercase letter, 2–128-character bound, and refusal of spaces, slash, uppercase-leading names and unrelated punctuation.
- Watch the baseline reject an `interop-agent-call` fixture with `agentId: example-agent`, capability `read_message`, input `{}`; then pass `read_message` and `list_messages` after the change. Retain all existing positive fixtures, add negative boundary cases and exercise the actual compiled schema/ref rather than only a copied regex. Register fixtures in `fixtures/catalogue.json`; run the existing schema-compilation, fixtures, consistency and interop-rules checks plus the repository gate.
- Record the contract decision, publish a revision through the owning release policy, and propagate source pins/bytes to Fabric, Fabric Agent Adapter and other declared consumers. Update the canonical knowledge/published backlog from committed owner status. Fabric CO-193 closes only after an exact contract release/pin receipt and consumer validation; an issue being opened is not the schema fix.

No credentials, private consumer identities, live database changes or product deployment are requested by this packet.
