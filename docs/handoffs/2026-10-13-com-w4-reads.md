## Decisions taken in the build

- Search's time budget is a clock check inside the loop (`board_search_budget()`, 2 s), not `set statement_timeout`:
  PostgreSQL arms that timer per client statement, so a function's own setting does not bound the running statement.
- At 200 held threads the list stops offering older pages and says how to reach them; dropping the oldest page on a
  "Show older" click would undo it.
- "since {since}" on the active responder line is a point in time; the other `{since}` values are "… ago".
