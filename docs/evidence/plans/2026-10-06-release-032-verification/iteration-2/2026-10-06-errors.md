## Sound

- **Editor, main side.**
  - `textOf` is fatal UTF-8 with a NUL check (`files.ts:238-245`).
  - A non-text file opens read-only with `content:''` and its hash over the bytes.
  - `writeFile` has no path that skips the hash compare (`files.ts:312-349`). A missing file is a conflict unless `ABSENT_HASH` is presented, and then it is created with `wx`, so a file that appeared meanwhile, or a dangling link, is not overwritten.
  - `roots.resolve` runs before any I/O.
  - Plants in a scratch copy:
    - hash compare bypassed → `FAIL: a stale write was accepted`
    - `readFile` decodes lossily → `FAIL: a binary file opened as text`
- **Editor, renderer side.** Each plant made its test fail:

  | `if (saving.current) return` removed (i1 ER-5) | "a second save while the first is in flight writes nothing" |

- **Grant-path write.** `policy.decide` runs before the write and `beginDispatch` → write → `observeEffect` keeps its order (`index.ts:3864-3897`). A refusal is returned, not thrown.
- **Digest.**

  - Plants:

  - Leaving acknowledges once, with the displayed boundary. `ProjectHome` is keyed by project (`App.tsx:838-844`), so a read still in flight for another project cannot land in or be acknowledged by the new one.
