Что здесь решаем

Слова владельцафильтры проектов… по имени, по последним активностям… human activity… agent activity, фильтр типа select… По организации определяются по GitHub

Выбор

  1. Где фильтры: А) всегда видны; Б) за кнопкой ≡.
  2. Нужен ли пункт «По организациям» (список с заголовками групп) в списке организаций.
  3. Что считать «моей активностью»: только действия в Fabric, или ещё ввод в консоль сессии проекта (рекомендуем: оба).
  4. Сколько закрытых сессий показывать в раскрытом проекте: за сутки, не больше трёх.

РекомендуемА, всегда видны: в колонке шириной 232 px два коротких списка помещаются в одну строку. Пункт «По организациям» добавить, он же отвечает на вопрос «что к чему относится».
