01Страница агента

вот пусть сбоку показываются там сессии, какие запущены, по центру у нас должно быть написано, что это, типа, за backend […] кто её инициировал, тоже здесь на каких это подписках работаетвладелец, 20 нояб.

  • Сессии агента в колонке сбоку: в Fabric и вне, живые сверху, завершённые свёрнуты. Нажатие выбирает сессию, справа её факты.
  • В центре мета: что это за бэкенд (из README), проект, организация PassionCode.ai, аккаунт «claude13@…» с остатком окна, где идёт сессия.
  • «Сейчас делает» с происхождением задачи: владелец сказал, CEO завёл, агент взял, плюс цитата. Пустые «нет …» убраны: одна тихая строка (переключатель «макет» сверху).

Что здесь решаем

  1. Где список сессийслева от центра, как в макете; это навигация по агентуиначе справа, как колонка «Сессия» сейчас
  2. Порядок сессийживые сверху, завершённые свёрнуты под «Завершённые · N»
  3. Как показывать аккаунткоротко «claude13@…», полный адрес по наведению, рядом план и остаток окна
  4. Пустые местаодна тихая строка с последним фактом («Задачи сейчас нет. Последняя закончена вчера…»), без заголовка блока

  6. Описание «что это»из README папки с датой и источником; без README одна строка «описания нет», без пустого блока

  2. Дорожки графапо направлениям работы (Доступ, Доска, Выпуск)иначе по ролям: владелец, CEO, агенты (так на странице задачи)
  3. Шаги агентов на графечислом на связи, по нажатию список шаговиначе отдельными мелкими узлами
  4. Вид по умолчаниюграф; выбранный вид запоминается для проекта
  5. Продуктовая доскачетыре блока сразу (цель, метрики, бэклог, заметки), пока их мало; вкладки, когда вырастут
  6. Приоритет проектоврежим «⇅ Приоритет» в левой колонке, перетаскиванием; тот же порядок у закреплённых на главной

03Главная

по центру, типа, будут у нас сначала вопросы, а потом давай идут наши основные премиальные, типа, проекты закрепленныевладелец, 20 нояб.

  • Светлое приветствие сохранено; ряд счётчиков с прочерками убран, живые числа в одной строке приветствия.
  • Сначала «Нужны вы»: вопросы компактно, с готовыми вариантами ответа; поле «своими словами» раскрывается по кнопке. Затем три закреплённых проекта: состояние, текущая работа, следующая веха с прогрессом.
  • «В работе» с режимами «Вехи», «Приоритет» (перетаскивание), «30 дней»; рядом недавние проекты и «Куда дальше».

Что здесь решаем

  1. Счётчики дняодной строкой в приветствии, без плиток с прочерками
  2. Ответ на вопросварианты кнопками, если агент их дал; поле своими словами по кнопкеиначе поле открыто у каждого вопроса, как сейчас
  3. Сколько вопросов виднотри самых старых, остальные строкой «Ещё 2: …»
  4. Закреплённыедо трёх карточек в ряд, порядок из «Приоритета»иначе до шести в две строки
  5. «В работе» по умолчанию«Вехи»: начало и конец задач, законченные шаги, вопросы

04Цепочка решений (на странице задачи)

как, типа человек сказал вот тут и потом агенты пришли сюда, а потом человек сказал вот тут, агенты пошли сюда, вот эту цепочку принятия решений на всех страницахвладелец, 20 нояб.

  • Слова человека дословно, с местом (окно CEO, ответ на вопрос, «Написать агенту») и временем; между ними «агенты: N шагов», раскрывается по нажатию.
  • Три вида из одних данных: лента (по умолчанию), карта по ролям «Владелец / CEO / Агенты», таблица с сортировкой по времени.
  • Сейчас эта история спрятана в свёрнутом блоке «История» внизу задачи; теперь она идёт сразу после постановки.

Что здесь решаем

  1. Что сворачиватьшаги агентов и системы; слова людей, вопросы к человеку, вехи и записи CEO видны всегда
  2. Записи CEOвидны, когда CEO завёл задачу или передал слова человека; его прочие шаги сворачиваются как агентские
  3. Длина цитатыдословно до трёх строк, дальше «ещё»
  4. Вид по умолчанию на задачелента; карта и таблица переключателем
  5. Где модуль стоитзадача: полная лента; проект: граф по направлениям; агент: лента текущей задачи; главная: только вехи

Вне этих макетов (из того же заказа)

  • Задачи: откуда тянутся, где хранятся, свой таск-менеджер или открытый под капотом. Отдельная проработка; в макете проекта это только строка бэклога «Открытый трекер задач под капотом: оценить».
  • Окно CEO тянется только за имя: исправление в коде, не в макетах.
