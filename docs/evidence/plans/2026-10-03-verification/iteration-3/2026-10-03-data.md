## Findings, most severe first

1. **Another estate can take over a session started by managed launch; the owner's heartbeats and stage reports are then refused** — data · blocking (migration 72's header, ADR-0103:26 and ledger V2-1 say fixed). Owned-cluster probe: after `admit_task_launch(A,T,…,S)` the session is in `task_runs` but not `project_tasks.session_id`; B's `agent.heartbeat@1 {session_id:S}` is accepted and the row belongs to B; A's next beat is refused. `agent.stage.reported@1` the same. Cause: the heartbeat pre-check looks only at `project_tasks.session_id`; stage, `transcript.captured@1`, `context.compiled@1` look only at their own tables; managed launches record the session in `task_runs.session_id` (migration 62). Fix: for all session-keyed events, a session is owned by whichever estate holds it in `task_runs`, `project_tasks` or any session-keyed table; an `admit_task_launch` case in `estate-identity-db.test.mjs`.
2. **Importing a workspace with two agents whose names differ only by case fails as a whole, with a misleading sentence** — data · major. `import_declared_snapshot` with "Reviewer" and "reviewer" is refused ("this project already has an agent called reviewer"), C ends with 0 projects. Duplicate names were legal before this change; `workspace.ts:343-356` sends every agent through `import_declared_snapshot` → `append_event` → `refuse_taken_agent_name`; migration 72's header says replay and restore do not pass through `append_event`, but the declared import does. Fix: a transaction-local exemption like the CEO and transcript ones, or rename duplicates in the import plan and say so; a test.
3. **A heartbeat row the old projector moved into another estate can never come back** — data/rebuild · minor. No repair re-derives `estate_id` from the session's owner.
4. **The search filter and the paged read are never exercised against the real gateway by any tier** — harness · minor. Checked by hand on a disposable stack and correct (escaped searches found exactly their projects; `selectAll` over 1,212 projects returned 1,212; `payload->>id` count correct). Fix: put the probe into the full tier.
5. **A failed pause-receipt write in `launchesExhausted` still aborts the whole chain pass** — orchestration · minor.
6. **If the routine tick throws, the chain pass does not run that cycle** — orchestration · minor. `runCycle` shares one `try`.
7. **The database's name rule and the form's can disagree on non-ASCII names** — data · minor. On an owned cluster (`--no-locale`) `lower('ÄRZT') = lower('ärzt')` is false; JS `toLowerCase` says equal.
