# Iteration 2 — errors, failure behaviour and boundaries

Independent reviewer, 2026-10-03, against `0ca25630..57f4080c`; probes in temp folders, nothing on the live ports. Kept as written.

## Findings, most severe first

1. **Scanning or adding a repository still runs a program named in that repository's own git config** — boundary · blocking. A partial clone (`extensions.partialClone=origin`, `remote.origin.promisor=true`, `remote.origin.uploadpack=<script>`, HEAD at a missing commit): `inspectFolder`'s `git log -1` ran the script 5 times; `gitRun status` (the repo-state watcher) 3 times. `GIT_NO_LAZY_FETCH=1` / `--no-lazy-fetch` stops it (git 2.55). `projectDiscovery.ts` keeps its own hardening copy, which `gitRun.ts`'s header forbids. Fix: lazy fetch off and `protocol.allow=never` in gitRun; fold `SAFE_GIT`/`SAFE_ENV` into gitRun; plant this repository for both callers.
2. **The renderer can make any folder reachable from every window, with no picker** — boundary · blocking. `projects.create` (index.ts:913-920) checks absolute/exists/directory, then `refreshFileRoots()` puts the path in `FileRoots.repos` for every window; `repos.attach` (index.ts:3470) the same. `projects.create({repoPaths:['/']})` opens the disk to the files API and `createFolder`. Fix: resolve each path through the window's roots or the candidates main recorded for its scan; same for `repos.attach`; tests.
3. **"No repositories were found" while repositories were skipped for depth** — scenario/error · major. A repository at depth 5 gives `candidates: [], deep: 1`; `deep` is never rendered.
4. **A hung filesystem can still hang the scan and freeze the main process** — error · major (from reading). Untimed `lstat`; synchronous `existsSync` in the walk and `inspectFolder`; a timed-out `readdir` keeps a libuv thread; deadline and Stop checked only between folders; the renderer leaves "scanning" only when the IPC returns.
5. **`CreatedAgents` never leaves "reading" under React StrictMode** — UI · major (dev builds). The cleanup sets `alive.current = false` and nothing resets it; the walk never reaches the form.
6. **The test-stack guard can be bypassed into the live database** — harness · minor. `?port=54322` and `?host=` in the URL; a URL with no port (pg falls back to `PGPORT`).
7. **`with-timeout` reports every non-KILL signal as 143** — minor. Fix `128 + os.constants.signals[signal]`.
8. **Coding-agent detection misreads versions and stops early** — minor. "update available 3.4.5" taken as the version; >64 KiB with no version yields garbage; a background child holding stdout makes it `unresponsive`; children left after a normal exit; nvm/volta Codex not on the Dock PATH.
9. **New-folder failures are reported without their real reason** — minor. Concurrent EEXIST → raw `failed`; a git-init timeout not named; `outside` detail English in the RU window ("that file is outside…").
10. **Raw error text and swallowed failures** — minor. `FirstRun.tsx:73,131`, `Onboarding.tsx:85` use `e.message`; `lastScan` failures dropped (`StartPaths.tsx:125, 268`).
11. **A repository whose `.git` is a symlink is listed as a plain folder** — minor.
