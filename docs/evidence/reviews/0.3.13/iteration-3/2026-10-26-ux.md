## Not findings

- The notifier's Russian burst «Вас ждут дела: {count}» avoids plural forms and is correct for every count; Copylot passes it (`aa42d931…`). The burst's title stays «Fabric» even when every row is from one project; that is a refinement, not a false statement.
- «Отменено действием» followed by «более поздним действием, которого нет в этом списке» repeats «действием», and Copylot calls «Отменено действием» an agentive passive (advisory). It reads as one phrase and says who undid it; iteration 2 kept it on purpose (V2-6).
- The «Консоль» tab says «Этот агент работает вне Fabric» while the joined agents are still being read (`hub.read.at === 'reading'`, `AgentsScreen.tsx:383`), and of a `quiet` row listed under «Простаивают». Both are about where its console is, which is true in both cases; once the hub answers, a joined agent gets «работает в терминале».
- Folder trust: a failed read of the environment lock keeps the person's switch (`SettingsScreen.tsx`, `useRead` of `folderTrustLocked`); SCN-170's iteration 1 amendment (`scenarios.md:4250`) says exactly this. Under the lock the box is off, disabled and explained (`settings.folderTrustLocked`, `ru.ts:298`).
- The agent page's header under a failed `work.home` says «Отзывался N назад», dated by the console's last output (`AgentsScreen.tsx:117`, `lastActivityAt` is non-null in `shared/types.ts:639`): an observed fact about the console, not about the agent's work.
- Code comments still name the group «Ждут вас» (`AgentsScreen.tsx:4`, `agentRoster.ts:4`); no person reads them, and the screen and CHANGELOG say «Возможно, ждут вас».
- Strings: en and ru hold the same 2830 keys; `check-design.mjs` passes; no em dash added since v0.3.12.
- Not verified here: layout and contrast in a real window, a real macOS notification, the heal on a real engine restart.

## Summary

5 new findings, 0 blocking: 2 major (UX-1, UX-2), 3 minor (UX-3, UX-4, UX-5). Every iteration 2 UX fix (V2-1 to V2-7) holds in the case it was written for, with tests passing and probes showing the new words in ru and en. What remains: История's agents list calls a filtered-out journal empty (UX-1, a state 0.3.13's filters made reachable); Агенты' row still says «has not said what it is doing» when that was not read, beside a page that now says so (UX-2); the scenarios and screens were not amended for iteration 2's changes (UX-3); the heal's own stop failure on Docker is not waited for (UX-4); the splash is silent during the heal (UX-5).
