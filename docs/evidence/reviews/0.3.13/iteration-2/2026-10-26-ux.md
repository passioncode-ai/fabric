## Not findings

- The «Брошено» rows with no title read as «Запрос из другого проекта», «Ответ из другого проекта», «Задача, которую не удалось прочитать» on every screen that lists the board, since each uses `titleOf` and `board.ts` keeps `swept` on the entry (`shared/board.ts` `...(a.swept ? { swept: a.swept } : {})`). The project a request finding sits under is the target for an unmoved request and the requester for an unread answer (`abandonedSweep.ts` `findAbandoned`), so «из другого проекта» is true in both. Two such requests in one project read the same and both open the project; that is the chosen fix, not a false statement.
- `joined.outUnreadable` («…поэтому сейчас никто не отключён») with «Отключены 0 Ни один агент не отключён.» is consistent: an unreadable list keeps nobody out (`access.ts:748`, fail-open).
- «Кто» and «Проект» narrowing «Что делали агенты» while «Что» and «Поиск» do not is what SCN-168's 2026-10-26 amendment says.
- Strings: en and ru hold the same 2825 keys; `check-design.mjs` passes; no em dash added; Copylot finds nothing blocking in the new ru strings.
- `agentsPlace.groupUnread` («выше произошла ошибка чтения») could stand with nothing failed above it only if the catalogue IPC itself rejected; `readMachineAgentCatalog` answers every failure as a value (`agentCatalog.ts:98-116`), so I did not count it.
- Not verified here: layout and contrast in a real window, the macOS notification as shown, the half-up window on a real engine restart.

## Summary

7 findings: 0 blocking, 3 major (UX-1, UX-2, UX-3), 4 minor (UX-4, UX-5, UX-6, UX-7). Every iteration 1 UX fix holds in the case it was written for (V1-1 to V1-12 and the three that repeat them). What is left sits beside those fixes: the failed heal's window still says the stack runs after Fabric stopped it and does not wait on a Docker refusal (UX-1); the notifier's burst is still English (UX-2); a failed first read of who works is said on the agent page as «no task» (UX-3); and three wordings in Агенты, История and CHANGELOG that the fixes left behind.
