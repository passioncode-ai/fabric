## Not findings

- The 0.3.12 UX findings on Агенты are answered: the pick sentence no longer shows when there is nothing to pick (`AgentsScreen.tsx:214-221`, the 0.3.12 UX-3 case); picking an agent moves focus to its page title and scrolls it into view (`focusPage`; probe `agents-idle-shell-focus-ru`: `agent-page-title`), the 0.3.12 UX-7 case; the agent rows are buttons with `color: var(--app-ink)` set (`launch.css` `.ag-row`), so they do not repeat the 0.3.12 graph-node contrast defect.
- Strings: en and ru hold the same 2817 keys; `check-design.mjs` passes; no em dash in any added string.
- Settings: the five sections are in SCN-170's order, each a `role="group"` labelled by its `h3`, the panels' headings are `h4` under the page's `h2`; «Сохранено» is shown only after a write that saved and cleared on the next change (`SettingsScreen.tsx` `change`, `Saved`); a refused write still goes to the pinned foot; usage counts say «Сохранено» only when the shared switch holds what was asked.
- История: each filter goes into `acts.history` and «Ничего не найдено.» with «Сбросить фильтры» replaces «История пуста» under filters (`HistoryScreen.tsx:168-174`); the filters survive leaving and returning within the window (`sessionStorage`); a remembered project that is no longer listed stays a visible choice; the pane opens on the sentence and closes on «Закрыть» or the sentence again, with `aria-expanded` and `aria-controls`.
- «На проверке»: each finding is its own row and its own notification key, and its reason is said in the interface language (`attentionTitle.ts#detailOf`); a request finding opens its project, not a page that does not exist.
- «Вы · освободили задачу» and Fabric's release read correctly in ru and en (tests in `HistoryScreen.test.tsx`).
- Not verified here: layout and contrast in a real browser (no browser run in this review); the notifier's actual system notification on macOS; the half-up stack window on a real engine restart.
