What holds:
- **Privacy.** The packet ref is still one ISO time; no new field, path or text travels to Observatory; `toISOString` gives three fraction digits, which `dispatch_packet.py`'s `_UTC` shape (`\.\d{1,6}`) accepts, and an uncut value is the board's own `...SSZ`.
- **Within 0.3.18 the packet is stable.** `packetDeadline` depends only on the stored `m.at` and the request's deadline, so the first write, `-ends-held` and the take-back `-ends` of a workflow 0.3.18 opened carry the same string, and `closeWorkflow` writes no artifacts (`check_write` keeps the packet). A request 0.3.17 could not open (deadline past write plus seven days) had no workflow, so CO-554 creates no cross-version mismatch for those.
- **The dispatcher's own decisions** (`candidate`, `runEndsAt`, the record's `until`, ER-7's past-deadline rule) still read the board's deadline, as the CO-554 row and the spec say.
