What holds:
- **Restart notes.** `restart-window` (`restartFabric.ts#askRestartWindow`): written with `writeFileSync`, mode 0600, one millisecond timestamp, overwritten (never appended) by each launchd-path restart; read and removed once by the next start that wins the lock (`applyLoginItem(..., true)` is the first statement after `if (!isPrimary) return`, `index.ts:5927-5929`); honoured for 120 s; unparsable content reads as none and is still removed. `restart-outcome` (`shared/loginItem.ts#restartPlan`): appended by the helper shell (`>>`) with the process umask (0644 in practice), holding only `waited`, `kickstart <rc>`, `open <rc>`, at most three lines per restart; read and removed by the same first statement; the losing copy never reads either. The data folder is `drwx------`, so the 0644 file is readable by no one else. Neither file piles up: one is overwritten, the other is emptied by the next start; a note whose removal fails is said again, never grows unless another restart is refused. After a rollback to 0.3.17 both are unknown files of a few bytes, ignored. The helper's argv holds a pid, the note's path, the job label and the bundle id; its environment is Fabric's, which carries no secret (`main/env.ts:42` writes only `PATH`).
- **`XPC_SERVICE_NAME`.** Read and removed at `index.ts:472`, the first statement after the imports, before `fixPath` (`:1023`) and every spawn; no module snapshots `process.env` at import (`grep '...process.env'` in `main/`: all at call time). The only reader in the tree is `shared/loginItem.ts#launchdStarted`; `serviceRunsUnderLaunchd` reads macOS's status, not the environment; `ownsBoardService` reads argv and `SMOKE`. A label that is not the board's is left as it is (Finder starts keep `application.<id>...`). The value is recorded nowhere: `startRecord` carries version, atLogin and background only. Children of launchd's copy now have no `XPC_SERVICE_NAME`, as a terminal start's do.
- **New log lines since 0.3.17** carry no private data: `app.quit-signal` {signal}; `app.quit-held` fixed note; `app.restart` {via, live} or {cancelled, live}; `app.restart-window` fixed error; `app.restart-helper` a spawn error of `/bin/sh`; `app.restart-kickstart` the note's fixed tokens; `app.login-item` {enabled, system, legacyKept}; `app.login-item-legacy` the system's error; `work.sweep-review-default` a task id and the store's error; `work.session-sources-unread` the store's error; `editor.recovery-sweep` existed in 0.3.17 (moved, same text). All pass `shared/opsLog.ts`'s redaction.
