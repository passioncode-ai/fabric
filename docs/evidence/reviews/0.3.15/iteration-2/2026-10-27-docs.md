### DO-6 (non-blocking): the rhythm reading's trigger is listed incompletely

- What is wrong: the `AGENTS.md` row «The home's rhythm reading» says «`work.rhythm` asked when a `work`, `task`, `agent` or `session` mark moves». The code asks on more.
- Evidence: `apps/desktop/src/renderer/src/EstateHome.tsx` line 210: `useRhythm(markOf(marks, ['work', 'task', 'agent', 'session', 'question', 'proposal', 'access', 'policy', 'grant']))`. The decisions the chart counts (`DECISION_TYPES`) are the reason for the extra families, so a reader of the row would not expect a question or a grant to refresh the chart. The 60 s tick, the 15 s main throttle and the one-in-flight rule in the same row are true.
- Fix: write the nine families in the row (or name the constant), or narrow the call to what the row says.
