## Checked and sound
- The console's one bar: the top bar names the session («Сессия · {project} · {runner}», «с {at}» only when two tabs share project and coding agent, `consoles.tsx#startClocks`, `App.tsx` title, `ConsoleTabs.tsx`); the bar holds state, a shortened folder with the full path on hover (`shortFolder`), «Завершить сессию» with its tooltip «Агент остановится. Его вывод и история задачи останутся.» (consistent ru/en), «Новая сессия» once ended, with its own failure line «Новая сессия не запустилась.» plus the machine's words; no confirmation, as ADR-0160 records. The removed back link leaves the rail's agent row and history travel as routes back.
- `fabric_session_observe` verdict: the description and `turnVerdict` reason tell the agent what to do (go on with the named task, or release with a wait, or release done); no verdict on a declared wait, on a closed or lapsed claim, or after two quiet turns; a failed read gives no verdict and is logged (`turnVerdictRead.ts`).
- `fabric_work_release` `wait`: refusals say exactly what is missing («time and limit need until; question, grant and request need ref»; «a done release waits for nothing ...»).
- `fabric_question_ask`: the `text` describe states the whole rule (240 characters, ending with ?, no ids), and the refusal `question-unclear` says how to ask instead and when not to ask at all.
- The resume packet (`boardDispatchRun.ts` `resumeBody`) tells the run why it was started, to claim first, to read the handoff and the Observatory workflow, and how to end; `waitLine` says what cleared.
- `task-to-operator`: «Сессия оставила задачу недоделанной, а три запуска её так и не продолжили. Задача ждёт вашего решения» / the en twin; untitled rows fall back to `attention.untitled.task`; not agent-only, so it reaches «На проверке».
- Board capabilities in words: `sayBoardCapability`/`sayBoardRequests` feed the access ask lines, the consent prompt, Comms' responder and unknown-outcome lines, a message's request target and a direction's title; an unknown capability reads «запросы вида «x»» / "requests of the kind “x”", never bare; ru grammar checked against `access.ask.respond`, `launch.comms.responder.absent`, `launch.comms.unknown.*`.
- История: an agent's act without a repeated subject (`acts.did.*`, 16 keys in both languages, used only for agent actors), «Отменить нельзя» instead of a doubled reason, stage names matching the board's («На проверке» / "In review").
- Agent access: «Агент без имени» / "An unnamed agent" with the id said once as where it registered; dates in words; a request leads with who and until when, the reason as its own line, «Что изменится после ответа» folds the rest.
- Comms: plural counts in both languages, a thread without a subject named by its first line without Markdown marks, «Все сообщения проектам прочитаны.», sender by `runnerLabel`, redacted message ids moved to the tooltip, dates by `whenSaid`.
- Settings: «Продолжать начатую работу без меня» is disabled while board starts are off and its help says so; «Присылать вопросы в Telegram через агента организации» says what goes, to whom, and that it applies only where the organization's agent takes such questions; «Чей это компьютер» with its three hints.
- Главная: an access request, a refused act and a proposal are decided on the card; a refused act is asked as its question with the target on its own line; «Нужны вы» is hidden only when the read succeeded and nothing waits.
- `say.read` «прочитано {when} назад» composes with `since` («5 мин»); the sent time is added with `board.ago`.
- No em dash and no new machine id in interface strings (`check-design.mjs`); en and ru keys at parity.
