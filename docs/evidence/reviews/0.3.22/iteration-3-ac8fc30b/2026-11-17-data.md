## Checked and sound
- Schema: no migration; every column the new reads name exists at schema 102 (`work_claims.released_how` and
  `released_at`, `questions.asked_command_id`, `chosen_option`, `answer`, `status` in `open|answered|withdrawn|stale`,
  `access_requests.status`, `session_heartbeats.phase`); `work.released@1` `wait` and `work.claimed@1` `workflow_id`
  / `resumed_from` ride existing types whose projector reads only its own fields (`apply_work_claims`), so 0.3.21 reads
  them unchanged; the hand-back's `work.claimed@1` by the system `session-resume` stands only where the lease is the new
  session's (the projector's own check), and is read back before the task is moved.
- Remote questions: filed as `question.asked@1` with `command_id` from a stable hash of the dispatch key, found again
  by `asked_command_id` before any append, texts through `cleanOriginalText`, the clarity rule applied; a refusal is
  retried under the same key and ends the run as before after `CLOSE_ATTEMPTS`.
- `board-dispatches.json`: `waiting`, `resume`, `question*` fields validate in `isDispatchRecord`; written whole,
  fsynced, renamed; a resume record's id is a task id and never meets a request's. 0.3.21 drops a `waiting` record as
  `records-unread` and starts the request again without the answer, and keeps a resume record as a request record that
  no board read names, so it starts nothing for it; both said in the runbook's 0.3.22 paragraph.
- Reads bounded: releases 500 (said as `capped`), chunks of 100 under the gateway's 1000, the verdict's 20 claims and 3
  turns, the hand-back's 200 sessions, people-ask 500 items and 5 pages per thread; `resume-since.json` begins once per
  process and a failed write is said once.
- Person-ended releases: `releaseSessionClaims` writes `how: operator` with the person as actor only for a marked
  session that ended (`why === 'ended'`), never at app quit; `operator` is outside `RESUME_HOWS` and `HANDBACK_HOWS`.
- Switchboard holds: in memory, capped at the newest claim, seven days and now an hour past the session's last work
  call (`lastWorkAt`, set only for work calls, `agentSurface.ts:1078`); released at a session's end and, through the
  next renewal, once idle.
- `bugs.json`: 200 rows, 30 days, 0600, written by rename; templates strip URLs, e-mails, ids, paths, quoted text and
  token-shaped strings before storage.
