# Fabric 0.3.25 release review, iteration 3: ux

Level ux, candidate 6da674bdc092ed36a34521198dd0f5d472d0d531, baseline 53e8c3e2, reviewer model anthropic/claude-sonnet-5.5, read-only.

## Verdict

No blocking findings. I did not run the code, the tests or the built app.

**Previous report:**
- UX-19 is fixed. The summary now has `list-style: none` plus a `::before` chevron that flips on `[open]`.
- UX-20 is fixed in code. `showLive` is now `call.active || call.phase === 'failed'`, so an ended call no longer leaves a live block with the voice switch. The fix has a cost, which I raise as UX-22.
- UX-21 is half fixed. `.ceo-call-hangup` is gone from the CSS and from the registry class list. The listen button's name is still built in code, and `listenTo` is rightly carried in CO-601 item 7. The `getAllByRole(...)[0]` in the test remains; in the stopped state only the body's «Запустить» exists, so it is harmless.

**Fresh review:** the popup head, call panel, floating button, voice picker, stop/start states, ru/en strings, roles and reduced-motion branches match the CHANGELOG and SCN-182/184/186/187 as far as the diff shows. Three new non-blocking findings follow. The first is UX-22, where the ledger and the code disagree.

## Checked and fine

**Previous report**
- **UX-19.** The disclosure cue exists in CSS (`▸`/`▾`), so a mouse user sees that a row opens. Native `details` and `summary` keep keyboard and screen-reader behaviour.
- **UX-20.** An ended call no longer keeps the switch or the live block, and `reset()` is only needed for the key form.
- **UX-21(a).** The dead hang-up class is out of the CSS and the registry.
- **The earlier fixes hold.** There is one hang-up (the head's `CallButton`), and the test asserts there is no second one. A stopped CEO has a single Start, in the body. `hintNoKey` shows only when `canSample === false`. `CallPanel` returns null with no live call and no history. The set-aside time uses the app's locale.

**Strings and wording**
- I found no em dash in the new ru/en strings, the three new CHANGELOG bullets, SCN-182/184/186/187, CO-601, the ADR amendment or the `sampleText` strings. The test asserts the sample texts have none.
- ru/en parity holds for every new key (`problem.*`, `call.*`, `voice.*`, `stop*`, `start`, `restartShort`). `status.problem` maps to all four `problem.*` keys, so the raw code is no longer shown on the failed banner.
- The five tone strings match `PERSONA_VOICES`. For orbit, male is rex ("уверенный и чёткий") and female is eve ("энергичный и бодрый"), as SCN-186 step 1 says.

**States and copy**
- Connecting, listening, speaking, ended and failed each have a label, a meter colour and a panel border. The hints differ for connecting and listening.
- The head shows Stop for running and starting, Start for ended and idle, and only Call for stopped. Restart hides while stopped. Failed shows Restart in the head and «Попробовать снова» in the body.
- The stop-failed message, the stopping and restarting labels, and the stopped sentence all exist in both languages. SCN-187 steps 1 to 3 match `stop`, `send` and `restart('person')`: a message starts it on the first agent not set aside, and «Запустить» clears the set-aside list.
- The floating button carries the CEO state in its accessible name, so the ring colour is not the only cue.

**Keyboard and roles**
- The voice options are native radios in labels with one `name`, inside a labelled `radiogroup`. Focus rings are defined for the radios, the listen buttons and the floating button.
- The listen button's name follows its state («Послушать: Женский», «Стоп: Женский») and contains its visible text.
- The call section has an `aria-label`. The typed-words input has an `aria-label`. The lines list is `aria-live="polite"`. The meter and icons are `aria-hidden`. The state label is `role="status"` on the sentence only.
- The Stop/Start swap on the head keeps a stable button. `main` and `header` landmarks are used in the popup.

**Reduced motion**
- `ceo-breathe` and `ceo-connect` are inside `@media (prefers-reduced-motion: no-preference)`. The live meter checks `matchMedia` and clears its bars. The resting bars keep their CSS shape, so the phase colour alone says the state, as SCN-184 states.

**Claims versus code**
- CHANGELOG items hold: head controls, meter, state, time, price, who said what, «Сказать текстом», the voice switch, ten kept calls, the home card's «Позвонить» opening the window and starting the call there (`CallLauncher`, `takeCall`), male default, the character-to-voice mapping, the sample cost and caching, and the stop details. The "says why" claim is the exception (UX-22).
- SCN-184 coverage symbols exist: `useVoiceCall`, `CallPanel`, `VoiceMeter`, `CallLauncher`, `readKept`. SCN-186/187 coverage symbols exist in the files shown.

**Could not check**
- The built app, the tests, the CSS cascade and the token values, including `--state-*` and `--app-focus` contrast.
- Whether `ceoAgent.floating`, `ceoAgent.state.idle` and `ceoAgent.state.starting` read well, and whether the button's visible "CEO" is contained in the accessible name.
- The head layout at narrow widths with English buttons.
- Whether `PersonaScreen` keeps `voice` when a variant is picked (SCN-186 step 4). The diff shows only the save path.
- The «Завершить сессию» label named in SCN-187.
- Whether a voice-tool request during a stopped CEO revives it, against the notice "will not start by itself".
- Whether the `Banner` for the stop-failed message announces itself to screen readers.
