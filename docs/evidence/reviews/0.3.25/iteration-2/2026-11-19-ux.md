# Fabric 0.3.25 release review, iteration 2: ux

Level ux, candidate 938f4b16e3a2adcb94f6ab6570ed66e81a56c79a, baseline 53e8c3e2, reviewer model anthropic/claude-sonnet-5.5, read-only.

## Verdict

No blocking findings. Of the twelve findings from iteration 1, nine are fixed in the code shown, two are rightly carried to CO-601 (UX-7, UX-8), and one (UX-6, the CSS tokens) is neither fixed nor carried. The CEO popup, call panel, button, voice picker and stop/start now match the CHANGELOG and SCN-184/186/187 as far as the diff shows. Six new non-blocking findings are listed, mostly small clutter and leftovers, plus one scenario that may be stale. I did not run the code, the tests or the built app. Everything comes from the diff and the full files shown.

## Checked and fixed from iteration 1

- **UX-1 fixed.** `role="status"` is now on the state label only. Time, price and the hang-up button are outside it (`CeoCall.tsx#CallPanel`).
- **UX-2 fixed.** The «Послушать» label follows the state (`${t(word)}: ${voiceName(g)}`). The test expects «Стоп: Женский». The related leftover is UX-16.
- **UX-3 fixed.** The options are native `<input type="radio">` in labels with a shared `name`, so there is one tab stop and arrow keys work.
- **UX-4 fixed.** The call history is in `localStorage`, ten kept, and `readKept` validates each record. SCN-184 step 5 and the CHANGELOG now say it is there the next time the window opens. That relies on the CEO window using a persistent storage partition, which I could not confirm.
- **UX-5 mostly fixed.** The head now shows Start only when stopped. Stop shows only for running or starting. Restart shows only when not stopped. The double Start in the stopped body is UX-14.
- **UX-7 rightly carried.** It is in CO-601 item 1. The popup head also states the state in text, so only the floating button depends on colour, and its accessible name carries the state.
- **UX-8 rightly carried.** It is in CO-601 item 2.
- **UX-9 fixed.** `personStopEnded` is called after both other doors' stops (`index.ts`, History's act and `terminal.end`). The unit test is `ER-6`.
- **UX-10 fixed.** `CEO_USES` now includes `ceoAgentStop` and `ceoAgentTakeCall`. `ceoAgentVoiceReady` and `ceoAgentVoiceSample` are `MAIN_ONLY` and used only by the main window's picker.
- **UX-11 fixed for the call history.** It uses `useLocale()`. UX-18 is the remaining instance.
- **UX-12 fixed.** «Остановить» is no longer disabled while starting. `start()` stops what it opened when `held`, and `stop()` awaits `starting` and `pendingFallback`. The test is `ER-1 (0.3.25)`.

## Checked and fine

- **Em dash:** none in the new ru and en strings, the CHANGELOG entries, SCN-186/187 and the SCN-184 edits, the ADR amendment, or the external-contracts section. The test asserts `sampleText` has none. The only U+2014 characters in the diff are in untouched, pre-existing backlog prose, which is not person-facing.
- **ru/en parity:** every new key is in both files: `problem.*`, the `call.*` set, `voice.*` including the five tones and three `sampleFailed.*`, `state.stopped`, `stop`, `stopping`, `start`, `stopped`, `stopFailed` and `restartShort`. The five tone keys match the five voices in `PERSONA_VOICES`. The raw problem code the failed banner showed in 0.3.24 is now worded.
- **States:**
  - Connecting, listening, speaking, failed and ended each have a label, a meter colour and a panel border. `ended` is shown through the kept call.
  - The stopped, stop-failed and still-running states have wording and tests.
  - A refused or missing key offers the key form, and `reset` returns the panel to idle.
  - The head and the floating button carry `starting`, `running`, `stopped`, `ended`, `idle` and `failed` in text, through the state label and the accessible name.
- **Stop and start in the UI:**
  - The same button node swaps between Stop and Start, so focus survives.
  - The notice text matches what the code does. A message starts a stopped CEO, and Start clears set-aside runners (`restart('person')`).
  - A failed stop says so and can be pressed again.
- **Call from the home card:** `takeCall` is taken once, and the broadcast reaches an open window. A closed window clears the ask (`ceoCallWanted = false` on close). `start()` ignores a second start while a call is active. `autoplayPolicy: 'no-user-gesture-required'` matches the CHANGELOG.
- **Reduced motion in CSS:**
  - The starting ring (`ceo-breathe`) and the connecting meter (`ceo-connect`) are inside `@media (prefers-reduced-motion: no-preference)`, with matching first and last frames.
  - The live meter checks `matchMedia` and resets the bars when reduced.
  - Under reduced motion the phase colour carries the state, as SCN-184 says.
- **Keyboard and roles:**
  - Native radios, native `<details>` and `<summary>` for past calls, a labelled call section and a labelled «Сказать текстом» input.
  - A checkbox for the voice switch, with explicit focus rings on the floating button and the voice controls.
  - `aria-live="polite"` on the live lines. The meter and icons are `aria-hidden`, and the avatar on the floating button is decorative.
- **Voice picker and sample:** an unknown voice id is refused before any request. The key is used only inside the main-process request. A failed sample never blocks saving the choice. The first run shows the picker only when `voiceReady` is true, and `PersonaScreen` and `FirstRun` now save `voice`.
- **Claims versus code:**
  - The CHANGELOG items hold, including male default, the orbit/spark/wave mapping, legacy looks read as male, the last ten calls kept, and the stop details.
  - SCN-186 and SCN-187 steps match the code. `ceo.agent.held` and `ceo.agent.stopped` are both recorded.
  - ADR amendment 2 matches `persona.ts`, `ceoVoice.ts` and `ceoAgent.ts`. The ceoTools refusal now says "stops or restarts".
  - The component registry lists the new classes and components.
