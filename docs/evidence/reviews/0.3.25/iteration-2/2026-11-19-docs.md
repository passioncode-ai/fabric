# Fabric 0.3.25 release review, iteration 2: docs

Level docs, candidate 938f4b16e3a2adcb94f6ab6570ed66e81a56c79a, baseline 53e8c3e2, reviewer model anthropic/claude-sonnet-5.5, read-only.

## Verdict

No blocking findings. All four iteration 1 findings (DO-1 to DO-4) are fixed in the candidate. Reading the changed documentation afresh against the CEO files shown in full and the diff, I found no shipped claim that I can show is false and no citation to a missing symbol. No em dash appears in the added prose, strings or sample texts. There are four new non-blocking drifts. One is a possible stale SCN-182, which I could not confirm either way.

Iteration 1 findings:
- **DO-1, fixed.** The `ceoAgent.ts` header now says «Перезапустить» and describes the person's stop and the hold (ADR-0197 amendment 2).
- **DO-2, fixed.** SCN-187 step 3 now separates «Запустить» (first agent of the order, set-aside agents come back) from a message (first agent not set aside). This matches `restart('person')` clearing `setAside` and `send` clearing only `held`.
- **DO-3, fixed.** The `CeoButton.tsx` header now reads "The ring's colour is the state signal; only the starting ring moves (it breathes), and it holds still under reduced motion", which matches the CSS.
- **DO-4, fixed.** The SCN-184 Coverage now keeps the symbols together and moves `CeoPopup.test.tsx` into the `tests` clause. The Design rationale now carries the owner's ask for a panel in the chat.
