Notes that are not findings:

- Strings: en and ru carry the same 2506 keys (`check-design.mjs`); no U+2014 or spaced hyphen in any new string, tool description or CHANGELOG line. Latin in the new Russian strings is limited to product names (Fabric, Docker, OrbStack, Docker Desktop), as in the existing `startup.diskLow`; «Открыть переписку» matches the existing Comms button. The `CONTEXT.md` entries use the glossary's existing em-dash shape: left to the docs level.
- The notice is mounted once in `Shell` (`App.tsx` `<StackHealthNotice />`), above every screen including the console and the first run; it shows nothing while the stack is up and the disk has room, and the low-disk-only case is a warning tone. The free space goes through `freeDiskGb(…, locale)`, so «2,1 ГБ» in Russian (the 0.3.8 UX-2 rule holds).
- The wait window's flow matches SCN-161's amendment: a background start shows it only on activation (`activate`, `second-instance`), the splash does not stack on it, a try in progress says «Пробуем сейчас (попытка N)», the disk line uses the per-OS `diskLowLine`, and the failure window remains for causes that will not heal.
- `com.list` `unread`/`since`, the `read` flag and the bulk `com.read_ack` are described accurately against `board_list_reader` and `board_read_ack_many` (own messages count as read; `since` is "at or after", as the SQL `m.at >= p_since`). The `noResponder` message is accurate. `fabric_agents_list` now marks the caller (`is_you`) and how each session came in, which makes its "The other sessions" wording loose but not misleading.
- SCN-140 (claim to running, done through running to review) and SCN-141 (rename after `/clear`, stale end, agents list, current leases) match `workTools.ts#moveClaimedTaskToRunning`, `#moveDoneTaskToReview`, `#endRefusal` and `agentSurface.ts` `agents-list-every-session`. SCN-141's amendment stands after its `Product:` line and a blank line, unlike its neighbours; `docs/ux/lint.py` accepts it.
- The `answered` state reads «получен ответ» / "answered by a reply" in the request's pill and timeline; such a request keeps the "No agent answers … now" responder line, which stays true.
