## Verdict
**Not ready. 2 blocking findings, 5 non-blocking.**

What works:
- **Rollback zip format.** The zip is now written before the swap with `ditto -c -k --sequesterRsrc --keepParent <target>/Contents`. Its layout is the same as 0.3.27's zip. I archived a scratch bundle both ways and both zips have `Contents/` at the root. The documented restore (`mkdir -p /tmp/back/Fabric.app && ditto -x -k <zip> /tmp/back/Fabric.app`) gives back `Fabric.app/Contents/Info.plist` and `Contents/MacOS/Fabric`.
- **Zip location.** Unchanged: `~/Library/Application Support/ai.passioncode.fabric/previous/Fabric-<version>.zip` (`scripts/lib/install-mac-update.mjs#rollbackZip`).
- **Routes file temp cleanup.** `setPeopleChoice` now removes its temp file on any failure and rethrows (`boardCycle.ts`, ER-20/DA-13). The routes-unread skip is in place.
- **Schema 104 migration.** Not touched since iteration 2. The blob is `8ca9da3f` at both 618551f7 and 666d0fdd. Its sha256 `29b5abd9…` matches `supabase/migration-ledger.json` and `origin/main`.
- **CO-622 model and effort.** The model name is checked by `launchModel.ts#MODEL_NAME`, so nothing can be injected into argv or `/model`. The model and effort are not stored anywhere. Only `ceo.session.model` writes the model name to the ops log.
- **Ops log and account names.** The ops log carries only the account id, never a label (`ceoTools.ts:741`, and `ceo.tool.start` records only outcome and via).
- **check-private.** `node scripts/check-private.mjs` gives "PASS: no private data in the tracked files", exit 0. A scan of the new docs found no mail address, home path or private organization name.
- **Tests.** Every changed surface's single test file is green: install-mac-update 11/11, ceo-access 8/8, launch-model 2/2, voice-board 11/11, ceo-agent 88/88, people-ask-run 26/26, quit 25/25.

Blocking:
- **DA-16.** Mail addresses still reach the voice (xAI) and its call journal. The `session_start` refusals carry whole Switchboard account labels, so iteration 2's DA-7 fix is incomplete.
- **DA-17.** CHANGELOG and the release ledger say CO-622 is not in 0.3.28 ("the next release"). The candidate ships CO-622 items 1, 2 and 5, including new tools that read session transcripts out to the voice.
