## Verdict
**Ready. 0 blocking findings, 6 non-blocking.**

What works:
- **The routes file on upgrade.** On a machine that already has `people-ask-routes.json`, every route is still read after the upgrade. In 0.3.27, `routesOf` used the file's own list whenever a file existed and never merged in the defaults. So emptying `DEFAULT_PEOPLE_ROUTES` changes nothing for such a machine. On this machine the file is 0600, holds 3 routes, and still includes the former built-in PassionCode.ai route. That was checked by shape only; no names were printed.
- **Writing a choice from Settings.** `withChoice` keeps every other key (`routes`, unknown keys) as it was. It refuses a target that is not a UUID, and a project that points at itself. The write is whole, fsynced and renamed into place.
- **The people-ask switch.** It stays on by default (`appSettings.ts#validateSettings` `peopleAsk: raw.peopleAsk !== false`, `types.ts` defaults `peopleAsk: true`). A fresh install routes nothing until a route, a choice or a live PM responder exists.
- **Memory's id-prefix filter.** It matches the ids the index actually writes. `estateSources.ts#projectBatch`, `#taskBatch` and `#boardBatch` write `project:`, `task:` and `message:`. A source's ids must pass `readSourceFile` `own`, which allows lowercase prefixes only and excludes `project|task|message|…`. So SQLite's case-insensitive `LIKE` cannot let a source node through.
- **The operator door's files.** The token and `board-door.json` are written through `hub.ts#writeAtomic` (`wx`, 0600, chmod, fsync), token first. They are withdrawn only while the document names this pid. Nothing in `apps/desktop/src` imports `operatorDoor.ts` yet.
- **Private data in the build.** `node scripts/check-build-private.mjs <release worktree>/apps/desktop/out` (the build at the same HEAD) printed: "none of 21 value(s) from this machine's settings is in the build" and "PASS". The old PassionCode.ai route id and the agent name are no longer in the bundle. The only "Kira…" text left is "Kiran" in supabase-js doc comments.
- **Tests run (all green):**

  - `scripts/test/check-build-private.test.mjs` 3/3 when run from the repository root
