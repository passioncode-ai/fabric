## Not findings

- **Unmount during a read:** the late answer is dropped by `mounted` (`CommsFeed.tsx:48`, `52`); a remount (switching «Ветки» and back) is a new instance with new refs and reads at once.
- **Mode switches in Comms:** each switch re-runs both read effects; the old interval is cleared and an answer for the old run is dropped by `alive` (`CommsScreen.tsx:211-215`, `235-237`).
- **A board whose page says `more` but does not advance its cursor:** the window ends (`commsNewest.ts:33`), so no endless loop; the board's RPC returns the last message's number as `last_seq` (`commsOperatorRead.ts:537`), so this needs a broken board.
- **`after === 0` with a too-wide window:** bisection continues (`commsNewest.ts:36-37`), it does not stop on the first page.
- **The `recovered` settings status:** the last-good copy is written with the same bytes after every committed write (`main/localState.ts:256-259`), so it is the last saved state, not one from before a switch-off.
- **The arrival focus effect without deps:** guarded by `arrived` and by the row being chosen (`BoardScreen.tsx:163-170`); it runs once, and a row that never arrives costs one comparison per render.
- **The kanban's `?` and the home's «Закончили» `?`:** correct on the candidate; only untested (ER-7).
- **`HomeWork` `bare` Doing and the Агенты heading:** an empty summary falls back to the action; the hidden h2 has keys in both locales (`i18n/en.ts:182`, `i18n/ru.ts:1617`).
- **`Feed.tsx` no-project text:** `launch.home.agents.noProject` exists in both locales («без проекта», «no project»).
- **Feed poll cadence:** 21 reads in 20 ticks with nothing pending (probe P).
