## Not findings

- **CO-389 statement timeout.** `startupHeals` adds the PostgreSQL message for the `unknown` and `stack-would-not-start` causes only; the retry is gated by `!pastRetryPoint` (`main/index.ts` startup catch), so nothing after the hub and IPC registration is repeated. `textOf` reads a plain PostgREST object's `message`, so a thrown `{ message, code: '57014' }` matches. An identity read that times out falls through `classifyCause` to `unknown` (the identity regex matches only the boundary's own refusal), so it waits too. A persistent timeout waits indefinitely like `database-unreachable` already does, and the wait window shows the low-disk line for `unknown` (`DISK_CAUSES`), which was the incident's cause. The new test fails when the regex is removed (plant A).
- **Working language.** `validateSettings` reads a file without `agentLanguage` as on (`raw.agentLanguage !== false`), a non-boolean as on, and `settingsPatch` refuses a non-boolean (tests pass; plant K caught). `readLanguage` turns a throwing reader into English and logs it; `readSettings` itself returns defaults rather than throwing, so the "off but told English" path needs a quarantined settings file, where the interface falls back to the same defaults. The obligation text covers the null case ("or the person's own, when none is named"). `protocolHash` changes with the language (tested).
- **`work:board` IPC.** Typed in `FabricApi.work.board`, exposed in `preload/api.ts`, `MAIN_ONLY` in `ipcWindowPolicy.ts` (the policy table is keyed by `IpcKey`, so a missing row would not type-check), handled in `main/index.ts`. Takes no renderer argument, so there is nothing to validate.
- **Races on the new reads.** `useHome`, `KanbanBoard` and `CommsFeed` each guard with a per-effect `alive` flag, so a slower old reply cannot overwrite a newer one and an unmount during a read sets nothing. `KanbanBoard` catches a bridge that throws synchronously and shows the failure note, never a blank board (plant M caught). After a later failed re-read the last view stays with the failure note above it, which says the read failed.
- **Huge lists.** `HomeAgents` now lists every live session in a scrolling box rather than 8; the list is bounded by the sessions Fabric holds. The kanban columns are bounded by the reads (100/200/50/20) and marked `+` when cut (the filtered case is ER-2).
- **CO-384 focus move.** Runs only when focus was on the rail, falls back to the page's `main` when there is no `h1`/`h2`, and leaves ⌘K and fields alone; the test fails when the rail check is removed (plant B).
- **FirstRun language.** Native radios in a labelled `radiogroup` with a described hint; a refused or thrown write is said through `setError`, and the controlled radio returns to the saved value.
- **«Нужны вы» rows.** `<details>`/`<summary>` keeps keyboard and screen-reader behaviour; a row without detail says so (`launch.home.board.noDetail`) rather than opening blank.
- **OpsLog fold.** `DiagnosticsSection` mounts only after the fold opens (`onToggle`), so the log is not read on every visit to История.
