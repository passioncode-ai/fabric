## Verdict
**Not ready. 1 blocking finding, 2 non-blocking.**

What works:
- **DA-42 is fixed.** `pruneAside` now runs every time the agent is created, and `registerIpc` creates it at every Fabric start (`index.ts:6126`).
  - Probe setup: kept-aside files 1, 2, 3, 4 and 40 days old, a folder and a symlink with matching names, and two names that differ (`pending.json.corrupt-5-notes`, `notes.corrupt-1`).
  - Result: the 40-day file and the fourth-newest file were removed. The folder, the symlink and the symlink's target outside the folder were left alone. The two other names were not touched. No failure was recorded.
- **DA-43 is fixed.** A file with two good entries and one bad entry, opened twice, gives `second: 2`. `pending.json` is rewritten at once as `[{"line":"a","at":1},{"line":"b","at":2}]` with mode 600. The kept-aside copy holds the whole original.
- **DA-44 is fixed.** A message typed at once records only `ceo.agent.delivered` and `ceo.agent.queue-delivered`. A message that waits also records `ceo.agent.queued {"reason":"not-delivered","waiting":1,"chars":5}`. No record carries the text. `ceo.agent.retyped` records only `{lines: n}`.
- **DA-45 is fixed.**
  - Each removal has its own `try`.
  - Only `lstatSync(...).isFile()` entries are removed, so a symlink is never followed.
  - Files are sorted by the number in the name.
  - A failure records `errorClass` only, never a path.
- **Modes hold on a fresh install.** A first message to a folder that did not exist (umask 022) gives `rootMode 700, pendingMode 600, inbox 700`. `saveQueue` now creates the folder with `mode: 0o700`. Every other writer in `ceo/` already uses 0700 for folders and 0600 for files (`ceoAgent.ts:298,301,333,405,412`, `ceoProjectAliases.ts:69`, `ceoVoiceJournal.ts:126`).
- **One caveat on modes.** A `pending.json` that Fabric did not write (for example, one the console wrote with 0644) keeps its own mode when it is kept aside. The probe showed `644`. The folder is 0700, so no other user can read it.
- **The queue writes are atomic.**
  - Every write goes to `pending.json.tmp` (0600), then a rename.
  - Owed lines are saved before the restart that loses them (`fallBack`).
  - A requeued line keeps its `retype` mark across a restart. The line is then recorded with `retyped: head.retype === true`, so it is never typed a third time.
- **Voice memory.** It holds one more boolean (`unknown`) and still no text beyond the 200 characters from run five. The transcript is now read from the write time (`askWrittenAt`). What is read from Claude Code's transcripts has not changed.
- **Tests pass:**
  - `ceo-agent`: 73 of 73
  - `voice-retro`: 38 of 38
  - `delivery-queue`: 11 of 11
  - `claude-transcript`: 3 of 3
  - `console-open`: 14 of 14
  - `CeoComposer.test.tsx`: 8 of 8
