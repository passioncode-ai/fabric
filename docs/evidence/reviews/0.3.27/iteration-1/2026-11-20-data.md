# Fabric 0.3.27 release review, iteration 1: data
Level data, candidate f6990a9aaed3f243d65a40be601e5b519b9af30d, baseline 44cd80ca, reviewer claude-opus-5-5, read-only. HEAD before/after f6990a9aaed3f243d65a40be601e5b519b9af30d/f6990a9aaed3f243d65a40be601e5b519b9af30d, dirty files before/after 0/0.

## Verdict
**Not ready. 1 blocking finding, 9 non-blocking.**

**What works:**
- **File modes.** The call journal's folder is 0700 and each file is 0600. The aliases file is written whole (temp file, then rename) at 0600.
- **What a journal line holds.** The `start` line carries the voice and the rate, never the ephemeral token.
- **The person's and the voice's lines.** They pass `redact()` on their raw text, which works as designed.
- **Redaction at the source.** Most tool answers are redacted before they leave the tool: `ceoTools.ts#screen`, `redactedTurns`, `last_line`, `ceo_reply`, `board_search` subject and snippet, `recap` reasons. They are also bounded: 3000 or 1500 chars, 10 × 300, 20 rows.
- **`machine_status`** sends only numbers.
- **Operations log.** `terminal.first-instruction` writes the session id, runner, state, reason and attempts, never the instruction text. `hub.unknown-credential` writes a 12-hex prefix of sha256 and a printable User-Agent cut to 80 chars, never the credential. `ceo.project.alias` writes the alias's length only.
- **Archived projects stay closed.** An agent that comes back into an archived project's folder is refused (`projectAdmission.ts#enroll`, line 172).
- **Privacy gate.** `node scripts/check-private.mjs` prints `check-private: PASS: no private data in the tracked files` (exit 0).
- **Tests.**
  - Green: `voice-retro`, `ceo-agent`, `console-open`, `delivery-queue` (each run with `node --experimental-strip-types --test`, exit 0).
  - NOT_RUN: `agent-surface.test.mjs` needs a disposable database stack. It refuses with "SUPABASE_URL is not set", which is not a red test.

**Blocking:**
- DA-1: the journal redacts tool arguments and answers as one JSON string. A credential on any line after the first then passes through to disk, so the shipped claim "secrets cut before writing" is false for shapes `redact.ts` removes everywhere else.

| DA-1 | Blocking | **Tool arguments and answers are redacted as one serialized string.** JSON turns each newline into the two characters `\n`.
