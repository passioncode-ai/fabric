## Verdict
**Not ready. 1 blocking finding, 10 non-blocking.**

**What works:**
- **Retro test counts match.** The fixes ledger's counts are right:
  - `voice-retro.test.mjs` has 14 tests, all pass (`node --experimental-strip-types --test apps/desktop/test/voice-retro.test.mjs`: tests 14, pass 14).
  - The per-finding counts in `fixes.md` (2, 2, 3, 2, 1, 1, 1, 1, plus «heard names») match the test titles.
  - `ceo-agent.test.mjs`: 56 pass. `voiceCall.test.ts`: 13 pass. `console-open`: 9 pass. `delivery-queue`: 5 pass.
  - `agent-surface.test.mjs` needs the disposable stack and was not run (it refuses without `FABRIC_TEST_STACK`).
- **Names in the docs exist in the code.** Every symbol, constant and file named in the CHANGELOG, `fixes.md` and `HANDOFF.md` exists and does what is claimed:
  - `deliverFirst`, `TAKES_NO_TASK`, `FIRST_TASK_WAIT_MS` = 70 000, `BUSY_WRITE_AFTER_MS` = 3000, `sayUnknownCredential` (10 min, 12-character digest).
  - `VOICE_INPUTS` {shell 3, agent 6} over 3 min, `VOICE_REPEATS` 3 in 30 s.
  - The journal: `KEEP_DAYS` 30, `CALL_BYTES` 2 MB, folder 0700, files 0600, `project-aliases.json` 0600.
  - `ceo_reply`: 25 s by default, 60 at most, 4 s of quiet.
  - `LASTING_SCRATCH`, `SCRATCH_FOLDER_MESSAGE`.
- **Sound matching works as claimed.** The measured lookups resolve as stated (my probe, below): «DC», «Диззи», «<личный проект владельца>», «Саунд энджин», «фабрик», «свитчборд», «обсерватория». «диск» does not reach dissy.
- **The CEO's brief lists the right tools.** `ceoBrief` names exactly the 11 tools in `CEO_TOOLS`, and every one is registered on the MCP door (`registerCeoTools` loops over `CEO_TOOLS`).
- **Counts in the ledgers hold.** CO-605's «13 projects» matches the 13 names in `fixes.md` §5.
- **The release's other docs hold.**
  - The `MERGES.md` top entries hold. Both new tests are in the fast loop: `scripts/ci.sh:443` has `delivery-queue` and `voice-retro`.
  - 37d69d6a is on `origin/main`.
  - The map's six catches are confirmed (`8decd28d`: 6 changed `catch` lines).
  - `check-regions`, `check-registers` and `check-design-map` all PASS.

**Blocking:**
- **DO-1.** «The home folder is no project» is false for the estate the retro describes. A project whose folder is the home folder now takes every unknown folder under home, so a start in a new folder runs in the home folder instead of making that folder a project.
