### Other checks
- **The call journal.** It keeps one JSONL file per call with these rows:
  - `start` (voice name, rate)
  - `person`/`ceo` lines, redacted, at most 4000 characters each
  - `tool` rows (name, arguments and answer, each redacted field by field, keys too)
  - `cut` (once a call reaches 2 MB)
  - `end`

  Calls older than 30 days by their name, and past the newest 200, are removed at start and at every call. Fabric sends none of it anywhere.
- **What the voice tools send to xAI.**
  - `ceo_reply`: at most 3000 characters, redacted.
  - `board_search`: 10 hits, snippets of 300 characters, redacted.
  - `recap`: launches with their reasons, redacted; project names.
  - `machine_status`: numbers only.
  - Session tools: projects with their folders.
  - Every answer is redacted again in main before it is returned.
- **The aliases file.** It is `<userData>/ceo/project-aliases.json`, mode 0600. It is written to a temporary file and renamed into place. An unreadable file is kept aside and logged once per change of its mtime. The `reason` of an alias goes to the operations log, which `opsLog.ts` redacts.
- **The scratch rule.** `isScratchFolder` covers `/tmp`, `/private/tmp`, `/var/tmp`, `/private/var/tmp`, `/var/folders`, `/private/var/folders`, the given `tmpdir()`, and five cache folders under home. Enrollment refuses a new project or a remote attach there. An existing project there is still admitted, as the CHANGELOG says. A worktree of a known project in `/tmp` enrolls into that project and records no new folder (`sessionEnroll.ts:123`), so the registry does not grow.
- **The hub's unknown-credential line.** It logs a 12-hex prefix of the SHA-256 of what was sent, never the credential, and the User-Agent cut to 80 printable ASCII characters.
- **Privacy gate.** `node scripts/check-private.mjs` prints `check-private: PASS: no private data in the tracked files` (exit 0).
- **Owner's folder names.** I checked every name in `~/DATA` and `~/DATA/_worktrees` against the release's added lines and against baseline file counts. The only new name of the owner's own (not a Fabric worktree) is `<worktree sound-engine>` (DA-25).
