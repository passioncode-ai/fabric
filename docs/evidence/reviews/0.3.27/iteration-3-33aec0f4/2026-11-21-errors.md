**Run nine's fixes at this level hold:**
- **ER-81 holds.** `redactState` now redacts a transcript's saved state one value at a time with `redactPayload`, so the JSON stays whole. No rule touches paths or UUIDs, so `cwd` and `sessionId` come through unchanged. A state that does not parse is read again from the start, and that cannot double any rows, because turn rows are keyed `runtime:sid#lineStart` (`estateSources.ts#readTranscript`).
- **ER-82 holds as a promise.** The installer's message and the wait line now say that with «Служба доски» on, the person turns it off and then quits. The staging order and the silent drop are carried in CO-620 (9).
- **ER-83 holds.** The guard compares the operation trimmed and lowercased, and the operations list the voice sees leaves out the two refused ones.
- **DO-75 holds.** `fabricRunning` checks `lsof … -c Fabric` for the exact `n<target>/Contents/MacOS/Fabric` line. Helper and Inbox executables do not match. When nothing matches, `lsof` exits 1 and `tryOut` returns `''`.
- **UX-80 / ER-84 (restore part) holds.** A restore writes `removed_by = 'restore-boundary'` (`20261011000082_write_rules_at_the_door.sql:337`), and the column is readable (table-level grant). The rest of ER-84 and all of ER-85 are carried in CO-620 (7) and (8).

**In the merged branch, checked and sound:**
- **Locale.** `LC_CTYPE` is set only when no `LC_ALL`, `LC_CTYPE` or `LANG` is present. The later layers in `pty.ts` set no locale.
- **Keeper overlap.** `keep()` cannot overlap itself. Board and access reads have deadlines (`dbDeadline.ts`, `HUB_DB_DEADLINE_MS`), so the `keeping` guard cannot stick.
- **Epoch.** A missing epoch or a board that is down gives `unavailable`, never a throw.
- **Access requests.** The own-project grant is immediate except on an organization's machine, where it is refused before any request is made, so the 30 s keeper never stacks requests to the person.

**Blocking, one line:**
- **ER-87.** The person's stop of the CEO is kept only in memory. After any Fabric restart (login with «Служба доски», «Перезапустить Fabric», an update), a waiting `ceo.task` request starts the console the person stopped. That makes «a CEO the person stopped stays stopped» false.
