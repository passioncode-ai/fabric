## Observations (not findings)

- **Release metadata still names 0.3.4.** `apps/desktop/package.json:3` (`"version": "0.3.4"`) and `docs/launch/release-gate.json` are expected to be bumped by the release PR. The CHANGELOG heading `## 0.3.5 (unreleased)` must become `## 0.3.5` (`release-mac.mjs:84-87`).
- **The CO-245 bullet's wording.** `CHANGELOG.md:57-58` opens "Not yet on Windows and Linux:", but the CO-245 item applies to Windows only ("macOS and Linux only"). The statement is accurate, just compressed.
- **Living documents are frozen after `verifiedCommit`.** The post-verify allow list is `CHANGELOG.md`, `release-gate.json`, the ledger, `MERGES.md`, `map.html`, the declared review files and the `releaseMetadata` handoffs (`scripts/lib/release-mac.mjs:154-155`). Every fix to `README.md`, `AGENTS.md`, `CONTEXT.md`, `release-mac.md`, ADRs or code therefore has to land in a candidate before the final iteration.
