# Fabric 0.3.26 release review, iteration 1: ux
Level ux, candidate 314c956660b35a25b4b71e3ba97cbd8b548914a4, baseline 53e8c3e2, reviewer Claude Opus 5.5 (1M context), read-only.

## Verdict

**Not ready. 3 blocking findings, 12 non-blocking.**

- **What works.** The home's top row places the CEO card at the top right as the spec claims. The CEO window redesign, the stop and the voice picker read correctly.
- **Blocking 1.** «Продолжить в Fabric» stops a person's session before it checks that the session can be continued.
- **Blocking 2.** Fabric's own consoles can show in «вне Fabric» with live «Закрыть» / «Продолжить в Fabric» buttons that end them.
- **Blocking 3.** The new panel's own test file is red on the candidate.

## Checked and fine

- The home's top row: `EstateHome.tsx` moves the hero and `CeoComposer` above `.lh-layout`. The `@container` rules now query `main.content` (the only container above `.lh-top`). `.estate-home .lh-top` outranks the older `.lh-top` media rules. The card stacks only under 640 px.
- `CeoButton`: renders with no CEO bridge, and its accessible name carries the state.
- CEO popup head: correct actions for the running, starting, stopped, failed and ended states. The stopped body offers «Запустить». A stop that fails says «Консоль CEO не остановилась…».
- The home card's «Позвонить» opens the popup and starts the call once (`ceoCallWanted` is taken once and cleared when the window closes).
- `VoicePicker`: native radios in a labelled group, sample loading, stop and failure states. «Послушать» is hidden with no key, and first run shows the step only when a key is ready.
- The rail project row's «＋» and «↻»: accessible names, a busy state, one press at a time. «Нет прошлой сессии» and «нет папки» are said in words.
- «Завершить сессию»: closes and dismisses only when `processGone`, and keeps «Проверить остановку» otherwise (SessionWindow test).
- The new ru/en strings are complete for every key used.
- `Rail.test.tsx` and `CeoPopup.test.tsx` pass on the candidate (46 of 48 in the three files run; the 2 failures are UX-3).
