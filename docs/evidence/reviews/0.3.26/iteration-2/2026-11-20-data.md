Level data, candidate 30552b73e58571047945ef0eafb6c63d44fcb42a, baseline 53e8c3e2, reviewer Claude Opus 5.5 (1M context), read-only.

## Verdict

No blocking findings at the data level. Every iteration-1 data finding marked fixed holds at the candidate. The four marked ruled are on CO-604. There are 6 new non-blocking findings:

- **DA-13:** the turns read from another session are cut to 700 characters before they are redacted. A key that spans the cut can leave about 15 characters of its body visible.
- **DA-14:** no test covers the DA-1 redaction. It lives only in the `index.ts` wiring.
- **DA-15:** `fabric://session/continue` shows the person 8 hex characters of an id. It does not name `from`, the folder or whether the session is running, and `from` never reaches the launch journal. The contract's SL-1 and SL-5 ask for all of these.
- **DA-16:** nothing stops two continues of one session from running at the same time.
- **DA-17:** the second copy of the credential detector (folder attribution) was not re-vendored with the first, so it lacks DEC-0177. This predates the diff.
- **DA-18:** a transcript whose first line is over 256 KB is reported as "not on this computer".

The re-vendored detector reaches nothing in Fabric except link parsing. `shared/redact.ts` has its own patterns and imports nothing.

## Checked and fine

- **Re-vendored contract.**
  - `shared/contract/fabricLinks.ts` and `secretShape.ts` are byte-identical to fabric-agent-contract `src/fabric-links.ts` and `src/secret-shape.ts` at `4c978495894e`. Only the vendor header, import paths and region `docs:` references differ, and the unused `deepLinkRules` is dropped.
  - `session` must match `SESSION_ID` (a full UUID) and is lower-cased by the parser. The credential-name exemption covers only `session` on `session/open` and `session/continue`; every value check still applies.
  - `from` must match `AGENT_ID` (at most 95 characters, no words).
  - Prompt-word parameters still refuse the link. Tests: "a session link with no UUID, or with words, is refused".
- **Credential detector reach.**
  - Inside the repository, `secretShape.ts` is imported only by `fabricLinks.ts`, which only `shared/linkRoute.ts` imports. `shared/redact.ts` has no imports and its own patterns.
  - The narrower `SECRET_VALUE` (case-sensitive prefixes, a boundary, the `sk-` strength check) changes only which `fabric://` links are refused. `jwtSpans` reads in linear time.
- **Link routing.**
  - `consoleOf` compares lower-cased ids. `session/open` starts and resumes nothing (`open-session` or `session-outside`).
  - `continue` acts only on the banner's press (`machineContinue`, a main-only IPC channel, `sessionArg`).
  - The link URL is never logged. `link.open` records only `notice` and `from`. A failed journal read is logged and the link still routes.
- **Process table read.**
  - `/bin/ps -A -o pid=,ppid=` reads only pids and parent pids: no command lines, no environment, no user names.
  - It has a 3 s timeout and a 4 MB buffer, runs at most once per listing or act, and a failure gives `null`.
- **readTail and readHead.**
  - Both are bounded: 2 MB and 256 KB allocations through a file handle, closed in `finally`.
  - A cut first line is dropped, and a cut UTF-8 character falls inside the dropped part.
- **resumeEnded.**
  - The transcript comes only from this user's Claude homes, by the fixed name `<uuid>.jsonl`.
  - Its Claude home is `path.resolve(file, '..', '..', '..')`, which equals the entry `claudeConfigDirs` lists for both `~/.claude` and Switchboard runtimes.
  - The default home starts with an empty environment, any other with `CLAUDE_CONFIG_DIR` only.
  - Before acting, a session already running is refused (`still-running`), as is a folder in no project (`no-project`).
- **Continue that stops but does not resume.** It now returns `stopped-not-continued` with only the session id and its folder, the user's own data.
- **The banner's id.** `slice(0, 8)` exposes nothing beyond what the link itself carried.
- **Launch journal.** `ensureDir` retries after a rejection, the folder keeps mode 0700, and the test passes.
- **Committed screenshots.**
  - `docs/evidence/reviews/0.3.26/shots/{before-home-1440,after-home-1440,after-home-1280}.jpg` show only fixture data: projects Atlas, Studio, Orbit, Signal and neutral questions. No private name, folder, session id or path appears.
  - The JPEG metadata carries only an ICC profile (`Google/Skia`) and no paths.
- **Tests run.** `node --test test/session-launches.test.mjs` passed 13 of 13. `node --test test/session-resume.test.mjs` passed 11 of 11.
