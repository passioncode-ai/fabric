Level ux, candidate 30552b73e58571047945ef0eafb6c63d44fcb42a, baseline 53e8c3e2, reviewer Claude Opus 5.5 (1M context), read-only.

## Verdict

**Not ready: 1 blocking finding and 9 non-blocking ones.**

- **The iteration-1 fixes hold.** The three iteration-1 blockers (UX-1, UX-2, UX-3) are fixed at the candidate:
  - «Продолжить в Fabric» asks for the folder's project before it signals anything.
  - Fabric's own consoles are excluded by their process tree.
  - The panel's tests pass.
- **The blocker is UX-17.** The new `fabric://session/open` link does not open the console. The CHANGELOG and the link notice both say it does, but the link opens the agent's page.
- **The rest is small.** It is wording, mapping and accessibility, plus scenario drift.

## Checked and fine

- `parseFabricLink` admits `session` only for `session/open` and `session/continue`, refuses it everywhere else, requires a UUID and lower-cases it. `from` is recorded and never trusted.
- `routeForLink` sends `session/continue` of a session a console already runs to that console (with UX-17's caveat), never a second move. A link only opens a view; the move needs the press.
- `continueInFabric` checks `stillNames` and the project before `signal`. A session no longer running is continued from its transcript's own `cwd` and Claude home (`resumeEnded`), and a folder in no project is said before anything happens.
- The rail's machine rows say the state once, by the word (`machineSessions.state.*` including `unknown`), with an idle dot for no state. The polls in the rail and the panel keep one read in flight.
- Every new key exists in both ru and en: `links.notice.open-session`, `session-outside`, `continue-session`, `links.continue.ask`, `links.continue.gone`, `machineSessions.countsUnknown`, `state.unknown`, `readAbout`, `continueAbout`, `closeAbout`, `why.noProject`, `why.stoppedNotContinued`.
- A bridge without `agents.machineSessions` (older preload) yields an empty list rather than a crash (`App.tsx` `loadMachineSessions`).
- The CHANGELOG's two session bullets match the shipped titles and scope, apart from UX-17.
