## Iteration 1 findings checked

- UX-1: partly fixed. Copies of one product now rank (`.default` first, local before online; «[name]», «[name]» open the owner's own; «[name]» asks between its two online copies). Still open in a new form: the placement and instance rank also decides between DIFFERENT products, see UX-10.
- UX-2: partly fixed. Description words no longer choose, fillers are dropped, «аналитику», «Фрейм агент», «гроус», «дашборд Ани» resolve right. The new sound-alike match is too loose and opens unrelated dashboards on common Russian words, see UX-11.
- UX-3: fixed. `window(false)` answers `{ known: false, why }` and `fabric_ceo_windows` says `open: null` with the reason (ceoTools.ts `windows`; ceoWindows.ts:161-174). A gap remains, UX-15.
- UX-4: fixed. A kill at the deadline is `OsascriptTimeout`, said as the Automation step, the script text never goes up (ceoWindows.ts:140-149, 198-201); comment corrected; test 263 covers the real runner.
- UX-5: still open. The cold-start wait exits on its first read: a process not started yet answers -1728, which `read` classes as unknown, so `waitWindow` returns at once and the move fails with "is it open?" (see the UX-5 row below).
- UX-6: fixed. `display` is a string enum in every tool; no union reaches the voice schema.
- UX-7: fixed. A project's console is looked up before the reserved words; `fabric`/`фабрик` are no longer reserved (ceoTools.ts `resolveWindow`).
- UX-8: fixed for the screen (each placement keeps its screen) and for Fabric Dashboards once its window has been read in this process; otherwise it is left out silently (UX-15).
- UX-9: fixed. `fitAreas` places area-less windows in what the named ones leave and says `overlaps` when it cannot (probe: `fitAreas(work, ['left'], 2)` gives top-right, bottom-right, no overlap); the description now promises exactly that.
