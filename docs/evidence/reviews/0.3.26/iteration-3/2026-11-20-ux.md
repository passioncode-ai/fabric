**Releasable at the ux level: no blocking findings, 3 non-blocking ones (UX-48 to UX-50).**

- All six run-four ux findings are fixed and hold at the candidate. Run four's ledger ruled none of them to a CO item, so there is nothing to check in CO-603 or CO-604 for this level.
- I measured the run-four blocker UX-42 again on this machine (`switchboard --json sessions --rows`, with Fabric's lookup replayed and the new `homes` root added):

  - **Running sessions.** Every running Switchboard row that has a session id now finds its transcript too.
  - **Shipped claims.** The three claims UX-42 made false are true again: the CHANGELOG line, SCN-142 and SCN-166.
- Focused tests pass: 37 of 37 in the ask, panel and queue files; 16 of 16 in `session-resume`, including the new homes test.
- The three new findings are wording and state gaps:
  - **UX-48:** a pre-existing silent path in the panel's retry from history.
  - **UX-49:** a repeated word in the new half-done banner.
  - **UX-50:** the homes fix makes Fabric-dispatched board runs actable from Агенты. CO-604 (18) already rules on this class, but its reach has grown since run four.
