## Verdict

**Releasable at the errors level. No blocking finding.**

- Every iteration-2 errors finding marked fixed holds at the candidate: ER-12 (a), ER-14, ER-16 and ER-17.
- Every ruled one (ER-12 (b), ER-13, ER-15) is written in CO-604, as items (22), (18) and (19).
- The named tests pass:
  - session-resume: 14 of 14.
  - ceo-agent: 54 of 54.
  - session-launches: 13 of 13.
  - vitest on ContinueSessionAsk, MachineSessions, linkRoute and Rail: 73 of 73.
  - Both typecheck projects are clean.
- The single-flight `continuing` set is always emptied, including after a throw (checked with a scratch run). No act can reach a Fabric console: an owned session goes to `resumeEnded`, which answers `not-outside`.
- `openConsoleRef` is assigned during render, before any early return, and links are applied only from effects. So a link cannot arrive before `openConsole` exists.

The fixes leave five non-blocking defects (ER-18 to ER-22). Two are worth fixing first:
- **ER-19:** the new launch origin `via: 'link'` has no sentence, so the agent's page shows the raw key `sessionLaunch.via.link`.
- **ER-18:** a continue press in flight is dropped when another link replaces the ask. Its late answer then closes the new ask, or its refusal is never shown.

## Checked and fine

- **Single-flight `continuing`.**
  - The entry is removed in `finally` on every path: success, refusal, a `resumeEnded` rejection (caught), and a throw from `find` (scratch run).
  - The wait for a running session to end is bounded by `TAKE_OVER_WAIT_MS`.
  - A close and a continue pressed at the same moment can both signal the same pid, and the continue wins. That is the person's last act, and the pid is checked again with `stillNames`.
- **No act on a Fabric console.**
  - `find` returns null for an owned session, by journal runner id, by pty pid or by parent chain.
  - `continueOnce` then goes to `resumeEnded`, which answers `not-outside` while `runningClaudeIds` holds the id. Nothing is signalled.
  - With the process table unread, every act refuses with `unknown-owner`.
- **`consoleToOpen`.**
  - It returns a console only for `notice: 'open-session'`, which `routeForLink` sets only when `consoleOf` maps the id to a running console. A continue link for a held console opens it, and no ask is raised (`continueSession` is undefined then).
  - The linkRoute test pins all four cases.
- **`openConsoleRef`.**
  - The default `async () => {}` is replaced in every render (`App.tsx:949`), before the early returns of the detached windows.
  - Links are applied only from effects and IPC callbacks, which run after the commit. So the default is unreachable in practice.
- **`redactedTurns`.**
  - It redacts a turn's whole text before cutting it to 700 characters, and the DA-14 test passes.
  - Redaction now runs over every turn in the 2 MB tail, not only the 12 kept. I measured that cost with scratch runs:

    | 2 MB tail made of | Before (ms) | Now (ms) |
    |---|---|---|
    | small turns | 12 | 26 |
    | large turns | 9 | 24 |
    | one huge turn | 17 | 48 |

    Pathological 2 MB inputs (base64, `a=b` repeated, `Bearer` repeated, URL tokens, dashes) each took 3 to 46 ms. None blocks the main process for long.
- **`readTail`.**
  - A tail with no newline returns the partial line, which `transcriptTurns` skips as unparseable.
  - A short read is handled.
  - `ceoTools.ts` importing `machineSessions.ts` makes no cycle: `machineSessions.ts` imports only `node:fs/promises` and a type.
- **IPC `from`.** It is checked against a lowercase grammar before it reaches the journal reason, so no free text is written. `sessionArg` still guards the id. An uppercase id cannot resume anything, because `findTranscript` requires lowercase; it answers `gone`.
- **`live` field.** `parseMachineRows` keeps `pid` only for an integer above 1, and a Switchboard-only row's `live` follows it. The `{live}` placeholder is present in both locales.
- **Refusal words.** `machineWhy` maps every code main returns (`gone`, `changed`, `still-running`, `no-project`, `not-outside`, `unreadable`, `busy`, `unknown-owner`, `stopped-not-continued`) to a sentence present in both `en.ts` and `ru.ts`, with a generic fallback.
- **Typecheck.** `tsc --noEmit -p tsconfig.node.json` and `-p tsconfig.web.json` both exit clean.
