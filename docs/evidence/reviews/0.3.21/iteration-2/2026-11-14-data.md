- The iteration-1 «fixed» rows in this lane hold: DA-1 (V1-23), at most 15 `board_list_reader` calls, 3 on a small board, measured; DA-5 (V1-27); ER-7/DA-4 (V1-12, V1-26), the alias proposed once per process and not awaited; UX-1 (V1-1); UX-2 (V1-2); UX-5 (V1-5); ER-1 (V1-6).
- Scoping: tasks, notes and released claims are read through the session's scoped store, its estate and project filters ANDed with the `.or`; `project_tasks.started_at` is `not null` and indexed; no other project's tasks, notes or claims are read; `similar_work` uses the same project's claims, lapsed ones left out.
- The board read goes through `this.board.list(this.boardCaller(scope))`; `board_list_reader` refuses a reader that is not a project and returns only messages of threads whose participants include the reader, with `since` and no `unread`, so nothing is marked read. From the directory only `id`, `name` and each capability's `capability` string reach the answer. Message and note bodies reach the answer only as a 240-character snippet; task titles fall back to the first 200 characters of the instruction; at most 30 hits.
- `holders` and `holder_unknown` carry only a fixed sentence and a boolean. `held_by` and `last_held_by` name sessions of the same project, as `fabric_work_list` does.
- `aliasProposed` is keyed by Fabric project id, bounded by the number of projects, never persisted. `noFolder` is pruned every pass; a no-folder decision leaves an existing record untouched, so `board-dispatches.json` is unchanged.
- `work.swept@1`: the ingress rule is built from `ABANDONED_KINDS`, so a receipt with `request-no-folder` is accepted, older receipts still validate, an unknown kind is refused; the database checks only that the type exists, so no migration is owed; `SWEEP_SOURCES.requests` lists the new kind.
- Liveness: `lastWorkAt` is set only for `tools/call` bodies, lives on the in-memory session entry and reaches `sessionLiveForDispatch` as `workAt`. Consoles use their output time.
- CO-570: the handler's path is returned in the refusal and written to the local ops log through `hub.consent.connect`; not journalled, not kept past the process, not shown by the i18n sentence.
- CO-575, CO-573 (10) and CO-572 change no stored data.
