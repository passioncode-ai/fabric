## Checked and sound
- **ER-1 fixed.** `compoundsOf` builds ids from the `wordsOf` matches in a single pass, and `TEXT_MAX` and `WORD_MAX` bound its input; the 64 KB test passes. A cut word cannot form a false compound. The rule handles separators like iteration 1's pattern did.
- **ER-2 fixed** for the macOS and Windows paths Electron gives. An empty path never reaches the check (`index.ts:1155`).
- **ER-4 fixed.** `allFailed` now needs both no documents read and every wanted part degraded.
- **ER-7 fixed.** The alias is proposed once per process and not awaited; both a refusal and a rejection are logged. If the tool answers `null`, the `then` callback would throw; that rejection reaches the process handler (`index.ts:1018`), which logs it, so nothing crashes.
- **`readBoard`:** at most 15 sequential pages; a failure is named without losing a window already kept; `board_window_days` is reported whenever it differs from `days`; a 1-day read that does not fit is not used.
- **`holder_unknown` and `holders`** appear only when the live claims are unread, and only on task hits. A stop-word query is reported as unsearchable.
- **`request-no-folder`** is present in every kind-keyed map, including the `work.swept@1` ingress. It is not an agent-only kind.
- **`runStateOf`:** an exit with a missing or non-numeric code is read as `crashed`. `stopped` and `timed_out` stay `ended`, as at baseline.
- **`isWorkCall`** counts only `tools/call`. A rejoin keeps `mintedAt`, so a hook cannot make an idle session look newly started.
- **`sessionLiveForDispatch`:** a console is judged by its output and an enrolled session by its tool calls; without either signal it falls back to the keep-alive sign. An unparsable console start reads as not live.
- **`similar_work`:** its title expression is the one the claim answer already evaluates, so it adds no new throw after the write. Lapsed claims are left out.
