## Checked and sound
- `fabric_board_search` description and answer tell an agent what to do next: put both languages in one query, use `com.submit` for another project, try other words or a wider `days`. An all-failed read says "nothing was searched ... not 'nothing matches'" (probe 5, test «a part that fails is named in degraded ...»). Russian stems match (probe 6: `диспетчеру доски` matches `Диспетчер доски`).
- In production both `boardList` and `boardDirectory` are always wired (`agentSurface.ts:3238-3239`), so the silent no-directory path the probe reached is test-only.
- `similar_work` carries a next step (`similar_note`, `workTools.ts` `similarWorkOf`). It is a hint beside `related` and never a refusal, as SCN-140 says.
- The advice `work.search-the-board` is worded as ADVICE and names the cost of skipping it.
- `fabric_question_ask`: the input schema accepts `recommended` on an option and at top level (`agentSurface.ts:2667,2670`). The options pass to the journal whole (`agentSurface.ts:2732`) and back to the Board (`index.ts:4034`). Refusals are actionable (`questionAsk.ts:108-112`). The CHANGELOG states the new refusal.
- The rail's «Доска» count reads the same person-only query as «Нужны вы» (`App.tsx:794`). Its aria-label «Ждут вас: N» is part of the link's name. No count is shown while the read fails.
- The Board's question card puts «Рекомендуем» with label and reason first, then the others, then «Отдать агенту». An own answer opens from «Ответить своими словами» (test «puts the recommended option first ...»). On Главная the recommended option is gold, with a hidden «Recommended:» for screen readers. Questions asked before this change, with no recommendation, show plain options and no false "recommended".
- `access.connect.wrong-handler` en/ru names the app and the step to fix it, with no machine id. The handler path goes to `detail`, not the sentence.
- The new en/ru strings carry no em dash and no raw identifier on a person-facing screen. The one dash in the `fabric_question_ask` description is agent-facing and was already there.
- The SCN-140 amendment matches the code, except the capability part (UX-1). The rail and home amendments match `LaunchShell.tsx` `FOOT` and `HomeParts.tsx`.
