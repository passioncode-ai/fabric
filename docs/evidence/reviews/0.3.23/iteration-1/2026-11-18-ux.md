## Checked and sound

- Every new or used key (`stack.health.diskHold`, `launchCheck.*`, `session.new*`) exists in en and ru; the Russian labels are «Всё равно запустить» and «Подождать» as the task names (`i18n/ru.ts:1921-1922`); no literal text in the changed components.
- No U+2014 in any added person- or agent-facing string of the diff.
- The overlap warning before «Новая сессия» is the same component and pattern the project page and Tasks use; it is `role="alert"`, starts nothing until «Всё равно запустить», and «Подождать» cancels; tested in `SessionWindow.test.tsx` «board task 4f83a67f».
- The ended session's own claims are released when its terminal exits (`main/board.ts` `onSessionEnded` -> `releaseSessionClaims`), so the warning does not normally list the agent that just ended.
- `scrollbar-gutter:auto` on the embedded console wins over `rail.css:92` `stable` by specificity (`:has(>.session-embedded)` adds a class), so the 15 px classic-scroll-bar gutter is gone only on the console page.
- Long words on an agent's page (`.as-said`, `.as-said li`) and in a project's analytics (`.lp-analytics-stat`) now sit in `minmax(0,1fr)` columns with `overflow-wrap:anywhere` on the text, which lets the grid shrink below a long word.
- The countdown is not shown beside a disk hold (`stackHealthView`: `counting` requires `hold === null`), so no «next try in N s» promises a start the hold prevents.
- Agents get `stack-unavailable` with «Fabric's database is stopped because this computer's disk is almost full; Fabric starts it again once space is freed. Nothing of this call was done. Wait and call again.» and a Retry-After of 60 s (`shared/stackWatch.ts#hubRefusalFor`).
- People-ask: a second ask's thread subject is «Нужны вы, ещё раз: ...» and its key `people-ask:<item>:<revision>:2` keeps the first key unchanged; a reply with no answer block is logged as a note and gets no «не применено» line; a withdrawal is said in the thread as «снят: <причина>» with the result block `withdrawn: true`, and the reasons («решено в другом месте», «пункт изменился, вопрос задан заново», «присылать вопросы в Telegram выключено») read correctly after «снят:». Spec §2, §4, §8 match the code.
- `hub.json` names `turn-verdict/1`; the verdict reason agents get (`shared/turnVerdict.ts:46`) is unchanged and tells them how to go on, wait or release.
- A Switchboard control timeout is said as «Switchboard did not answer in time; the act may still happen», logged `unknown`, not as «exited 1».
- `boardMain.ts` refusal texts («the board has no window to show a prompt in», «the hub is not ready») are not reachable by the app in this candidate: the `board-main` entry is built but nothing starts it (`grep -n "board-main" src/main/*.ts` finds nothing outside `boardMain.ts`; only `electron.vite.config.ts` names the entry).
- Renderer and shared tests over the changed surface pass (table above).
