## The patch's decisions

- **`fabric.project.resolve` answers only a live `project.resolve` or `session.enroll` grant.** Right: revoking in
  Settings now ends it, and the refusal carries the arguments to ask with. It narrows 0.3.7, where any binding could
  call the tool (a service holding only `board.respond` now gets `access-required`); the notes say so. The door lane
  minting one binding per ask is correctly ruled to CO-363.
- **The disconnected agent is refused in the new lane.** Right, and checked before any write (`accessService.ts:266-271`).
- **Only a folder that is no project backs off to 10 min.** Right for the measured case (the home folder), wrong in
  its scope: `no-project` also carries the refusals the person fixes in Fabric and a failed Git read (DO-1). `failed`
  to a minute and the 503 cooldown are right and tested.
- **Refusal levels by code (CO-335).** Right: `trace_outcome` stays `threw`, so the trace contract is unchanged; the
  log level follows the code's meaning, product and hub failures stay errors.
- **The decimal 3 GB line and its one number.** Right: one threshold in the unit it is said in, one formatter for the
  dialog, the copy and the log (the log in English digits, the dialog in the reader's: the same value). Its scenario
  text is right and misplaced (DO-4).
- **The session cap stays 8.** Holds: `main/sessionEnroll.ts` is unchanged since v0.3.7, and no living document says 16.
- **Wave 4 renumbered to 0.3.9.** Complete in the living registers and plans; the remaining "0.3.8" for wave 4 are dated
  sentences each followed by its 2026-10-21 correction.
