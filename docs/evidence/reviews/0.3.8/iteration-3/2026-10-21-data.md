## Checked and holding

- **Schema 94, no migration.** No SQL and no contract change; the order gate passes against `v0.3.7`; the runbook carries "0.3.8 admits schema 94" and "94 for 0.3.7" (`docs/launch/release-mac.md:304`, `:326`, `:373`).
- **The grant as stored.** A `project.resolve` ask writes the ten admitted `access.requested@1` keys (`registry` without `project`); `access_grants.capability` `^[a-z][a-z0-9._-]{1,127}$` and `resource` 1 to 400 characters admit `project.resolve` / `projects`; `access.decided@1` grants only the asked capability and resource; the auto-decision is journalled with the asker as actor (`accessService.ts:443`); the grant lasts `GRANT_TTL_MS` within the 366-day guard. No SQL reads a `fabric` grant except `board.respond`; TypeScript readers that mean an enrollment filter on `session.enroll` (`JoinedAgents.tsx:51`, `pendingFacts`, `sessionEnroll.ts`), so a resolve grant is never read as one. `agent.call` cannot use it (`hubCall.ts:418`).
- **Revocation.** `fabric.project.resolve` reads `liveGrantsOf` on every call (`hubTools.ts:236`), which drops revoked and expired grants; a revoked binding authenticates nothing; «Отключить» revokes every live binding of the agent, resolve bindings included (`keptOut.ts`, `index.ts` `liveBindingsOf`), and the lane refuses a kept-out asker before any write (`accessService.ts:268`).
- **The log's shape.** A typed refusal keeps `trace_outcome: threw` (no reader of `trace_outcome` exists outside `toolTrace.ts`) and gains `error_code`; levels follow `refusalOps`: every code a hub, board or enrollment tool emits (`refusal(...)` call sites, `RefusalCode`, `sessionEnroll.ts` codes) lands in one of the three sets as intended; a 202 with no bytes is `returned`, a 202 with bytes stays `unknown`; JSON responses (`enableJsonResponse: true`) so the tap reads them whole up to 4 KiB.
- **Measured numbers.** 336 in 49 minutes, 148 enrollment errors, 5 `com.submit` and 2 `com.list`, 187 of 259 (in the 0.3.7 period), the three OrbStack I/O exits on 2026-10-20 and the full disk at 23:02 UTC, the Hermes cadence of 30 s, and "three days" (its `fabric-mcp` has run since 2026-10-18) all reproduce.
