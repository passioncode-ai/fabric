## Not findings

- Nudges are taken only after the turn's journal append succeeded, so a refused turn loses none (`workTools.ts:659-661`; `test/session-observe-wire.test.mjs` passes).
- Every part of `waiting` that fails says `read: false` with its reason, never zero (`sessionWaiting.ts:84-103`; `test/session-waiting.test.mjs` passes); its size is bounded (5 items of 120 characters per part).
- `work:session` is main-window only (`ipcWindowPolicy.ts`, `test/ipc-window-policy.test.mjs` passes); a failed read rejects and the page says so with «Повторить», keeping the last good list; a stale read for another agent is never shown (`AgentPage.tsx`, the `of` check).
- The sweep checks `quitting()` before each lapsed release and each done repair (`abandonedSweepRun.ts:289`, `:302`).
- A done repair racing the agent's own done move converges: both re-read the task before moving and read back; at worst two `task.moved@1` rows to review.
- The operator's own move to running is undone when the claim on it ends: a recorded decision of the plan ("The operator's own release also returns a running task nothing else holds to backlog"), not an error.
