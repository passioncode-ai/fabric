## Находки и решения

| Находка | Исправление / контракт | Доказательство |
|---|---|---|
| Чат сдвигает страницу третьей колонкой | Fixed overlay справа, mobile dialog, Escape/focus; один разговорный scroll | `assistant.css`, `attachAssistant`; browser 1280×800 / 390×844 |
| Свободный вопрос всегда создаёт тему | Каталог read/write/draft/form/clarify; неизвестный запрос уточняется | `classifyFabricIntent`; тест `every capability leads to a known view` |
| «Задача» создаёт только Board topic | `createFabricTask` вызывает общий `opCreateTask`; Task и учебная тема раздельны | Тест `Fabric creates one real backlog Task`; browser Boreal |
| Пауза цикла выключает весь чат | Чтение и сохранение задачи доступны; запуск остаётся отдельным | Тест `paused schedule permits conversation` |
| Проект неявный / контекст смешивается | Явный scope picker, Estate+Project threads, исходные реплики сохраняются | `assistantScope`; unscoped-task test |
| Большая форма мешает первому результату | Source → goal → candidate → review; затем работа на своём Project | `renderGuided`, `attachGuided`; browser creation/Task/Board |
| Дедупликация draftId переносит проект в другое Estate | Estate входит в create identity и draft/form keys | `createDemoProject`, `formKey`; estate regression test |
| Селект провайдера теряет выбранное значение | Отрисовывается сохранённый provider; observer list из доступных fixtures | `renderWorkbench` onboarding branch |
| Нет отдельной понятной помощи | Примеры → чат; полный каталог → адресная общая форма | `launch-help`, [руководство](../../launch/fabric-guide.md) |
| Обучение смешивается с прогрессом работы | Счётчик результатов знакомства; skip/resume не закрывает Task | `guideRecord`, `attachGuided`; scoped guide test |

## Детали, которые нельзя потерять в реализации

- Scanner: отдельные cancel/denied/empty/partial, canonical paths и duplicate identity, symlink/nested repository policy. Макет показывает состояния и точный дубликат repo; реальный canonical discovery остаётся открытым.
- Setup: выбор кандидата не является account connection или допуском. Отсутствие провайдера не блокирует запись проекта/Task. Авторитетный backend должен повторно проверять все условия.
- Guide: progress по receipts, tutorial revision, step resume после restart, доступ/архив и второе Estate; пока page-local. Макет сохраняет бизнес-объекты при пропуске подсказок.
- Chat: NLU не исполняет произвольный текст. Scope/ACL resolution и typed commands обязательны; capabilities, пока открывающие форму, не объявляются выполненными.
- Task: title/result/check/owner можно уточнить в карточке; никакого автоматического Run при создании. Unknown retry сохраняет request ID. Receipt и source идут в журнал проекта.
- Audio: явный старт, стоп, review/send; текст и оригинальная расшифровка версионируются; ошибка не уничтожает черновик. Микрофон и STT ещё не подключены.
- Accessibility: мобильная focus containment, Escape, resize и отсутствие layout shift проверяются отдельно; native screen reader и usability pilot остаются открытыми.
