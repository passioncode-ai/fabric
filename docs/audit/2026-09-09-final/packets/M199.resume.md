##### flow
- Persist SwitchOperation и target feasibility до остановки: identity/org/data scope, native compatibility, checkpoint manifest, pending input, unresolved effects.
- Дождаться адаптерной safe boundary; подтвердить stop/fencing. Старый TaskRun заканчивается cancelled либо outcome_unknown; новый linked TaskRun допускается только после подтверждённого результата.
- Записать spawn intent, возобновить exact native ref и проверить account+conversation ack перед отправкой input. CAS binding commit; сбой ведёт к recovery той же операции.
- Реализовать crash reconciliation на каждой фазе; сохранить prior checkpoint для возврата; manifest защищён от symlink/path traversal. Не копировать целиком provider home или live SQLite.
