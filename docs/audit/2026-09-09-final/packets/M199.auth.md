##### flow
- Реализовать provider-specific resolver, очищающий конфликтующие env overrides; official auth backend выбирается по capability receipt.
- Один refresh lineage имеет одного согласованного writer. Сессии одного аккаунта используют совместимые CLI locks; нельзя размножать rotating refresh tokens по session dirs.
- Получать и проверять subject/org при каждом новом auth revision; refresh/cancel/readback не записывает credential в неверный slot. Несовместимый внешний writer блокирует managed operation.

##### exit
Получать и проверять subject/org при каждом новом auth revision; refresh/cancel/readback не записывает credential в неверный slot. Несовместимый внешний writer блокирует managed operation.

#### invariants
- Credentials remain local and outside shared event payloads.
- No account change expands Fabric authority, replays effects or resets enclosing budgets.
- Unsupported or unverified capability is never reported as successful continuation.

#### failure_cases
- Две конкурентные refresh-попытки не создают два живых токена и не портят store.
- Старый токен не перезаписывает более новую auth revision.
- Наследуемый API key не обходит выбранный subscription account.
- Чужой runtime и shared-Keychain конфликт оставляют operation blocked, не делают global swap.
