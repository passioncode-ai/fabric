#### flow
- On committed newmemoryrevision consume category service only; classifier can suggest product issue but local candidate contains private source links and untrusted claim. No source content leaves by being classified.
- Dedup lineage and occurrence group; lock unique lineage+candidate purpose; transaction creates candidate+intake checkpoint. Poll/replay exactly same receipt, notnewcandidate.
- Suppress journals durable lineage tombstone and removes candidate payload from visible queue according to content-retention policy; rebuild restores suppression before considering eligible candidates. Never use local UI preference as only suppression storage.
- Intake OFF separately stops future source consumption and tracks policycursor; existing local candidates retained unless explicit remove. Outbound OFF does not stop localservicelearning. Re-enable only newly observed cursor bydefault, explicit backfill preview required.
- Existing rawmemorysource is not deleted by feedback suppression. Privacy UI must state private source remains in project, minimized feedback copy deletion retention separately; no hidden network endpoint magic.

- Local policy and suppression are business/operational estate decisions, not settings.json syncpreferences.
- No automatic Board task from incomingfeedback; suggestion through same checker/authority as any untrustedinput.
