### observed
Scrollback хранится строкой с cap; предыдущий отчёт фиксирует full-buffer work на output. Общий feed tick запускает независимые readers. Реальные latency/heap budgets в этом аудите не измерялись.

### solution
Chunk/ring buffer и bounded tail analysis, batch renderer delivery; причины invalidation по источнику и scope. Извлекать только затронутый модуль; длина index.ts сама по себе не приоритет.

### steps
- Снять baseline main event-loop lag, heap и render commits на replay fixture 1/10/50 sessions; записать оборудование и workload.
- Вынести bounded scrollback/tail операции, сохранив unicode/ANSI/reconnect/transcript semantics.
- Ввести source-specific invalidation и coalescing, не подавляя distinct entity changes.
- Сравнить p50/p95 и memory plateau с baseline; вынести gates после согласования budget.

### acceptance
- Память ограничена cap×sessions и не растёт после закрытия sessions.
- Повторное подключение даёт правильный terminal output без потери байтов.
- Нерелевантное событие не запускает все loaders; relevant event обновляет нужный reader.
