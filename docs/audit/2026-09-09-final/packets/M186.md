#### solution

##### entry
Home cycles summary, project automations, Inbox failure, full system map cycle node.

##### exit
Cycle detail→tick receipt→started task/run/blocked input/config; manual wake через тот же guarded command, Back retains cycle scope.

##### recipe
CycleReadService joins actual config and S15 tick receipts, per-source capability inventory. Three columns config enabled/cadence, observation health/age, last outcome. For planned CEO/retro/letter/review sources show planned/uninstrumented. Never infer success from cron expectation.

##### preview
Нужно вмешательство N + работающих N + unobserved N; последняя проверка. Full table primary columns kind/project/cadence/nextDue/lastOutcome/health/action.

##### states
disabled/planned/running/waiting plus measured five-state liveness only when detector exists; no telemetry→unknown, app-off→monitor absent; not due/empty workload→skipped reason, not failure.

#### interfaces

##### route
#/e/:estate/cycles?cycle=:cycleKey&project=:projectId; detail tick=:tickRef

##### canonical_id
Cycle definition canonical ID + typed kind/scope; cycle_invocation_id for one admitted window with stable window key. Legacy routine/follower IDs require typed conversion, never one untyped ID.

##### query
cycles.query({scope,kind,configState,health,cursor}); cycles.history(cycleRef,asOfSeq,cursor)

##### command
cycles.wake({cycle_ref,command_id,expected_config_revision}) → admitted/refused/coalesced receipt

##### dto
CycleView {config:{enabled,cadence,timezone,placement,revision},observation:{state,source,age,coverage},lastOutcome:{kind,receipt},nextDue:{at,policy}|unknown}

##### read_policy
Exceptions needing action first, then nextDue asc, then canonical CycleRef; filters project,kind,enabled state,placement,observation health. Unknown nextDue grouped explicitly. Source partial/reconnect never fabricates last success.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- A started task is not cycle success.
- Disabled does not mean no inflight work; show both.
- Sort exceptions first, then nextDue asc and stable CycleRef; unknowns separately labelled, filters reveal hidden counts.
- Pause reason requires source; app-off no outside detector cannot assert stalled.

#### failure_cases
- Sleep/wake, DST ambiguous/missing wall times, DB down, tick overlap, missed ticks, disabled during run, partial producer coverage.
- Chain paused event mistaken for routine: typed source required during legacy conversion.

#### migration
- S15 adds tick start/finish/skip/failure receipts before reader truth; legacy ran maps to started, not succeeded.
- S14 source coverage shared; M180 only unlocks matching detector classifications, not whole screen.

#### tests
