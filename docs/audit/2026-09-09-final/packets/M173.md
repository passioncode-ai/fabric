#### solution

##### entry
Project Decisions preview, ответ Board, факт памяти, source-ref задачи/графа.

##### exit
SCR33 exact decision→superseded ancestors/cited fact/answer/past pack/task; Back восстанавливает selection/asOf.

##### recipe
DecisionService возвращает DAG lineage с multiple predecessors/cycle gaps, exact actor и typed evidence. Flat list и graph используют один snapshot. Legacy source strings parse только безопасным typed resolver.

##### preview
Последние изменения решений и кто их принял; current vs superseded явно; открыть историю.

##### states
no-decisions,one-unlinked decision (list),branching history,missing source,cycle diagnostic,partial,stale,source denied. Нельзя обещать скрытый reasoning: только rationale/citations автора, предоставленный pack и последующие retrieval receipts.

#### interfaces

##### route
#/e/:estate/p/:project/decisions?decision=:factId&asOf=:seq; SCR-33

##### canonical_id
memory fact UUID+valid revision/event seq; question/answer refs optional; actor identity distinct session

##### query
decisions.history({scope,root?,cursor?,asOfSeq?}) → ReadEnvelope<DecisionGraph>; source.resolve(typedRef)

##### dto
DecisionNode {factId,claim,author:{person|agent|system|unknown,id?},validFrom,validTo,supersessionRefs,rationale?,citations,suppliedPackRef?,retrievalRefs,affectedTaskRefs}

##### read_policy
Current roots newest recorded seq desc with stable fact ID tie; lineage follows recorded supersession relations. Filters subject,author kind,current/superseded,evidence availability and as-of. Missing roots/sources are diagnostic rows; reconnect keeps pinned as-of until operator applies updates.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

- No guessing causal links from temporal adjacency.
- Historical exact source version or explicit missing; current pack not substitute.
- Human original never silently replaced; unknown author not agent.
