##### Outbox
{deliveryId:UUID,lineageId,policyEpoch,approvedPayloadRef,digest,receiverContractRef,deliveryKey:OpaqueRandomPerDelivery,state:'queued'|'leased'|'dispatching'|'acknowledged'|'failed_retryable'|'failed_final'|'cancelled_before_dispatch'|'delivery_unknown',attemptCount,nextAttemptAt,leaseEpoch,dispatchStartedAt,ackAt,remoteReceipt?,lastErrorCode,retentionUntil}; deliveryKey stableperretry, notsourceidentifier

##### OptOut
{commandId,expectedPolicyRevision,outboundMode:'off'} transaction increments epoch and cancels queued/leased items not dispatched; result {cancelledCount,inflightIds,acknowledgedRetainedCount,deletionAvailable}; remote deletion separate request and confirmationstate

#### flow
- No endpoint/contract→no dispatcher. Privacy contract approval is externalactivationgate, not developmenttest success. Build fakeendpoint fixture and localpreview before actualendpoint.
- Structuredprojection constructs new fixed DTO from validated categorical fields; never redact-and-send originalobject. Remove noIDs logic entirely; filenames/rarevalues/IP still governed. Manualtextperitem noteligibledefault-on.
- Prepare immutable payload blob+digest, receivercontract+epoch; approved event and outbox projection commit atomically. Rebuild materializes state only, no POST.
- Before dispatch reserveS03 bounded grant/permit and outboxlease with currentpolicyepoch under transaction; recheck epoch at last reversible point. Record dispatchstarted durably, then network. Responsevalidated+remoteid→acknowledged. Commit receipt failure→unknown until reconcile.
- Optout increments epoch: queued/leased cancel; dispatching attempt best-effortabort but honest possible-send. PreviouslyACK retained remotely perreceiverpolicy; remote delete requested separately and onlyconfirmedafterremoteproof.
- LostACK retry uses endpoint declaredidempotency TTL and same deliverykey/digest; outsideTTL or noidempotency→unknown/manualreconcile, notblindPOST. Re-enable startsnewpolicycursor; suppressedlineages remainblocked.
- Receiver treats allfeedback as untrusted suggestions; no machine commandembeddedintext/taskautocreation/checkerruleupdate.

#### invariants
- Endpoint credentials never in payload/projectmemory; perhopsecretrefs only. URLredirects outside acceptedorigin refused; safeerror strips requestbody/headers.
- ExternalpayloadDigest immutable after approval; retries exactlysamebytes, metadatawithinacceptedcontract.
- No inference ‘all sent removed’ fromlocaldelete/optout. Deliveryreceipt and remotecontentpurge have separate timeline.
- No claimzeroanonymizationrisk; servicecategory can carrysensitivecontext so defaultstructuredfieldset is necessary but needsreview.
- Unknowncost/remainingquota notfree; outboundexistingpolicy permission cannot grantagent autonomousprivacypolicychanges.
