#### flow
- Separate ModelPort for builtinmodelcall from NativeManagerRunner (whole externalagent loop). Both use samemanager tools andusagecontract; CLI is not API-key fallbackadapter.
- Health read returns not_configured separately unavailable; nofakeModelPort productiondefault. Syntheticfake registered only in fixture composition.
- Adapter normalizes observablecontent/toolcalls/usage, stores opaqueproviderstate safely ifrequired byprovider; no parsing orinventinghiddenreasoning/rationale. Recorded rationale is explicit outputfield atproposaltool.

- Abort stops reads/dispatch as supported, but networksent/unknown remains receipt; never returncancelledbeforeeffect ifalreadyexecuted.

- Rawtextcomplete doesnotcommitanything; all statechanges via sharedcommandports.
- No directprovider SDK import in renderer/sharedpurecore.
