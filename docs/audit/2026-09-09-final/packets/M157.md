#### solution

##### entry
Manager вызывает settle по open question; человек видит resolved-by-manager в Board history и decision detail.

##### exit
Committed settlement с exact basis refs, либо typed refusal→question остаётся Board. Override открывает конкретное заменяемое решение и создаёт supersession через human answer path.

##### recipe
Validate typed subject+scope+version, current basis и применимость; затем общий M168+M158 gate и M152.commit. Не считать одинаковый about достаточным при разных environment/config revisions.

##### preview
Кто решил, цитата/факт, применимость, когда, action оспорить; подробная арифметика/trace раскрывается.

##### states
proposed/checked/settled/refused/overridden; basis-stale,scope-mismatch,trust-revoked показывают причину и путь operator answer.

#### interfaces

##### route
Board?status=answered&answeredByRole=ceo,product-manager&item=question:<id>; decision SCR33?decision=:id

##### canonical_id
question+expected seq, basis fact/prior-answer ID+revision, subject key, scope, settlement command

##### command
settlement.propose({question_id,expected_seq,basis_refs,answer,subject_ref,policy_revision})

##### response
CheckedSettlement or Rejection {reasonCode,sourceRefs,remedy}

##### read_policy
Settled history default settlement seq desc with stable ID tie, filters project/subject/actor role/current/overridden. No settlements is an honest empty list; unavailable basis store is partial and prevents new auto settlement.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Human decision reversal запрещён независимо от criticality score.
- Override supersedes decision, не редактирует старую запись; уже исполненный внешний эффект не отменяется магически.
- No-basis всегда refuse, model confidence не authority.

#### failure_cases
- Basis exists but superseded/different environment; same about чужого project; trust revoked между check и commit.
- Оператор override после resumed work — показать затронутые pending/running tasks, не утверждать rollback effects.

#### migration
- Structured subject/basis refs additive; legacy plain source_ref не считается подтверждённым basis.
- Enable settlement only after M158/M168 activation gate; default trust settings не обходят gate.

#### tests
- settlementCitationValidity: current/superseded/cross-project/config-changed refs.
- settlementHumanFloorAtLowScore: hard refusal even score below threshold.
- settlementOverrideLineage: original retained, continuation handles new decision revision.
