#### interfaces

##### Read
shared_contracts.reads; caller query {scope request resolved server-side, generation, filter, minimumCursor?, pageCursor?}; generation client correlation, not authorization

##### LocalRead
{value:T,revision:Revision /* opaque */,status:'ready'|'recovered'|'default_missing'|'unreadable',lastGoodAt:string|null,error?:SafeError}

##### LocalWrite
Command<{patch}> with expected_revision:Revision → canonical CommandResult<{value:T,revision:Revision}>. Committed receipt_ref addresses a durable local operation receipt; conflicts expose current revision. Renderer preserves unsavedPatch independently on every non-committed result; private local persistence is not a journal domain event.

##### PackAdmission
{purpose:'manual_terminal'|'task_unattended'|'manager',mandatorySources:string[]}; compile result complete/partial/failed; no successful complete if any mandatory read failed

#### flow
- Query through scoped reader returns source receipts and highwater; loader key=(scope,filter,generation). Stale A response ignored after B switch, even if A finishes later.
- Overview and misses fetch independently, each source success/error published; optional combined headline only when compatible source snapshots. lastSuccessAt remains previous successful timestamp, not overwritten by failed retry.
- Local JSON writes serialize per file in main: validate→merge at expected revision→write temp same dir0600→fsync→atomic rename→fsyncdir→reply saved. Keep validated last-good separate, invalid original moved to quarantined filename; parsefailure never silently persists defaults over lost file.
- Settings nested patch per schema, not shallow unknown-property spread. Pin/digest/tabs all use same typed result primitive; coalesce save safely but don't acknowledge revisions skipped. Local preferences never journal as estate state.
- Manual terminal may start in explicitly labelled degraded context when identity/rules intact; unattended agent/manager authority inputs unavailable→admission deferred. Current catch-and-log in bundle replaced typed readiness; this is local behaviour fix before full S12 restore.

#### invariants
- No data crosses scope through cache; authorization loss immediately invalidates old scoped value.
- source unavailable ≠ no rows; mixed counts cannot produce known miss rate.
- minimumCursor unavailable returns pending/unavailable reason instead of stale exact decision. Eventual search can show lag with exact reader fallback.
- Seen cursor advances only for payload successfully displayed/acknowledged by that feature; no globalcursor bulkack of failed memory misses.
- In-memory optimistic preference and persisted preference kept separate; restart returns last committed file.
