#### solution

##### entry
Home needs-you preview, project preview, attention command и прямой deep link.

##### exit
Question detail или конкретный task/grant/proposal; после решения остаётся receipt с переходом к resolved item, Back возвращает scope/filter/selection.

##### recipe
BoardService получает unresolved вопросы и obligations из текущего состояния, рассчитывает один rank snapshot и counters, затем применяет scope и cut. Заменить ad-hoc attention DTO общей discriminated union. Не считать policy refusal текущим только потому, что он входит в last50.

##### preview
Top5/top10 плюс exact total или at-least indicator при partial; ссылка Все N сохраняет scope и item.

##### states
initial loading,complete-empty,partial,last-good stale,error,no-access,selected item resolved,updating. При свежей смене rank показывать N обновлений, не двигать кнопку под pointer.

#### interfaces

##### route
#/e/:estate/board или #/e/:estate/p/:project/board?item=:boardItemId&kind=:kind&status=open

##### canonical_id
question:<uuid> | review:<task_id> | lease:<work_id> | proposal:<uuid> | refusal:<command/effect_ref>

##### query
board.query({scope,filters,sort:rank|age|project,cursor?,snapshot_seq?}) → ReadEnvelope<{items,total,countsByProject,rankRevision,nextCursor}>

##### dto
BoardItem {subjectRef,origin:authored|derived,kind,rank:{value,components},owner,waitingSince,blockerRefs,availableActions,sourceRefs}; availableActions объясняют blocked/denied reason

##### read_policy
Default rank desc → age desc → canonical ID asc; optional age/project grouping, filters project/kind/open/history/owner. Cursor pins rank snapshot. Complete empty only when every required source read succeeds; partial/stale/reconnect follow ReadEnvelope.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Task Kanban — состояния задач; ranked Board — обязательства оператора. Их нельзя назвать одним DTO/экраном.
- Unresolved не dismiss/read; resolved исключается из open, но история доступна.
- Сортировка стабильна для одного snapshot; pagination использует тот же rankRevision/asOfSeq.
- Failure одного обязательного source не даёт zero badge/всё спокойно; stale mutations проверяют revision на server.

#### failure_cases
- 11 project/6 estate obligations: hidden count+full link, ничего не исчезает.
- Policy refuse после grant/закрытия перестаёт требовать действие согласно current command state.
- Question исчезла при ответе другого человека: показывается resolved receipt, draft можно скопировать, повторный submit conflict.
- Невалидный cursor или stale snapshot → refresh hint, выбранный объект не подменён.

#### migration
- Board остаётся query, не новая business truth table; projection unresolved obligations допустима только rebuildable и source-linked.
- Сохранить adapter старого attention IPC до миграции всех consumers/counters; затем удалить duplicate ranking.

#### tests

- boardPartialReadNeverClear: один source упал, остальные доступны с coverage.
- boardStablePagination: >500 mixed items и rank change между pages.
- boardKeyboardResolveBack: focus/item remain during refresh.
