### contract

#### id
S02.roots

#### depth
deep

#### solution
- Replace the single global root set with per-window/per-project grants, so a folder chosen in one context does not widen another window or an agent.
- Keep the trusted-local profile's stated limit explicit: realpath defeats a static symlink, not an attacker swapping a path component concurrently.

#### interfaces
- main/files.ts: resolve(scope, rootRef, relativePath) enforcing the boundary at each operation rather than once at grant time.
- root_grant projection {estate_id, project_id, window_context_id, root_ref, canonical_path, grant_revision, revoked_seq}.

#### invariants
- A native folder selection grants that window only.
- A revoked root refuses the next operation; an open editor does not retain authority.

#### tests
- Two windows with a symlink from one root into the other; revoke while an editor is open; the component-swap race, which stays unadmitted until it passes.

#### migration
- Grants become rows rather than a process-lifetime set; dialog grants may remain local config and must not become estate authority by accident.

#### failure_cases
- Root revoked mid-edit -> refusal, not a stale write.
- Untrusted-repo profile -> refused as unsupported rather than silently weaker.
