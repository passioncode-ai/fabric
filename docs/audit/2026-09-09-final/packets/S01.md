#### solution

##### entry
Boot main window; пустой project; edit/save; switch task A→B; pending onboarding create.

##### exit
Сохранённый ввод/правильный task; honest failure с retry; успешный поздний create доступен без захвата фокуса закрытого экрана.

##### recipe
Hooks до любых returns. Monaco model стабилен, persisted baseline отдельно от live value; save only advances submitted baseline/hash. Task drafts/request generations keyed scope; disable wrong-identity mutations while new detail loading. Empty first-task form вынести вне data-length branch. Project create op owns canonical pending ID; close view не отменяет committed op и не разрешает late navigation.

##### preview
Busy/error/saved states соответствуют именно current buffer/op, а не последнему завершившемуся Promise.

##### states
boot metadata unavailable,editing,saving,new edits during save,conflict,loading new task,stale old task discarded,pending create detached,succeeded elsewhere,failed draft retained.

#### interfaces

##### route
Существующие Shell/Editor/Task/Onboarding entrypoints; AppRoute adoption отдельно S13

##### canonical_id
DraftKey project_id/task_id; RequestKey scope+generation; CreateOpKey client_project_id/command_id; FileModelKey canonical file path

##### interface
scoped resource loader; stable editor model; operation registry for late create result

##### read_policy
No new collection order. Request generation scope and current draft/file/task identity bind busy/error state; late operation can finish without replacing active view. Reconnect reload does not discard dirty local draft.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Never clear newer text on older save/note completion.
- Displayed object ID equals mutation target ID.
- Empty board allows first idea without requiring preexisting task.
- Unexpected boot metadata error visible and retryable, no hook-order crash.

#### failure_cases
- Save→type more→resolve; task A/B reverse response order; submit noteA then switchB/type; close create before success; duplicate retry.

#### migration
- No DB migration needed for hook/editor fix; onboarding idempotent project create/partial attachment semantics may depend S06/S04 boundary.
- Persist draft at agreed local boundary only; no telemetry of typed content.

#### tests
- Existing audit Shell/editor/project probes reproduce before fix; TaskPage identity race component probe.
- New tests call actual components and fake IPC; avoid helper-only mirror tests.
