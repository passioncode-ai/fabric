#### solution
- Разделение в одном процессе, без новых сервисов/БД. Main/index только composition root/window lifecycle + register handlers; MCP AgentSurface только adapter. Ports WorkCommands, ExecutionCommands, Authority, KnowledgeQueries/Commands, ProjectFiles закрывают повторяющиеся scope/error/transaction обязанности.
- Извлекать один вертикальный шов: scoped command → storage transaction → receipt → reader. Нельзя сначала вынести raw db в utility и считать границу созданной. Структура renderer разделяется по существующим пользовательским блокам, state orchestration остаётся в typed query hooks.
- Операции одного SQL commit остаются одной command даже если задействуют несколько domain projections (например answer+decision+block set+outbox).

#### interfaces
- WorkCommands {answerQuestion,moveTask,createTask}; ExecutionCommands {requestLaunch,continueRun,cancelRun}; Authority {authorize,reserveEffect,reconcileEffect}; Knowledge {queryCurrent,compilePack,recordClaim}; ProjectFiles {readWithinRoot,writeExpectedHash}. All consume VerifiedCommandContext and return CommandResult.
- Storage ports are private to command modules; read ports return immutable DTO, never SupabaseClient or filesystem handle.

#### invariants
- No raw service-role db in renderer/MCP handlers/scheduler after affected seam is migrated.
- Pure ranking/projector functions stay pure; dependency injection for clock/id/provider ports.
- Do not postpone an urgent scope fix until whole file extraction finishes.

#### failure_cases
- AgentSurface calls removed old handler -> contract compile failure, no compatibility alias that bypasses auth.
- Extraction accidentally weakens person-vs-agent supersession check -> P18 negative probe catches.

#### migration
- Move implementation byte-equivalent first under tests, wire same endpoint, then introduce scoped boundary in a separately reviewable change. Shared file ownership is sequential per seam. Leave unrelated domains until they need edits.

#### tests
- Run current pure/SQL probes before and after each seam with identical fixture.
- Dependency rule asserts renderer/preload/MCP adapters cannot import raw write client module.
- P24 projection hash parity incl M198 config_revision remains required; extraction cannot accept new exclusions.
