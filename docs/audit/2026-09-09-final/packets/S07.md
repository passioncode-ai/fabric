#### solution
- Разделить подготовку release pipeline и разрешение распространения конкретной сборки. Build identity генерировать при сборке из checkout/lockfile/schema/contract pins; installed runtime читает встроенный manifest, а не git текущего каталога.
- CI запускается в чистом checkout. Зафиксировать Supabase CLI и digest локального Postgres image в release toolchain.lock.json после получения версии из успешно прошедшего fresh+upgrade matrix. Текущий latest не является воспроизводимым pin; версия не выбирается по памяти.
- Собирать macOS arm64 пакет на соответствующем runner. Smoke через тестовый profile + test estate + запрет scheduler auto-start; не наследовать userData/.env/default credentials. Проверить все типы окон и bridge внутри реально упакованного приложения.
- До публикации: migration from-empty, upgrade previous supported schema, replay parity включая config_revision, восстановление backup в отдельный DB, проверка прав для anon/authenticated/service_role и cross-estate direct SQL/RPC. Fresh P21 на 5051def красный: это open release gate S02, не доказанная утечка строк.

#### interfaces
- BuildManifest@1 {build_id, commit_sha, source_dirty:false, built_at_utc, app_version, lockfile_sha256, schema_min, schema_max, journal_read_versions, adapter_contract_revision, toolchain_digest, files:[{relative_path,sha256,size_bytes}]}
- meta.info(): {installed: BuildManifest, runtime_schema, compatibility: compatible|read_only|incompatible, reason_code}; manifest query never reads repository HEAD.
- ReleaseEvidence {build_id, fresh_acl_probe, fresh_rls_probe, upgrade_probe, replay_probe, restore_probe, packaged_smoke, artifact_sha256}; every receipt names source SHA/environment and command exit.

#### invariants
- Unknown schema/version does not migrate automatically; compatible read-only mode only if explicitly declared by manifest.
- Backward rollback is application rollback within declared schema window; never silently down-migrate append-only journal.
- Install, verify and pilot observed remain independent statuses.
- Desktop renderer sandbox does not imply spawned CLI isolation.

#### failure_cases
- Corrupt artifact byte -> checksum fail before install.
- Offline update download -> retain current installed version, resumable retry, no version change.
- Upgrade fails halfway -> transaction rollback; if migration crosses nontransactional external store, restore verified backup into new database and switch endpoint only after checksum/health checks.
- Native app smoke without test profile/test estate must abort before invoking any scheduler.

#### migration
- Add manifest generation and About reader first; toolchain pin committed after measured matrix. Version migration is append-only. Maintain old appId/userData paths; display brand changes do not migrate data directories.
- Signing/notarization credentials are delivery environment inputs, never repo values. Missing credentials blocks public distribution only; unsigned test artifact can be inspected as such.

#### tests
- Run bash scripts/ci.sh fast and full on clean CI; expected direct exit0. Full currently fails P21 so artifact remains not releasable.
- Build twice with same source/toolchain and compare identity inputs and file checksums excluding declared nondeterministic signing timestamps; report differences, do not claim reproducible build unless byte comparison passes.
- Use one archived test fixture of previous supported DB; create task/decision/question/run, upgrade, restart, restore -> IDs, event order, bodies and receipt relations equal.
