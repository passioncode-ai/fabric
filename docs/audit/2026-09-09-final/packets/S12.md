##### RecoveryActivation
Command<{recoveryOperationId,expected_revision,verifiedArchiveDigest,currentAuthorityReceipt,reconciledIntentRefs,newEnvironmentId}> → CommandResult<{recoveryGeneration:Revision,activeCapabilities,heldCapabilities}>. Pending effects/deliveries/exports remain held unless individually reconciled and freshly admitted.

#### flow
- Read scope from S02, obtain consistent snapshot and sourceCursor in one DB read transaction. Coverage explicitly lists assets/membership/goals/autonomy/agent bindings/human decisions+their relation pointers; unsupported entity is partial and blocks 'all declared restorable' claim.
- Mirror writer renders deterministic allowlisted files to sibling temporary generation directory, fsync files, writes manifest LAST as generation commit marker, atomically replace manifest pointer; readers validate all hashes to avoid mixed generations. Existing user divergence preview before overwrite; no auto git commit/push.
- Import v2 fully parse+schema validate+cross-ref validate+duplicate ID check+payload size bound before write. Server-side operation reserves scope+command key and rechecks target empty under estate lock. Execute bounded batch in ONE SQL transaction, append existing domain events needed to preserve status/settings/relations plus durable import receipt; crash beforecommit no partial estate. Larger archive returns IMPORT_TOO_LARGE with no writes, not silent chunk mode.
- Legacy two-file import reads v1 with explicit partial coverage warning; uses same atomic command; cannot advertise restoration of absent goals/decisions. Path strings stay evidence; mappings checked local roots before executable use.
- Restore journal, identity membership/role assignments, durable operational reservations/dedup/delivery/outbox/consent/suppression/cursors and required immutable blobs under a coherent snapshot. Restore is isolated, all dispatch/schedulers/export held. Old archive may predate rebind, opt-out or successful send: first obtain fresh recovery authority generation from the current trusted control plane and fence old environments; never trust restored grants or credential epochs as live authority. Reconcile possibly dispatched intents with provider receipts; unknown stays held. Reauthorize current membership, bindings and pending work through normal admission. Outbound consent resets off/quarantined; restored candidates/outbox never become sendable through activation alone; revalidate current suppression or retain quarantine. No current authority/suppression proof means read-only recovery, not success-by-default.
- M198 scoped rebuild uses new projection generation/staging and parity check against live expected fixture, activation pointer last; other estates untouched. Failure leaves old generation readable and operation failed; rollback chooses previous generation, not undo journal history.

#### invariants
- A target is empty for selected estate, not 'no projects anywhere'. Different estate rows neither block preview nor get exported.
- Import status archived/done/settings/relations preserved through versioned semantics; never synthesize new IDs for matching existing entities.
- No partial default fallback when manifest omitted/invalid; no imported filesystem path trusted as access grant.
- Mirror sourceCursor advances only when committed manifest covering that snapshot exists; unrelated journal event seq is not mirror freshness.
- Replay/projector never calls disk/network; operational receipts distinguish replay/rebuild from original live activation.
- An older archive never revives permissions, a revoked binding, a consumed grant, acknowledged delivery or suppressed feedback. Recovery generation is issued outside restored state; reactivation is a separate guarded command, not a replay side effect.
