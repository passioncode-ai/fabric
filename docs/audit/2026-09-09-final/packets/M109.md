#### solution
- Единый typed register IPC handlers производит runtime validator + sender validator + типизированный result из FabricApi. Не второй реестр возвращаемых типов: handler satisfies Returns и Parameters того же method, validator names correspond to method keys.
- При постепенном переносе каждый неперенесённый handler остаётся в явном inventory. Sweep считается законченным при равенстве зарегистрированных каналов и методов контракта; отрицательный type fixture ломает typecheck при return drift.
- Чтения возвращают общий ReadEnvelope (S14); команды CommandResult. Наружу выходит error code + безопасные recovery details, не stack/path/token.

#### interfaces
- registerHandle<K extends keyof IpcContract>(key: K, input: RuntimeParser<IpcContract[K].args>, handler:(ctx:VerifiedIpcContext,...args:IpcContract[K].args)=>Promise<IpcContract[K].result>):void
- All results use exactly CommandResult<T> and Ref in docs/architecture/system-contract.md §4; do not duplicate a local union. Uncertain effect outcome is status:unknown and requires reconciliation.

#### invariants
- No type annotation substitutes for runtime validation of renderer-originated data.
- Nested UUID/project scope checked by domain commands after syntax validation.
- All privileged IPC validates sender frame/window/origin against local owned surfaces; renderer cannot supply ctx.

#### failure_cases
- Malformed enum -> typed invalid_input and no DB call.
- Correct syntax with mismatched project -> domain refusal.
- shell.openPath nonempty error string -> unavailable/refused, never committed.

#### migration
- Introduce register helper alongside current handlers, migrate domain-by-domain, remove legacy direct registration only when inventory=0. No big-bang change to all renderer methods before compatible result readers ship.

#### tests
- Negative tsc fixture returning string for declared number must fail; valid fixture passes.
- Call helper with unknown iframe sender and structurally invalid payload -> handler invocation count0.
- Generate inventory from AST or actual registration map, not count raw text containing ipcMain.handle.
