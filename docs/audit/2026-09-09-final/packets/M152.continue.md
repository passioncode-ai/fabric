#### solution

##### entry
После commit оператор остаётся на question/task; agent check получает durable response.

##### exit
acked тем target task/session authority epoch либо visible needs-restart/rejected; task возвращается к работе только если нет других blockers и policy допускает.

##### recipe
ContinuationService пишет addressed delivery envelope; responder выбирает live session с lease/epoch. Одна доставка может повторяться, получатель дедуплицирует command и подтверждает его ID. При смерти session UI предлагает guarded resume существующей незавершённой task с новым session, актуальным pack и прежним decision receipt.

##### preview
«Ответ записан» и «доставка ожидает/получена/требуется перезапуск» — разные строки. Retry повторяет доставку, не ответ и не grant.

##### states
queued/delivering/acked/retryable/needs_restart/obsolete/rejected; delivered-by-transport допускается как промежуточное, не accepted-by-agent.

#### interfaces

##### route
Task SCR32 или Board answered item; delivery=:command_id в detail

##### canonical_id
answer_command_id + delivery_id + task_id + task_run_id + target fabric_session_id + authority_epoch:Seq. S04 creates TaskRun on admission; addressed/dispatched continuation requires that ID. Null only while pending before admission or reading an explicitly legacy receipt.

##### command
continuations.retry({delivery_id,expected_revision}) / tasks.resume({task_id,decision_ref,command_id})

##### dto
ContinuationReceipt {committedAnswerRef,targetRef,transportState,ackState,lastAttemptAt,nextRetryAt,problem,retryAllowed,restartAllowed}

##### read_policy
Delivery attempts ordered recorded seq; current target and latest attempt primary. Filters old/superseded delivery in detail only. No delivery yet means queued/unsupported according to capability, not acked. Reconnect queries persisted delivery status.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Text bytes sent не ack.
- Answer commit никогда не повторяется при delivery retry.
- Obsolete epoch не получает право работать; новый runner не наследует одноразовый grant автоматически.
- Живой agent, polling question_check, также выдаёт explicit received ack, если transport contract это поддерживает. TaskState done/cancelled нельзя reopen: после terminal создаётся новая linked task с origin; existing unfinished task получает новый TaskRun.

#### failure_cases
- Session died before send/after send/before ack; lost ack; duplicate delivery; renderer reload.
- Decision superseded while envelope queued → old envelope obsolete; delivered old fact remains evidence.
- Другой вопрос блокирует task → ответ доставлен, task remains waiting.
- Unknown transport outcome reconciles delivery/request ID; no new answer/effect identity and no blind duplicate side effect.

#### migration
- Add durable command/delivery receipts from S04/M103. Require task_run_id for every new addressed delivery; M188 adds progress plans but is not the producer of initial TaskRun identity. Preserve legacy records as incomplete read-only observations; never dispatch from ambiguous old IDs.
- Legacy no-ack runner помечается capability=unsupported, не автоматический success.
