#### solution

##### choice
Instrument transport + central tool dispatcher so read, mutation, schema refusal, thrown handler, retries and cancellation share one attempt identity. Business receipts remain their own events. Do not infer a tool-call count from domain events.

##### transactions
- At authenticated parsed tools/call ingress allocate trace_id and attempt_id before tool schema validation. Record safe start with tool/version/protocol/request correlation; finalizer records exactly one terminal transport outcome. MCP SDK validation occurs before some callbacks, so handler-only wrapper is insufficient: trace the request/response adapter boundary at AgentSurface.handle and pass attempt context into domain gateway.
- Invocation outcome is separate from HTTP status: JSON-RPC error/isError/refused/committed/unknown/cancelled. Nested command ids link to domain receipt. Same logical command repeated creates new transport attempt trace but reuses original command receipt.
- Mutation must commit domain receipt even if optional trace sink unavailable; return traceCoverage partial. Failed diagnostic sink appends a bounded local redacted gap marker and later recovered original observed times. Once buffer fills, increment lost_count with first/last interval; never claim full corpus. Reads may still answer with gap flag.

##### privacy
Persist allowlisted metadata, normalized error code, typed safe summary and content ref/hash only where approved. No raw args/results/transcripts by default; target/basis refs with scope checks. Unknown/bad token is unscoped authentication diagnostic without raw token. Rate-limit pre-auth diagnostics; event types/catalog cannot loop into their own tracing.

#### invariants
- Every admitted Fabric request attempt is countable; unknown failed ingress is labeled separately.
- One request may cause N domain events; those do not multiply tool count.
- Trace incompleteness survives recovery and excludes affected intervals from claimed complete eval corpus.

#### failure_cases
- MCP schema rejects before handler → terminal schema_error exists.
- Caller disconnects after committed mutation → domain committed, response delivery unknown.
- DB down → local gap; future reconnect not a retrospective invented complete trace.

#### migration
- Add trace event types + projection and safe versioned envelope without changing existing domain @1.
- Update surfaceTools metadata and eval readers to actual trace coverage. No backfill of missing read tool invocations from historical journal.
- Existing transcript redactor reused as defense; typed allowlist is primary minimization. Trace retention and local max bytes/time configurable and measured, not arbitrary forever.
