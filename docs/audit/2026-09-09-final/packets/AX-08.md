### context
RoutineTick returns void and swallows read/spawn failures. Outer cycle defaults completed. Partial inner receipt and completed outer receipt have no join ID. Reader gap helper also equates gap with app closed though sink failure exists.

### files
- apps/desktop/src/main/routineTick.ts
- apps/desktop/src/main/index.ts
- apps/desktop/src/shared/cyclePort.ts
- apps/desktop/src/shared/cycleView.ts
- apps/desktop/src/renderer/src/ProjectHome.tsx

### solution
Return typed per-producer pass outcomes; one tick identity/config revision and explicit admitted/skipped/refused/partial/unknown aggregate. Observer independent of routine success; gap means unobserved unless host evidence says otherwise.

### decomposition
- Define tick identity and aggregation table including source outage and coalesced overlap.
- Return routine/chain results instead of catch-and-complete; cap planned starts vs actual admitted counts separately.
- Separate observer sampling so failed/slow workload does not suppress health recording.
- Expose all-cycles table/detail with planned unsupported sources and guarded wake.
- Use fake clock for sleep, concurrent tick, cap fairness, unavailable DB and failed receipt sink.

### depends_on
- AX-01 admission; AX-02 observation service; CO-111 when adding cursors

### acceptance_positive
- One partial pass remains partial in aggregate; zero due explicitly not-due/skipped.

### acceptance_negative
- Failed routine read never reports completed empty pass.
- Receipt absence cannot prove app closed.
- Wake cannot bypass leases/admission or duplicate inflight work.

### exclusions
- No hosted always-on monitor required for local cycle reader.
- Do not treat task start as verified outcome.
