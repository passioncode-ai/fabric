### observed
mayStart разрешает missing windows и NaN; HTTP 200 {} формирует problem:null. Chains не вызывают quota gate. Производственный финансовый ущерб не измерен.

### solution
Валидированный QuotaSnapshot с provider/account, finite values, observedAt/expiresAt и полнотой; общий admission требует свежий допустимый снимок и атомарную внутреннюю бюджетную резервацию. Manual override только advisory quota, не authority floor.

### steps
- Ввести негативные fixtures HTTP200 {}, missing windows, NaN, Infinity, negative, expired, wrong account.
- Проверять snapshot на producer и в едином admission для routine/chain/manager failover.
- Разделить vendor observation и Fabric spend reservation, хранить unknown usage; вернуть reason+remedy в UI/cycle receipt.
- Проверить конкурентные admission, invalid snapshot после первого тика и освобождение reservations только по доказанному исходу.

### acceptance
- Неполный/устаревший/чужой snapshot запускает 0 unattended sessions.
- Два admission не расходуют один остаток дважды.
- Operator override не расширяет grant/project scope и записывается отдельно.
