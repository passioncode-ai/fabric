#### solution

##### entry
Любой preview/list/detail; человек раскрывает вторичные сведения или приходит deep link в скрытую часть.

##### exit
Локальное раскрытие без смены main task; при full view переход/Back сохраняет collapse/focus.

##### recipe
Disclosure primitive с controlled state, heading/button semantics, aria IDs, keyboard/reduced motion. Navigation reveal распаковывает ancestor path и ставит focus. Inventory каждый SCR: main subject,status,age,owner,next action vs secondary source/filters/advanced.

##### preview
Главное действие и blocker видны без меню; technical trace/evidence details можно раскрыть.

##### states
collapsed/expanded/targeted by deep link/loading/error; incoming delta не сбрасывает открытое и не раскрывает всё.

#### interfaces

##### route
Не новый screen; совместим с NavigationState раскрытий по entity scope

##### canonical_id
DisclosureKey {screen,scope,entityId,section}, не index массива

##### interface
<Disclosure id title open onOpenChange summary?>; revealEntity(ref,{focus:true})

##### dto
Preferences не создаются глобальной layout системой на этом этапе

##### read_policy
Disclosure preserves subject order, never changes business sort. Empty/error/partial states remain visible at appropriate parent; live refresh cannot collapse source details or steal focus.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Never hide urgent action/error behind closed detail.
- No nested interactive controls; correct focus restoration.
- Screen-reader/list equivalent for graphs; no color-only provenance/status.
- Меньше видимого содержимого не означает потерянные source facts.

#### failure_cases
- 200% zoom/narrow width,keyboard-only,async reveal before data arrives,entity deleted,theme contrast,reduced-motion.

#### migration
- Первый increment primitive для новых M189/M190; полный sweep отдельный gate M187. Future personalisation остаётся deferred без implemented claim.

#### tests
- disclosureKeyboardAriaRefs; disclosureDeepLinkReveal; disclosureLiveUpdateState; visual light/dark+narrow+zoom.
