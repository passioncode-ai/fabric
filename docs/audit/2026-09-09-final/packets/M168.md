#### solution

##### entry
Любой человек/agent/model proposal проходит один предметный service, до authoritative write.

##### exit
Typed checked command либо rejection receipt, который UI связывает с сохранённым draft/proposal.

##### recipe
Schemas для proposal variants, validators ссылок/версий/authority/eligibility; transactional revalidation на commit. Checker не оценивает скрытые мысли и не доказывает истинность смысла свободного текста.

##### preview
Reason, affected object, remedy; diagnostic source refs за раскрытием.

##### states
validating/accepted/rejected/retryable/stale; rejected != unavailable checker.

#### interfaces

##### route
Остаётся исходная Board/task/decision view; receipt открывается в source inspector

##### canonical_id
proposal/command id + validator_version + input_snapshot_seq

##### dto
CheckResult = {ok:true,checkedCommand,inputRevisions} | {ok:false,reasonCode,fieldPath?,evidenceRefs,remedy,retryable}

##### command
checkAndCommit(command,actorContext), no renderer direct DB writer

##### read_policy
No independent primary screen; rejection receipts ordered newest recorded seq in source detail/Inbox. Filter reason/command/actor optional diagnostics. Checker timeout is retryable refusal to commit, never valid.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Нельзя bypass checker через вторую IPC/MCP entry.
- Model output проверяется до употребления, а не after-the-fact badge.
- Error/timeout checker fail closed, draft не теряется.

#### failure_cases
- Well-typed malicious refs, different project, superseded basis, invalid reorder band, concurrent invalidation.
- Reject payload содержит secret → safe redacted receipt, не raw prompt в Inbox.

#### migration
- Versioned reason enum и adapters; no new user workflow just for validation.

#### tests
- checkerPlantedInvalidProposalEachVariant; positive control for every rejection.
- checkerAllEntrypointsSharedBoundary; concurrent source revision changes.
