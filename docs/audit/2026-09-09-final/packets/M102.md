#### solution
- Один scoped event cursor подписывает query keys на семейства событий. Repo/config читает project.config_revision; memory — memory changes; transcripts — session outcome/transcript receipt; quota — собственный срок свежести и explicit refresh. Feed tick сам по себе не invalidates all.
- Subscribe-before-snapshot: получить high-water H и snapshot at H; сохранить buffered deltas >H; применять по монотонному estate seq, dedup by seq. Если query storage не умеет snapshot atH, server transaction выдаёт согласованный revision/snapshot; renderer не присваивает произвольный feedMark снимку.
- При reconnect replay(afterSeq) с пагинацией до current high-water. Retention gap -> invalidate affected scope and reread snapshot. Stale useful data остаётся видимым с as_of/reason; scope A→B abort/generation исключает late A.
- Burst coalescing в один in-flight запрос на key и один trailing refresh если cursor сдвинулся; stale completion не закрывает trailing refresh.

#### interfaces
- QueryKey {estate_id,project_id,reader,filter_hash}; QuerySnapshot<T> = ReadEnvelope<T> & {at_seq:string,query_revision:string}; invalidation table keyed by event.type.
- refresh(key,minimumSeq): Promise<ReadEnvelope<T>>; readers store applied_seq separately from requested_seq.

#### invariants
- An event seq is order inside estate, not a timestamp and not globally comparable.
- No refresh can turn unknown source into known zero.
- Deactivation/unmount releases subscription; project state never shares cache without scope in key.

#### failure_cases
- 100 unrelated PTY events -> memory query count0.
- Snapshot arrives after a newer delta -> buffered delta applied after snapshot, never overwritten.
- Error during refresh -> stale snapshot+error not blank state.

#### migration
- Introduce one query adapter and move ProjectHome readers independently; feed store unchanged until adapter cursor semantics covered. New graph readers use same adapter from first implementation.

#### tests
- Same event fixture before/after: collect IPC calls by channel and payload bytes; report measured counts.
- Simulate reconnect gap and duplicate/out-of-order deliveries -> current snapshot equal to reference fold.
- Switch A→B while A query pending -> B not mutated.
