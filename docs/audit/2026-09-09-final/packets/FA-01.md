### observed
Свежий checkout и удалённый CI d28c321 падают ENOENT до сборки: resources не существует. Локальный прогретый checkout проходит fast.

### solution
Сделать manifest producer самодостаточным; генерировать окончательный manifest после сборки и включать его в packaged artifact. Проверить порядок, digest содержимого и точную contract revision; не считать число файлов хешем их содержимого.

### steps
- Воспроизвести cold clone без resources/out/build, сохранить exit 1 и CI run URL.
- Создать output directory внутри producer; определить единый порядок build → final manifest → package и убрать чтение предыдущего out.
- Проверить packaged app без Git: manifest существует, идентифицирует текущие bytes, несовместимая schema не открывает writers.
- Прогнать Linux fast/full и macOS fresh+upgrade; подпись и notarization — отдельный внешний gate S07.

### acceptance
- Чистый clone с frozen lockfile проходит fast без ручного mkdir.
- Изменение одного bundle byte меняет digest; старый manifest или неподдерживаемая schema явно отклоняются.
- Сборка запускается без исходного checkout; manifest находится внутри артефакта.

### dependencies


### do_not
- Не отключать release gate и не коммитить generated resources.
- Не обещать notarization без runner и credentials.

### consequence
observed-test-and-ci

### acceptance_negative
- Missing output directories must not fail a cold build; stale bundle, modified byte and unsupported schema must never receive a compatible manifest.
