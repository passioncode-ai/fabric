#### flow
- Authoritative protocol built from runtime enums/schemas, not two prose copies; include accepted version/hash and safe obligation list. PREAMBLE remains pointer to whoami rather than reprinting all rules.
- Capture actual server UTC/timezone at compile; record runtime config revisions and input snapshot. Compiler budget accounts for whole output incl mandatoryheader/footer, defensive encoding all inserted variable strings.
- Archive exact content before append new revision lock; launch uses exact locked artifact; whoami returns same pack lock (no assertion today's project values equal historical pack). Live project summary separate ReadEnvelope.
- On explicit resume/fork/rebind/observedcompaction materialize newer pack and protocol offer; previous ack stale until new hash ack. If runner cannot emit compaction signal, mark observation unsupported and permit whoami refresh; don't pretend every compaction captured.
- ActorKind/source authority bound by S02, supplied kind/person ignored/rejected; keep agent facts in data-only block even when many agent reports agree.

- No context.read or memory.remembered names introduced as if current; exact existing events session.oriented@1/memory.project.recorded@1/context.compiled@1.
- One source fact ID+revision immutable; old pack IDs cannot prove old task brief/project purpose, preserve exact assembled bytes going forward.
- Unknown omitted count outside candidate query limit reported null; cannot say pack holds everything merely omittedFacts=0.
- Task/plan/heartbeat status enums remain different axes; not merged status vocabulary.
