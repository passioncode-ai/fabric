#### solution

##### entry
Search/Attention/Feed/Board/Graph/source link/reuse task.

##### exit
Точный объект в правильном estate/project; Back возвращает query/filter/draft, а не просто home.

##### recipe
Один EntityRef resolver + discriminated AppRoute, separate overlay state, safe default for invalid/missing ref. Search result DTO содержит entity type/id/location/snapshot/coverage/cursor. Reuse creates draft owned by project/task and refuses overwrite silently. Registry names вместо ternary labels, pin cap helper; UI theme/grid/nested controls отдельными маленькими fixes.

##### preview
Title+kind+scope+source snippet; incomplete search store обозначен, more link/cursor.

##### states
exact hit,missing/denied,outdated source,partial search,stale result,new draft conflict; keyboard labels include object names.

#### interfaces

##### route
AppRoute discriminated union + EntityRef resolver; hash routes proposed, not existing HTTP API

##### canonical_id
entity type+estate/project+id+version/location where relevant; display label never key

##### query
search.query returns grouped ReadResult with per-store coverage and exact refs

##### interface
navigateTo(ref,{returnTo,focusTarget}); reusable draft restore keyed by project/task

##### read_policy
Search order explicitly deterministic per store (exact ID/title first when supported; remaining backend order and stable ID), not fabricated relevance confidence. Filters by store/project and pagination. Hits name incomplete stores; source denied/missing stays local; query change generation rejects stale responses.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- Search/Attention never silently land at generic project when exact entity known.
- No leftover showAgents overlay overrides route.
- Names from shared agent descriptor; system/unknown not guessed labels.
- Historical plan done/total computed from same membership snapshot as full graph.

#### failure_cases
- Search A→B late response; transcript A/B race; corrected note→decision wrong target; stale ref; existing nonempty reuse draft.

#### migration
- Migrate existing callback props incrementally through resolver; old hash/source refs explicit redirects.
- Keep current route-independent session/file windows metadata; do not parse untrusted source string as shell/file path.

#### tests
- navigationAllEntryPointsSameEntity; searchPartialMore; reuseDoesNotOverwrite; transcriptLateResponse; agentLabelsCodex; themeContrast/grid regression.
