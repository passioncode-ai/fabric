#### solution

##### entry
Project Memory SCR34, task/run pack receipt, decision supplied context ref, system map knowledge source.

##### exit
Next-context dry preview→why included/omitted→exact source; Past pack→recorded artifact/version; source back keeps selected mode.

##### recipe
load snapshot with per-store errors; pure compile(snapshot,budget,compilerRev); launch persists artifact+lockfile separately. Dry preview never append/context event or spawn. Distinct next vs actual past modes. Retain immutable artifact or complete input revisions+compiler/budget for historical reconstruction.

##### preview
Selected source backend, measured chars/budget, count included/omitted, coverage/freshness. Past pack hash+compiled time+session, no estimate passed as exact.

##### states
no-history,no-facts,complete,partial-source,over-budget,unsupported-cloud,legacy-incomplete,mirror-behind,mirror-error,preview-outdated; current-vs-past labels always visible.

#### interfaces

##### route
#/e/:estate/p/:project/memory?view=next-context&task=:id; ?view=pack&pack=:eventRef; ?view=lineage&fact=:id; ?view=sync

##### canonical_id
PackRef = immutable artifact id or context.compiled estate+seq; session alone insufficient for historical snapshot

##### query
memory.preview({scope,task_ref?,snapshot_seq?,budget_spec,compiler_revision}); memory.pack(PackRef); memory.lineage(FactRef); memory.sync(scope)

##### dto
PackView {mode,sourceSnapshots,budget:{unit:chars|tokens,value,tokenizer?},used,contentHash,artifactRef?,included:[versionedRefs],omitted:[ref,reason],coverage,compilerRevision}; SyncView has own covered/exported seq

##### read_policy
Selector order is same pure versioned compiler path; facts operator group then reported group, newest with stable tie-break in selected snapshot; past packs seq desc. Filters store/kind/author/current/superseded. No history distinct from missing artifact; reconnect refreshes next preview only after marking outdated.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

#### invariants
- No inference that supplied context equals complete knowledge.
- Char budget is not relabelled token count.
- Dry no writes/no sessions; same snapshot+compiler+budget deterministic hash.
- Mirror lag only over declared covered event family, not whole journal seq difference.

#### failure_cases
- One source fails; header alone exceeds budget; rename project/brief changes later; missing compiler input versions; cloud selected but not available; mirror ahead/behind/conflict.

#### migration
- S14 read envelope first; immutable pack persistence additive; legacy pack visible as incomplete when exact original cannot be reconstructed.
- Full workspace import/backup restore is S12, not prerequisite for read-only preview.
