#### solution

##### choice
CapabilityReport is versioned per admitted runner/binding revision, with required vs optional capabilities for workload. Degraded result is a tuple of completed claims, missing capabilities/checks and available evidence, never a green boolean.

##### states
- capability supported_verified|supported_unverified|unsupported|temporarily_unavailable with evidence/checked_at; admission requires supported_verified for required safety capabilities.
- execution mode full|degraded_optional|blocked_required; model absent permits deterministic rank/hygiene, not fictitious judgement.
- degradation occurrence open→recovered; one actionable Board item only when operator action needed, informational history otherwise.

##### transactions
- Admission pins capability report revision/digest; mid-run loss emits capability.lost observation with affected commands. Required channel loss stops future mutations/fences dispatch until recovered; optional loss may continue with explicit outcome note.
- Result envelope lists done/proof/notVerified/omittedInputs and per-source freshness. Notifier partial aggregates actual successes N of configured M; unavailable source never becomes empty. Recovery does not retroactively make old incomplete result complete; append new verification/result receipt.

- ExecutionOutcome={claims,observations,evidenceRefs,notVerified[],omittedInputs[],degradations[],completionAssessment:complete|partial|unknown}

#### invariants
- No unsupported capability presented as tested because runner name is recognized.
- An optional missing skill cannot erase verified work; required safety channel cannot silently degrade to arbitrary CLI.
- Same native session reuse is denied without task invocation identity/ack/fence capability.

#### failure_cases
- AgentSurface down for external CEO workload → blocked_required, no mutation-capable launch.
- Advisory model down → deterministic mode works; unperformed judgement marked unavailable.
- Notifier one source down → partial with age or explicit skipped reason, not empty/full.

#### migration
- Additive runner passport fields default unknown, never true. Existing plain terminal launch remains possible as manual trusted-local capability with explicit limitations.
- Shared domain result versioning keeps old result schema pinned; Fabric degradation annotation can live beside provider envelope if its schema forbids additional properties.
- Do not turn M181 into new wallet/provider procurement; budget/source prerequisites stay their named cards.
