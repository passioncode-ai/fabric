### observed
Effect lifecycle и honest unknown есть; добровольный fabric_effect_request не ограничивает все native tools. Диспетчер под ноль провайдеров обоснованно не реализован; два реальных runner pilots не выполнены.

### solution
Сначала один выбранный provider с ограниченным test target, idempotency и read-back; adapter permission interception для каждого declared runner. Conformance verdict отдельно от owner admission и budget authorization.

### steps
- Зафиксировать provider capability/policy-equivalent runner profile и версию contract, используя отдельные owner repos.
- Проверить обход native tool без fabric_effect_request и запретить unsupported profile для autonomous floored effects.
- Реализовать один bounded effect adapter: reserve→dispatch→observed/unknown; retry сохраняет identity.
- Сравнить два реальных runner на одном независимом operating-loop fixture с failure controls и scoped credentials.
- Добавлять fleet/router только после измерений и общей retry/usage reservation.

### acceptance
- Попытка обойти floor перехватывается либо profile явно не допускается к этому действию.
- Timeout после dispatch не даёт executed и не разрешает blind повтор.
- Agent done не заменяет независимую проверку сервиса; reviewer отличается от producer.
