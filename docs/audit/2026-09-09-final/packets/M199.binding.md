##### flow
- Разрешать explicit run choice → project binding → default → system default один раз при admission с CAS account/config revision.
- Записать ConversationBinding, provider-native ref, workspace fingerprint, current Session generation и неизменяемый account snapshot TaskRun.
- Ввести один writer на conversation и reject поздних callbacks от прежней generation. Для externally mutable system login показывать drift и не обещать строгую pinning без подтверждения.

##### exit
