#### solution

##### entry
Project history/plan previews, agent history, Task run link, Board source, system map module node.

##### exit
Selected node inspector→exact task/question/run/decision/artifact; Back restores kind/scope/asOf/filters/zoom/selection.

##### recipe
GraphQuery kind agent_history|project_history|target_plan; route family separate destinations. Journal nodes/edges retain observed/reported/declared origin and accepted/rejected outcome; causal relations explicit. SHOULD query picks plan revision and retains completed membership. Shared renderer infra includes graph/list/outline, not one toggle changes DID into SHOULD.

##### preview
Project DID последние N observed transitions; agent DID exact binding/session scope; SHOULD remaining obligations/progress of declared revision. Always link to corresponding full scope.

##### states
empty graph/list with reason,unlinked nodes,partial/truncated,legacy provenance missing,loading,stale,reconnect,pinned-asOf,invalid edge/cycle diagnostic; not silently remove nodes.

#### interfaces

##### route
#/e/:estate/p/:project/graphs/agent-history?agent=:bindingId OR session=:id; /graphs/project-history?task=:id; /graphs/target-plan?revision=:planRev

##### canonical_id
SCR-40 family; kind is route segment; EntityRef union and graph-specific stable edge IDs

##### query
graphs.query(GraphQuery) → GraphSnapshot (общий контракт далее); graph.getNode(entityRef,scope,asOfSeq)

##### dto
Four semantic graph types shared infrastructure; decision_history routed separately SCR33, not fourth tab hidden in M190

##### read_policy
DID default recorded seq order with occurred time separately; SHOULD dependency topology plus declared task position, tie stable ID; no time-based invented schedule. Filters entity/actor/state/relation/goal/as-of; graph/list share same query. Pagination and reconnect preserve snapshot.

##### outer_envelope
Query: canonical ReadEnvelope<T>; mutation: Command<T>/CommandResult<T> from system-contract §4–5. UI lifecycle labels are local, not wire enums. New seq/epoch: decimal strings.

- Pagination snapshot stable, exact scope; current no-data is not full empty graph if coverage partial.
