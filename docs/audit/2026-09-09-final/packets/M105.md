#### solution
- Разделить terminal display ring, incremental tail parser и durable transcript stream. onData делает O(chunk size) обработку; запрещены regex/split всего scrollback на каждый chunk. UI sessions.list возвращает summary без scrollback; terminal subscriber получает bounded snapshot once then sequence-numbered chunks.
- Tail parser — streaming state machine text/ESC/CSI/OSC/OSC_ESC, сохраняет незавершённую escape sequence между chunks; CR обновляет текущую строку, LF завершает, ordinary [link] сохраняется. Raw transcript хранит исходные bytes отдельно; display text не source transcript.
- Async persistence batching: queue byte counter, 64KiB flush threshold или 50ms, final flush awaited before transcript-complete receipt. Это проектные начальные limits, не измеренный оптимум. At 4MiB pending apply upstream PTY pause if supported; otherwise keep durable spool and mark overload, never silently drop data or block main with sync I/O.
- Terminal capture error marks transcript incomplete with offset/error; independent execution status persists. UTF-8 decoder state does not split multibyte codepoints. Limit tail text to120 Unicode codepoints after ANSI decode, not bytes.

#### interfaces
- SessionSummary {session_id,status,tail,tail_seq,transcript_state:capturing|complete|incomplete,last_output_at}; no scrollback.
- TerminalSnapshot {session_id,from_seq,to_seq,text,truncated}; TerminalChunk {session_id,seq,data}; TranscriptRange {session_id,offset_bytes,limit_bytes} -> {bytes,next_offset,complete,sha256?}.

#### invariants
- No full transcript in periodic all-sessions query.
- Exit observed and transcript persisted are separate receipts; flush failure cannot erase process exit.
- Truncation of display ring does not truncate durable transcript without explicit incomplete state.

#### failure_cases
- ESC sequence split at every byte boundary -> same visible text as unsplit fixture.
- Queue write error/ENOSPC -> incomplete and actionable notification; output not reported fully saved.
- Burst then immediate exit -> completion receipt emitted only after flush.
- Remote runner with no pause/spool contract -> capability unavailable, bounded loss is explicit not hidden.

#### migration
- Add summary endpoint while keeping old terminal snapshot endpoint for one reader migration; remove scrollback from sessions.list once all consumers use explicit snapshot. Reuse existing raw transcript storage and redact at existing ingest boundary, not by replacing source bytes with tail.

#### tests
- Fixture plain [link], Cyrillic/emoji, CR-progress, CSI/OSC split positions -> expected strings.
- Compare event-loop delay and IPC bytes under same long-output fixture, record baseline and result; do not impose arbitrary speedup percentage.
- Injected slow disk+exit demonstrates bounded queue path and exact raw byte checksum or explicit incomplete.
