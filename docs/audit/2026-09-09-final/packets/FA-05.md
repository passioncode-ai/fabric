### observed
Последний отчёт называет scratchpad-ошибку m152.commit/m152-commit. В Git нет этого executable scheduler. 44 shipped строки содержат явные недоделки, а подробный каталог остаётся target-spec. Независимый parse escaped pipes даёт 81 open CO вместо 79: cell() теряет CO-050/CO-060.

### solution
Сделать canonical id и явный alias mapping машинно проверяемыми. Разделить foundation_delivered, consumer_integrated, runtime_verified и external_activation. Сохранить milestones, а остатки вести child IDs с owner и payload dependency.

### steps
- Зафиксировать regression graph с dotted ids, missing node, cycle, duplicate alias и частично delivered prerequisite.
- Реализовать один queue parser над canonical execution_nodes; named phase это preference, не hard edge.
- Сопоставлять ссылку на контракт с конкретным capability receipt и consumer; предусмотреть ready-contract vs ready-activation.
- Синхронизировать backlog/engineering model/retro и внедрить integrity gate; не затирать старые датированные отчёты.
- Один Markdown cell parser для column validation и counters: CO-050/CO-060, bold status, escaped pipes; независимый baseline 81 open.
