### observed
fabric_task_link читает только data RPC и допускает append при error/null. Проверка и запись раздельны. Конкурентный ущерб в production не наблюдался.

### solution
Транзакционный linkTasks с одним lock для проверки scope, cycle topology и append; error/unknown отказывает. Развести dependency edges и provenance edges по принятому контракту.

### steps
- Проверить прямой и MCP пути записи task.linked и существующие DB constraints.
- Создать RPC command с idempotency, scope/revision и проверкой DAG под одним lock.
- Перевести всех writers на command; возвращать типизированные cycle/unavailable/conflict причины.
- Прогнать A→B одновременно B→A, чужой estate, повтор key и отказ хранилища.
