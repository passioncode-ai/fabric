## Визуальная часть

Проверены обе темы, токены, 14 компонентов и фактическая композиция Estate, Project, onboarding, Workspace, Session, Editor. На актуальном renderer воспроизведены вложенные кнопки AgentTile; найдены две select без accessible name; измерен light live-count: 4.349:1 при 10.4 px, ниже требования 4.5:1 для обычного текста. Выборочный keyboard focus виден; полный VoiceOver/WCAG audit не выполнен. Скриншоты и размеры есть в HTML и evidence archive.

На Project 640 px и публичном сайте 390/700 px после завершения layout нет горизонтального document overflow. В public SCR-29 есть небольшой breakpoint drift: при 700 px ещё две колонки, хотя сценарий обещает одну ниже 720 px. Второе небольшое расхождение — secondary CTA ведёт к Project model, а документ обещает repository map.

**Источник актуальных утверждённых mockups не найден.** Проверены текстовые screen contracts, реальный renderer и публичный сайт; pixel comparison с утверждёнными макетами не заявлен. W06 включает фиксацию версии и источника mockup для каждого SCR.

## Проверки и поставка

`pnpm typecheck`, `pnpm gates:docs`, `pnpm gates:design`, desktop build и `pnpm test` прошли. Live DB suites действительно выполнялись; renderer имеет 26 component tests. Memory retrieval ablation дала 6/6 → 0/6 → 6/6. При этом negative probes доказали пробелы в проверках.

`pnpm audit` сообщил четыре DOMPurify advisories через Monaco: две low и две moderate, без high/critical по registry. Exploit в текущей конфигурации не воспроизводился. Главный renderer bundle — 8 098 936 байт; Monaco импортируется до открытия редактора. Startup latency не измерялась.

В fabric нет tracked CI workflow и GitHub runs в выборке. Установленный asar версии 0.1.0 отличается от текущей сборки по main/preload/renderer; в установленном main нет `effect.executed@1`. W06 требует commit/build manifest и smoke test именно установленного пакета после исправления рисков.

Публичный сайт проверен отдельно: 11/11 allowlist URLs доступны, 10 файлов совпадают с source побайтно, robots имеет Cloudflare-managed prefix. Последние 8 GitHub workflow runs успешны; это не оценка общей частоты deployment failures. [Подробности](2026-09-05-evidence/public.md).

После filing `pnpm gates:docs` снова прошёл: 107 CO, 145 milestones, 190 verification rows. Дополнительная проверка разрешила 275 source/evidence line references и локальные HTML links. Код, миграции, установленное приложение и внешние сервисы не менялись. Commit/push не выполнялись.

## Ограничения

- **approved-mockups**: Актуальный источник утверждённых интерактивных mockups не найден; указанная visualization directory пуста, ответа на запрос источника нет. Проверены screen contracts, shipped tokens/components и нынешний renderer; это не pixel-diff с утверждёнными макетами. Следующее действие: В W06 привязать каждый SCR к версии source mockup, состояниям и viewport; затем сравнить реально реализованный экран.

- **native-electron-lifecycle**: Native CUA denied by Computer Use permissions. Browser replay использует реальный compiled renderer с synthetic IPC. Нет end-to-end claims про настоящий PTY/file/dialog/quit. Следующее действие: W03/W04/W06: разрешённый native replay + fault harness по acceptance каждой строки.

- **full-accessibility**: Проверены DOM, labels, отдельный keyboard focus, light contrast и responsive geometry. VoiceOver, все error states и полный WCAG conformance не выполнялись. Следующее действие: W06: обе темы, keyboard/VoiceOver, states и контраст всех элементов.

- **real-provider-e2e**: Paid Claude Code E2E не запускался. Историческое CO-093 не переопроверено; текущий optional test не требует context pack для PASS. Следующее действие: W02/W03: явный production launch path с required identity/context/task/transcript receipts.

- **runtime-telemetry-and-performance**: SCN telemetry — планируемые события, emitter отсутствует; measured production error-rate и cold-start trace нет. Byte size не равен latency. Следующее действие: Обозначить retained local diagnostics без секретов; cold-start benchmark. Hosted telemetry только в соответствующем slice.

- **external-estate-and-vendor-history**: Linked contract/adapter проверены по seams, не как два полных самостоятельных проекта. Исторические vendor prices/quotas, registry estate domains и автономные business outcomes не перепроверены. Следующее действие: Отдельные probes перед использованием соответствующего контракта/цены; не переносить исторические BL-* измерения в текущую production оценку.

Сам HTML передан в Codex file panel. Browser file URL заблокирован политикой браузера, поэтому визуальное открытие отчёта в браузере не заявлено; доступна эта Markdown-версия.
