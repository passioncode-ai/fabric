Fabric · UI kit

Один источник для всех экранов Fabric: правила в ui-kit.md, значения в стилях приложения. Эта страница собрана из них скриптом scripts/build-ui-kit.mjs; править её руками бесполезно, гейт найдёт расхождение. Шрифт PassionCode здесь заменён системным.

Цвета: роли интерфейса

Компоненты берут только эти роли (--app-*), никогда сырой цвет: так обе темы и обновление PassionCode меняют все экраны сразу. Золото это действие, выбор и фокус, но не состояние.
